# 货灵供应链运营平台三端核心功能清单

**目标读者**：产品、研发、测试。
**核心目的**：划定三端功能范围与边界，作为开发拆分依据。
**前提**：独立部署、单一运营主体；货主是业务实体，不做多租户。

## 货灵ERP

货主查在库、单据、账单，发起委托；以订单、委托、查询与确认为主，不执行仓内作业。

| 模块 | 关键要点 |
| --- | --- |
| 首页工作台 | 库存概览、待办单据、异常、待确认账单 |
| 订单中心与平台接入 | 多平台多店铺拉单、平台乘订单类型、店铺授权、同步任务与失败重试 |
| 订单 360 与履约决策 | 一张订单聚合渠道、履约、仓单、运单、售后与账单；记录履约方式、仓、承运商、承诺时间与拆分原因 |
| 履约与发货 | 仓发货、自发货、平台备货；一单多履约、部分发货、补发与多包裹 |
| 平台售后 | 售后同步、同意、拒绝、确认收货、退款；仓发货生成售后入库计划单 |
| 商品资料 | 商品主档、条码包装单位、批次效期属性 |
| 委托单据中心 | 各类委托单统一查询、状态跟踪、导入导出、变更取消 |
| 入库委托 | 入库通知单、预计到货、商品数量、收货差异确认 |
| 出库委托 | 出库订单、收货方与承运商、批次效期要求、优先级 |
| 调拨与退货申请 | 跨仓调拨发起与进度、退货退仓申请 |
| 库存查询 | 在库/可用/冻结、ATP 可承诺、已占用/在途、数据截止、批次效期、库存台账、多仓汇总 |
| 异常与对账 | 跨订单/同步/履约/售后/账单的异常队列；平台单、ERP 单、履约/运单、账单四单对账差异 |
| 物流跟踪 | 发货交接、运单与在途节点、签收回单、异常件 |
| 费用结算 | 费用规则查看、账期账单与明细、对账申诉、确认、发票付款记录 |
| 数据报表 | 周转库龄、出入库趋势、履约时效、费用构成、多仓对比 |
| 账号与权限 | 只服务本货主账号；子账号与角色、按仓按业务的数据可见范围、操作日志 |

上述能力全部纳入原型范围（2026-11-08 补订单 360、履约决策、ATP 与异常对账）。逐项落点：

| 功能域 | 页面（模块 / key） | 可做的动作 |
| --- | --- | --- |
| 首页工作台 | `workbench/workbench` | 库存概览、待确认账单、单据状态与异常汇总；授权、拉单、待下发、待发货、待预约、待售后待办 |
| 订单中心与平台接入 | `owner/order-center`、`owner/platform-order-list`、`owner/platform-shop-list`、`owner/sync-task-list` | 拉单、下发 3PL、自发货、备货到平台仓、授权、重新授权、重试 |
| 订单 360 与履约决策 | `owner/order-center` | 订单 360 抽屉：渠道、履约决策、关联单据、ATP、时间线；决策表单记录仓、承运商、承诺时间、拆分原因 |
| 履约与发货 | `owner/fulfillment-list`、`owner/platform-replenish-list`、`owner/selfship-list`、`outbound/out-plan-owner-list` | 一单多履约、部分发货、箱唛/装箱单/预约入仓、自发货运单 |
| 平台售后 | `owner/platform-aftersale-list` | 同意、拒绝、确认收货、退款、生成售后入库计划单 |
| 商品资料 | `base/sku-apply-list`、`base/sku-audit-list`、`owner/sku-owner-list` | 查看自有商品；新建、编辑、保存草稿、提交审核、撤回、驳回后修改重提；运营中台审核留意见、赋码、版本递增并发布 |
| 委托单据中心 | `owner/delegation-list` | 统一查询与状态跟踪、变更取消 |
| 入库委托 / 出库委托 | `inbound/in-plan-owner-list`、`outbound/out-plan-owner-list` | 建单、提交、看运营中台确认结果；委托与计划单合并为一页，统一中心只做视图 |
| 调拨与退货申请 | `owner/transfer-apply-list`、`owner/return-apply-list` | 新增、保存草稿、提交、撤回、看进度 |
| 库存查询 | `inventory/stock-owner-list`、`ledger-owner-list`、`stock-owner-report`、`batch-owner-list` | 只读查询；看 ATP、已占用、在途、数据截止；临期处置意见由货主确认 |
| 异常与对账 | `owner/exception-list`、`owner/reconciliation-list` | 异常确认、异议申诉；对账差异转异常、确认、关闭 |
| 物流跟踪 | `owner/tracking-list` | 只读查看运单状态与在途节点 |
| 费用结算 | `billing/rate-owner-list`、`billing/bill-owner-list` | 查看规则与账单明细、确认、对账申诉 |
| 数据报表 | `owner/owner-report` | 周转库龄、出入库趋势、履约时效、费用构成、多仓对比 |
| 账号与权限 | `owner/account-list`、`owner/role-owner-list`、`owner/audit-owner-log` | 新增、编辑、停用子账号，分配货主角色，按仓按业务限定可见范围，查看本货主操作日志；账号与角色只在本货主范围内 |

边界不变：以订单、委托、查询与确认为主，不执行仓内作业；自发货只做 ERP 内发货记录，不写 3PL 库存台账。货灵ERP按登录身份限定数据，不提供货主下拉、货主筛选与身份切换；商品新增一律由货主提交申请、运营中台审核赋码发布，运营中台不直接建商品。表单可录入字段并驱动状态流转，状态只在本端产物的内存与会话里生效，两端初始数据由同一份共享申请单主档还原。

侧栏一级菜单按信息线索分，不按单据类型或模块名分：工作台 / 订单 / 履约 / 售后 / 仓储委托 / 异常与对账 / 库存 / 商品 / 商城店铺 / 平台接入 / 账单与服务 / 报表与设置。每段只回答一个问题，单段不超过 5 页；页头页签与侧栏同源。

## 货灵运营中台管理端

服务商管仓库与货主服务关系，统筹跨仓库存、资源与结算；不直接执行仓内作业。

| 模块 | 关键要点 |
| --- | --- |
| 仓网总览与监控 | 仓库状态、全网库存库容、出入库量、异常预警、按仓下钻 |
| 仓网布局与仓库配置 | 仓库档案、库区库位结构、可存货主品类、作业能力、启停用 |
| 货主与主数据管理 | 货主档案、货主与仓库授权、商品承运商主档、编码规则、下发各仓 |
| 跨仓调拨与库存统筹 | 调拨受理审批、出仓入仓两端、在途库存、分仓补货建议、调拨台账 |
| 多仓数据汇总与报表 | 库存库容、履约、效率人效、差异异常、临期预警、按仓按货主下钻 |
| 资源调度 | 作业量预测分配、人员设备月台运力排班、跨仓支援、高峰预案 |
| 计费结算 | 仓租作业费规则、按货主账期汇总账单、审核调整、对账、发票收款 |
| 权限与组织管理 | 组织架构、角色权限、按仓按货主数据范围、账号、审批流、审计日志；原型落账号管理、角色权限、操作日志三页，组织架构先用仓库与班组表达；只服务运营方与仓内账号，不管理货主 ERP 账号 |
| ERP 运营管理 | 货主开通、模块与版本、平台应用、同步健康、全局审计、代维只读；不管理货主子账号 |

原型落点：

| 功能域 | 页面（模块 / key） | 可做的动作 |
| --- | --- | --- |
| ERP 运营管理 | `erp-ops/erp-tenant-list`、`erp-ops/erp-module-list`、`erp-ops/erp-app-list`、`erp-ops/erp-sync-health`、`erp-ops/erp-global-audit` | 开通/停用货主、调整有效期、模块配置、代维进入、查看全局审计；模块与版本启用停用；平台应用查看凭证、测试连接、更新版本；同步健康重试；全局审计按货主/端/模块/动作筛选 |

## 货灵WMS

实际仓库的日常作业执行与账实管理，含任务分派、人员与设备协同。

| 模块 | 关键要点 |
| --- | --- |
| 作业工作台与任务中心 | 待办任务池、派工领取、作业看板、进度、交接班 |
| 收货入库 | 到货登记、按通知单收货验收、数量批次效期质检、差异拒收、越库直发 |
| 上架与库内存储 | 上架任务与推荐库位、库区库位管理、移库并库补货、先进先出、冻结解冻 |
| 拣货出库与发货交接 | 出库受理、波次计划、库存分配锁库、拣货作业、复核打包、发货交接回单 |
| 库存盘点 | 盘点计划与范围、实盘录入、差异复核调整、盈亏审批、盘点报告 |
| 库存查询与台账 | 按货主商品批次库位查询、台账与流水追溯、临期清单、库存快照 |
| 异常处理 | 差异短缺破损丢失批次不符任务阻塞登记、分类归责、审批、库存调整 |
| 作业人员与绩效 | 班组岗位、账号权限与岗位授权、派工工作量、效率准确率、排班资质；人员档案关联账号与账号状态，账号由运营中台统一维护 |
| 设备与作业资源 | 设备登记状态、任务下发与结果回传、故障维保、容器托盘、月台占用 |
| 单仓报表与看板 | 收发货量、效率准确率、库容利用率、周转库龄、异常、人效、班次报表 |
