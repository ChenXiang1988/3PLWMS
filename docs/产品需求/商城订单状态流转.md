## 一单多履约与部分发货

商城订单仍只走仓发货，但一个订单可以拆多张出库单。首张出库单交接后，商城订单转「部分发货」；全部履约单交接完成才转「已发货」。`obNo` 只存首张主履约单号，全部履约单见履约单视图。

```mermaid
flowchart TD
  A["商城订单 · 待发货"] --> B["生成首张出库订单"]
  B -->|首张交接完成| C{"全部履约单完成?"}
  C -->|否| D["商城订单 · 部分发货"]
  D --> E["继续生成下一张出库订单"]
  E -->|交接完成| C
  D -->|未发部分取消| F["未发部分取消 · 已发部分保留"]
  F -->|全部收口| G["商城订单 · 已发货"]
  C -->|是| G
  G -->|签收或超时确认| H(["商城订单 · 已完成 · 不可逆终态"])
  G -->|拒收或退货| I["退货退仓 · 生成逆向入库单"]
  I --> H
```
