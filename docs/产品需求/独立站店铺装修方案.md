# 独立站店铺装修方案

## 1. 目标

在现有 `站点内容` 页面内提供 Schema 驱动的店铺装修能力，不新增独立装修导航。运营人员通过区块库、画布和属性面板编辑页面，使用同一份 Schema 完成桌面端、移动端预览、草稿、发布、下线和历史版本管理。

## 2. 页面与职责

| 页面 | 变更 | 责任 |
| --- | --- | --- |
| `site-content` | 必须同改 | 内容列表、状态筛选、装修编辑入口、Schema 编辑、预览与发布动作 |
| `site-channel` | 必须同改 | Web、APP、微信小程序、支付宝小程序的发布任务与结果反馈 |
| `site-member` | 必须同改 | 查看、编辑、删除、发布与区块级权限 |
| 独立站 Web / APP 前台 | 无需改 | 仅作为已发布内容的预览目标 |

## 3. 编辑器结构

- 顶部操作栏：标题、保存状态、撤销、重做、设备切换、预览、保存草稿、发布。
- 左侧区块库：轮播、图文、页面、商品网格、分类导航、优惠券。
- 中央画布：按区块数组渲染，支持选中、上移、下移、复制和删除。
- 右侧属性面板：由区块定义字段生成控件，编辑结果直接写入 Schema。
- 底部状态区：显示 Schema 状态、当前版本、权限与下线动作。

首期原型以点击、排序和属性编辑演示结构化编辑；移动端提供同 Schema 的比例预览，完整画布编辑仍以桌面端为主。

## 4. 数据与版本

`pageSchema` 是唯一真相源，包含 `schemaVersion`、根节点、区块实例、区块属性、数据绑定、链接、终端配置和可见性。商品网格只引用站点商品主档，不能复制价格、库存等字段。保存草稿不改变已发布版本；发布失败保留当前草稿；下线只改变当前发布状态并保留历史版本。

## 5. 状态与权限

内容状态为草稿、待发布、已发布、已下线。发布、下线和重新发布均需发布权限；属性编辑和区块增删排序需编辑及区块级权限；查看权限只允许预览。危险动作二次确认并明确后果。

## 6. 校验

发布前检查 Schema 版本、区块类型、必填字段、终端配置、站点内链接、数据绑定和成员权限。校验失败不清空编辑内容、不生成发布版本，并在编辑器内给出修正提示。

## 7. 原型落点

- 数据：`prototypes/site/data/site-content.json`
- 页面：`prototypes/site/pages/site-content.mjs`
- 共享编辑器：`prototypes/shared/ui.mjs`
- 字段真值：`docs/数据字典/装修区块.md`
