# 商品档案管理方案（三端交互与效期批次）

**目标读者**：产品、研发、测试。
**核心目的**：定下商品主档在三端之间谁建档、谁审核、谁使用，以及效期与批次的生成与管控口径，作为原型与开发依据。
**前提**：独立部署、单一运营主体；货主是业务实体。字段真值见 [商品主档.md](../数据字典/商品主档.md)。

## 1. 三端职责

| 端 | 对商品主档 | 对批次效期 | 不做 |
| --- | --- | --- | --- |
| 货灵ERP | 查看自有商品、提交新增与变更申请、确认临期处置意见 | 查看本货主各仓批次与剩余天数 | 不赋码、不发布、不改主档 |
| 货灵运营中台管理端 | 唯一真值源：审核申请、赋商品编码、发布版本、停用 | 配置效期与批次策略，跨仓汇总临期与过期 | 不直接新建商品、不执行仓内作业 |
| 货灵WMS | 只读使用已发布主档，用于收货验收、拣货复核、盘点 | 收货时生成批次并采集生产日期；按策略分配出库；执行处置 | 不改主档、不自定策略 |

商品新增的唯一入口是货灵ERP提交商品资料变更申请。运营中台商品档案页保留策略维护、版本递增与停用，不提供新建与导入商品；`商品主档.changeSource` 的「仓网维护」只用于运营中台对已发布主档的策略订正，不用于新建 SKU。新增类型在提交前不带 `skuCode`，审核通过时由运营中台赋码；两端申请单取同一份共享主档，字段与状态见 [商品资料变更申请单.md](../数据字典/商品资料变更申请单.md)。

## 2. 交互流程

| 环节 | 发起 | 处理 | 结果 |
| --- | --- | --- | --- |
| 建档 | 货灵ERP新建申请单，填基础标识、包装计量、效期批次与存储作业 | 校验必填与撞码；运营中台审核并留审核意见、赋商品编码、版本递增发布 | 主档下发各仓，货灵WMS可见；申请单留操作轨迹 |
| 变更 | 货灵ERP提交变更申请 | 运营中台审批，效期与批次策略为必审字段 | 版本递增；新单据用新版本，已有批次不回溯改写 |
| 撤回与重提 | 货灵ERP撤回、驳回后修改重提 | 申请单留痕不可删 | 状态回到草稿或待审核 |
| 逆向 | 运营中台反审核、未下发前作废 | 原版本留痕，`skuCode` 不复用 | 已产生单据或批次时不可逆，按变更申请发新版本 |
| 收货 | 货灵WMS按入库通知单验收 | 依主档校验批次与生产日期是否必录 | 生成批次，写库存（货主＋商品＋批次＋库位） |
| 出库 | 出库订单 | 按 FEFO / FIFO 分配批次；过期与禁售拦截，临期按货主确认放行 | 发货交接回单，批次台账留痕 |
| 查询 | 三端各自范围 | 货灵ERP限本货主、运营中台全网、货灵WMS本仓 | 批次号与剩余天数口径一致 |
| 临期处置 | 运营中台汇总临期批次 | 货灵ERP确认退货 / 销毁 / 降价出库 | 货灵WMS执行，冻结与解冻同步 |

### 条码与扫码上下文

- 商品身份是「货主＋商品编码」，69 码只作扫描索引；`barcode` 在同一货主内唯一，跨货主允许重复。
- 收货、拣货、复核、盘点一律先有单据或任务上下文（含货主），扫码只在「本单 / 本任务货主的商品集合」内匹配，条件为「货主＋条码」，不做全局按条码取第一条的查询。不允许未进单据的裸扫。
- 命中 1 条才允许继续；命中 0 条判差异或拒收，不借用其它货主的商品主档；命中多条弹出候选并登记异常，不默认取第一条。
- 运营中台建档与审核遇到跨货主同码时给出提示，由审核人确认是贴牌共用还是录错；同一货主内同码直接拒绝。
- 一商品多包装条码另建「商品条码映射」（货主、条码、商品编码、包装单位）；外包装无法区分时贴仓内码，改扫内部商品编码。
- 台账留扫码原值、匹配到的商品编码与货主、单据行与时间，便于追溯。

## 3. 字段分组

| 组 | 关键字段 | 谁维护 |
| --- | --- | --- |
| 基础标识 | 商品编码、商品名称、规格、条码、货主、单位、商品状态 | 运营中台赋码发布 |
| 包装计量 | 箱规、每件数量、毛重、净重、体积、长宽高 | 货灵ERP申请，运营中台审核 |
| 效期策略 | 是否效期管理、保质期天数、生产日期必填、失效日期来源、临期预警天数、禁售天数 | 运营中台配置 |
| 批次策略 | 是否批次管理、批次编码规则、批次属性、混批存放、出库分配规则 | 运营中台配置 |
| 存储作业 | 温区、存储条件、质检要求、拣货单位、是否称重 | 运营中台配置 |
| 版本与审计 | 版本号、生效时间、创建人、创建时间、更新时间 | 系统写入 |

## 4. 效期管理

- 商品级策略：是否效期管理、保质期天数、失效日期来源（生产日期推算 / 供应商给定）、临期预警天数、禁售天数。
- 收货验收：效期管理商品必录生产日期；失效日期＝生产日期＋保质期天数；供应商给定失效日期时校验一致性。
- 剩余天数＝失效日期−当前日期，按天重算，不落库。
- 状态流转：正常 → 临期（剩余天数 ≤ 临期预警天数）→ 禁售（≤ 禁售天数）→ 过期（＜0）。
- 出库：过期与禁售批次不可分配；临期批次需货主确认；效期商品按 FEFO 优先分配。
- 临期处置：运营中台汇总 → 货灵ERP确认意见 → 货灵WMS执行，冻结批次同步。

## 5. 批次管理

- 批次不是商品主档字段，是库存维度；主档只定义「是否管理批次＋编码规则＋属性集合」。
- 批次号在收货验收时生成：生产日期＋到货日期＋当日流水，或沿用供应商批次号。
- 批次属性：批次号、生产日期、失效日期、到货日期、供应商、入库通知单号、货主、商品。
- 库存粒度：货主＋商品＋批次＋库位 → 在库数量 / 可用数量 / 冻结数量。
- 出库分配：效期商品 FEFO、非效期商品 FIFO，由主档「出库分配规则」决定；关闭混批存放时同库位只允许一个批次。
- 台账：收货、上架、移库、拣货、盘点、处置均记批次变动。

## 6. 界面交互设计

| 端 | 页面 | 骨架 | 关键列 | 页签与筛选 | 主操作 |
| --- | --- | --- | --- | --- | --- |
| 货灵ERP | 商品资料变更申请 | list + 表单抽屉 | 申请单号、商品名称、变更类型、商品编码、审核状态、提交时间、申请人、操作 | 页签 全部/草稿/待审核/已通过/已驳回/已撤回/已作废；筛选 变更类型、商品编码、提交时间 | 新增、保存草稿、提交审核、撤回、退回修改重提 |
| 货灵ERP | 货主 · 批次效期查询 | list | 货主、商品编码、批次号、生产日期、失效日期、剩余天数、效期状态、在库数量 | 页签 全部/正常/临期/禁售/过期；筛选 仓库、商品编码 | 确认处置 |
| 运营中台 | 商品档案 | list | 商品编码、商品名称、规格、条码、货主、单位、是否效期管理、是否批次管理、保质期天数、临期预警天数、商品状态 | 页签 全部/启用/停用；筛选 货主、是否效期管理 | 新增、导入、导出 |
| 运营中台 | 商品主档审核 | list + 表单抽屉 | 申请单号、商品名称、变更类型、货主、申请人、提交时间、审核人、审核时间、审核状态、操作 | 页签 全部/待审核/已通过/已驳回/已撤回/已作废；筛选 货主、变更类型、申请单号 | 审核通过、驳回留原因、反审核、作废、赋商品编码、版本递增 |
| 运营中台 | 效期批次策略 | 商品档案列表行抽屉 | 抬头：商品编码、商品名称、货主、版本号、商品状态；明细：策略项与取值 | 无状态页签 | 保存、关闭 |
| 运营中台 | 批次效期总览 | report | 批次数、临期批次、禁售批次、过期批次；分仓与分货主明细 | 报表页按本部署主体口径 | 导出 |
| 货灵WMS | 本仓商品查询 | list | 商品编码、商品名称、规格、条码、货主、单位、是否效期管理、是否批次管理、商品状态 | 页签 全部/启用/停用；筛选 商品编码、条码、货主 | 导出、刷新 |
| 货灵WMS | 批次效期 | list | 货主、商品编码、批次号、生产日期、失效日期、剩余天数、效期状态、库位编码、在库数量 | 页签 全部/正常/临期/禁售/过期；筛选 库位编码、商品编码 | 批量异常登记、导出 |

交互约束：列表页一页一张表、状态页签点击真筛数据、货主下拉只作用于有货主维度的页面且仅用于运营中台与货灵WMS；货灵ERP按登录身份限定数据范围，不提供货主下拉与货主筛选，身份在登录时选择、进入后锁定；数字列右对齐；表头口径说明收进提示，不摆在版面。货灵WMS商品查询只读，不出现编辑类主操作。
