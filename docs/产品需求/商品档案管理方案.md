# 商品档案管理方案（三端交互与效期批次）

**目标读者**：产品、研发、测试。
**核心目的**：定下商品主档在三端之间谁建档、谁审核、谁使用，以及效期与批次的生成与管控口径，作为原型与开发依据。
**前提**：独立部署、单一运营主体；货主是业务实体。字段真值见 [商品主档.md](../数据字典/商品主档.md)。

## 1. 三端职责

| 端 | 对商品主档 | 对批次效期 | 不做 |
| --- | --- | --- | --- |
| 货主端 | 查看自有商品、提交新增与变更申请、确认临期处置意见 | 查看本货主各仓批次与剩余天数 | 不赋码、不发布、不改主档 |
| 仓网管理端 | 唯一真值源：审核申请、赋商品编码、发布版本、停用 | 配置效期与批次策略，跨仓汇总临期与过期 | 不执行仓内作业 |
| 单仓端 | 只读使用已发布主档，用于收货验收、拣货复核、盘点 | 收货时生成批次并采集生产日期；按策略分配出库；执行处置 | 不改主档、不自定策略 |

## 2. 交互流程

| 环节 | 发起 | 处理 | 结果 |
| --- | --- | --- | --- |
| 建档 | 货主端提交商品资料 | 仓网端审核、赋商品编码、发布 | 主档下发各仓，单仓端可见 |
| 变更 | 货主端提交变更申请 | 仓网端审批，效期与批次策略为必审字段 | 版本递增；新单据用新版本，已有批次不回溯改写 |
| 收货 | 单仓端按入库通知单验收 | 依主档校验批次与生产日期是否必录 | 生成批次，写库存（货主＋商品＋批次＋库位） |
| 出库 | 出库订单 | 按 FEFO / FIFO 分配批次；过期与禁售拦截，临期按货主确认放行 | 发货交接回单，批次台账留痕 |
| 查询 | 三端各自范围 | 货主端限本货主、仓网端全网、单仓端本仓 | 批次号与剩余天数口径一致 |
| 临期处置 | 仓网端汇总临期批次 | 货主端确认退货 / 销毁 / 降价出库 | 单仓端执行，冻结与解冻同步 |

### 条码与扫码上下文

- 商品身份是「货主＋商品编码」，69 码只作扫描索引；`barcode` 在同一货主内唯一，跨货主允许重复。
- 收货、拣货、复核、盘点一律先有单据或任务上下文（含货主），扫码只在「本单 / 本任务货主的商品集合」内匹配，条件为「货主＋条码」，不做全局按条码取第一条的查询。不允许未进单据的裸扫。
- 命中 1 条才允许继续；命中 0 条判差异或拒收，不借用其它货主的商品主档；命中多条弹出候选并登记异常，不默认取第一条。
- 仓网端建档与审核遇到跨货主同码时给出提示，由审核人确认是贴牌共用还是录错；同一货主内同码直接拒绝。
- 一商品多包装条码另建「商品条码映射」（货主、条码、商品编码、包装单位）；外包装无法区分时贴仓内码，改扫内部商品编码。
- 台账留扫码原值、匹配到的商品编码与货主、单据行与时间，便于追溯。

## 3. 字段分组

| 组 | 关键字段 | 谁维护 |
| --- | --- | --- |
| 基础标识 | 商品编码、商品名称、规格、条码、货主、单位、商品状态 | 仓网端赋码发布 |
| 包装计量 | 箱规、每件数量、毛重、净重、体积、长宽高 | 货主端申请，仓网端审核 |
| 效期策略 | 是否效期管理、保质期天数、生产日期必填、失效日期来源、临期预警天数、禁售天数 | 仓网端配置 |
| 批次策略 | 是否批次管理、批次编码规则、批次属性、混批存放、出库分配规则 | 仓网端配置 |
| 存储作业 | 温区、存储条件、质检要求、拣货单位、是否称重 | 仓网端配置 |
| 版本与审计 | 版本号、生效时间、创建人、创建时间、更新时间 | 系统写入 |

## 4. 效期管理

- 商品级策略：是否效期管理、保质期天数、失效日期来源（生产日期推算 / 供应商给定）、临期预警天数、禁售天数。
- 收货验收：效期管理商品必录生产日期；失效日期＝生产日期＋保质期天数；供应商给定失效日期时校验一致性。
- 剩余天数＝失效日期−当前日期，按天重算，不落库。
- 状态流转：正常 → 临期（剩余天数 ≤ 临期预警天数）→ 禁售（≤ 禁售天数）→ 过期（＜0）。
- 出库：过期与禁售批次不可分配；临期批次需货主确认；效期商品按 FEFO 优先分配。
- 临期处置：仓网端汇总 → 货主端确认意见 → 单仓端执行，冻结批次同步。

## 5. 批次管理

- 批次不是商品主档字段，是库存维度；主档只定义「是否管理批次＋编码规则＋属性集合」。
- 批次号在收货验收时生成：生产日期＋到货日期＋当日流水，或沿用供应商批次号。
- 批次属性：批次号、生产日期、失效日期、到货日期、供应商、入库通知单号、货主、商品。
- 库存粒度：货主＋商品＋批次＋库位 → 在库数量 / 可用数量 / 冻结数量。
- 出库分配：效期商品 FEFO、非效期商品 FIFO，由主档「出库分配规则」决定；关闭混批存放时同库位只允许一个批次。
- 台账：收货、上架、移库、拣货、盘点、处置均记批次变动。

## 6. 界面交互设计

| 端 | 页面 | 骨架 | 关键列 | 页签与筛选 | 主操作 |
| --- | --- | --- | --- | --- | --- |
| 货主端 | 商品资料变更申请 | list | 申请单号、商品名称、变更类型、货主、审核状态、提交时间、申请人 | 页签 全部/待审核/已通过/已驳回；筛选 变更类型、商品编码 | 提交 |
| 货主端 | 货主 · 批次效期查询 | list | 货主、商品编码、批次号、生产日期、失效日期、剩余天数、效期状态、在库数量 | 页签 全部/正常/临期/禁售/过期；筛选 仓库、商品编码 | 确认处置 |
| 仓网端 | 商品档案 | list | 商品编码、商品名称、规格、条码、货主、单位、是否效期管理、是否批次管理、保质期天数、临期预警天数、商品状态 | 页签 全部/启用/停用；筛选 货主、是否效期管理 | 新增、导入、导出 |
| 仓网端 | 商品主档审核 | list | 申请单号、商品名称、变更类型、货主、申请人、提交时间、审核状态 | 页签 全部/待审核/已通过/已驳回；筛选 货主、变更类型 | 审核通过、驳回 |
| 仓网端 | 效期批次策略 | detail | 抬头：商品编码、商品名称、货主、版本号、商品状态；明细：策略项与取值 | 无状态页签 | 保存、发布 |
| 仓网端 | 批次效期总览 | report | 批次数、临期批次、禁售批次、过期批次；分仓与分货主明细 | 报表页按本部署主体口径 | 导出 |
| 单仓端 | 本仓商品查询 | list | 商品编码、商品名称、规格、条码、货主、单位、是否效期管理、是否批次管理、商品状态 | 页签 全部/启用/停用；筛选 商品编码、条码、货主 | 导出、刷新 |
| 单仓端 | 批次效期 | list | 货主、商品编码、批次号、生产日期、失效日期、剩余天数、效期状态、库位编码、在库数量 | 页签 全部/正常/临期/禁售/过期；筛选 库位编码、商品编码 | 批量异常登记、导出 |

交互约束：列表页一页一张表、状态页签点击真筛数据、货主下拉只作用于有货主维度的页面；数字列右对齐；表头口径说明收进提示，不摆在版面。单仓端商品查询只读，不出现编辑类主操作。

原型按端交付，一个端一个 `prototypes/00 dist/<端名>.html`，侧栏只列本端页面；页面源仍按模块目录存放。

| 端 | 产物 | 页面（模块 / key） |
| --- | --- | --- |
| 货主端 | `prototypes/00 dist/货主端.html` | `base/sku-apply-list`、`inventory/batch-owner-list` |
| 仓网管理端 | `prototypes/00 dist/仓网管理端.html` | `base/sku-list`、`base/sku-audit-list`、`base/sku-policy-detail`、`inventory/batch-network-report` |
| 单仓端 | `prototypes/00 dist/单仓端.html` | `base/sku-warehouse-list`、`inventory/batch-list` |
