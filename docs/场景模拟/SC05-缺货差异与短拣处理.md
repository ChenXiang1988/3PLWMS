# SC05 缺货差异与短拣处理

## 场景描述

乙在剩余 20 箱中完成 18 箱，另外 2 箱缺货。本场景验证差异闭环：核对为 60 = 40（前段已确认）+ 18（接续已确认）+ 2（差异待处理），实际拣出 58；随后决定这 2 箱是补货后继续拣，还是经授权接受短拣。补拣需明确谁跟进补货、谁接续执行、恢复作业条件；接受短拣需记录决定人、差异原因与关闭依据，实际完成量仍为 58。

## 参与角色

- 乙（作业人员）：接续 20 中完成 18、报 2 缺货。
- 主管 / 授权人：决定补拣或接受短拣。
- 补货员：跟进补货（若走补拣路径）。
- 系统（WMS）：记录差异、决定人与关闭依据，关联异常队列 / 库存调整。

## 触发条件

- 拣货作业出现少拣 / 缺货，实际拣出 < 计划数量；
- 任务进入差异待处理状态，等待补拣或接受短拣决策。

## 正常流程

1. 系统核对：60 要求 = 40 前段 + 18 接续 + 2 差异待处理，实际 58。
2. 差异进入异常队列，等待授权决策。
3. 分支一·补拣：授权人指定补货跟进人与接续执行人，定义恢复作业条件（补货到位）；补货完成后乙/接续人完成剩余 2 箱。
4. 分支二·接受短拣：授权人记录决定人、差异原因、关闭依据；任务以实际完成 58 关闭，差异归档。

## 异常流程

- 2 箱无明确后续责任：不进入异常队列、无人决策 → 强制差异必须有关联的授权决策单，禁止静默关闭。
- 未经授权接受短拣：直接关单 → 拦截无决定人/无依据的短拣关闭。
- 补拣与短拣决策不清：既发补货又接受短拣导致重复作业 → 二选一锁定，决策后释放另一路径。

## 闭环条件

- 差异 2 箱有明确决定人、处理方式（补拣 / 短拣）与后续执行责任；
- 补拣路径：补货与接续执行人明确、恢复条件满足后任务可完成；
- 短拣路径：决定人/原因/关闭依据已记录，任务按实际 58 关闭。

## 闭环验证

- [ ] 少拣 2 箱后，系统呈现 60=40+18+2 的核对结果，差异入异常队列待决策。
- [ ] 选补拣：能指定补货跟进人与接续执行人，补货到位后恢复作业。
- [ ] 选短拣：必须录入决定人+原因+关闭依据，否则关单被拒；关单后实际完成量=58。
- [ ] 任一路径均不产生「既补货又短拣」的重复作业。
