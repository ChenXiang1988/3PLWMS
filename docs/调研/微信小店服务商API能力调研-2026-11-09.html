2.3 非页面能力

对集成最关键的能力不在「页面」而在「开放接口与回调」，逐项确认：

  • 事件通知（回调）：订单生命周期 8 类事件主动推送（见 3.2），是 ERP 实时拉单的主要通道。
  • ISV 代调用：服务商经 authorizer_access_token 代商家调用，受权限集（129/130/131/132/138/141/192）约束。
  • 电子面单：取号、预取号、取消、打印报文，是 WMS 打单核心。
  • 隐私号 / 虚拟号：收件人真实号码自 2026-01-19 起不返回，需「售后单兑换虚拟号」等接口履约联系（B 级公告）。
  • 奇门协议：代发模式下 ERP↔WMS 协同的标准映射（ds_order_id / supplier_appid / product_id+sku_id）。

2.4 未覆盖项

17 个运营 / 营销 / 生态类模块仅目录级覆盖，不展开；资金结算、类目管理等字段未验证。详见第 7 节。

3 逐页记录

3.1 微信小店 › 接入与鉴权（ISV 模式）

入口

微信小店支持两种接入模式：商家自研（用自己的 access_token）与第三方服务商 ISV（商家授权后用 authorizer_access_token 代调用）。本次命题聚焦后者。服务商需先成为微信开放平台「平台型第三方平台」并全网发布，申请对应权限集后，商家在服务市场订购即触发授权。来源：官方「服务市场接入指引」「第三方服务商调用模式介绍」（B 级）+ 百度百科服务市场词条（C 级）。

结构分区

授权链路为：服务商创建第三方平台 → 申请权限集并发布 → 商家订购 → 平台静默授权权限集并推送授权变更消息 → 服务商用 authorizer_access_token 代调用；退款成功后平台解除授权关系（C 级，服务市场词条）。

权限集矩阵

不同服务类型授予的权限集 id 不同（B 级，官方服务市场接入指引）：

服务类型权限集 id与履约的关系
商品服务129、130、131、132商品 / 库存同步
订单服务129、130、131、132拉单 / 发货
ERP129、130、131、132、138、141覆盖订单 + 物流 + 商品全链路
厂商代发129、130、131、132代发协同
会员工具129、130、131、132、167、185、186会员，与履约无关
供货商代发192供货商侧代发 API
带货工具129、130、131、132、141、167带货，与履约无关

交互与异常

典型的「静默失败」：授权时若未勾选「订单」「售后」相关权限，即便应用已上线，订单 / 售后事件也不会推送（C 级，点三网解读 + 官方 FAQ）。因此接入前必须确认权限集 131 已授权、回调 URL 已配置并返回 200。

3.2 微信小店 › 事件通知（回调）

入口

文档地址 developers.weixin.qq.com/doc/store/shop/notify/。微信小店以事件通知驱动为核心，而非轮询（C 级，点三网「事件通知体系」）。订单相关事件清单（B 级，官方 notify/order_callback）：

事件英文名说明对货灵的意义
channels_ec_order_new订单下单建单起点（未支付）
channels_ec_order_cancel订单取消逆向：关闭平台订单
channels_ec_order_pay订单支付成功触发 ERP 拉详情 + WMS 备货
channels_ec_order_wait_shipping订单待发货进入履约队列
channels_ec_order_deliver订单发货回传运单后平台推送
channels_ec_order_confirm订单确认收货完结
channels_ec_order_settle订单结算成功财务对账
售后单更新通知售后状态变更逆向履约
api_diffAPI 变更日志接口变动预警

结构分区

事件经回调 URL（POST）推送，需校验 msg_signature / timestamp / nonce 与 EncodingAESKey 签名，返回 200 OK 才视为成功，否则平台重试（C 级，CSDN 实现示例）。订单 / 售后事件需要权限集 131（B 级，点三网 + 官方 FAQ）。

入口

商品模块 API/channels-shop-product/：添加商品、更新商品、获取商品、上架 / 下架 / 删除，另有赠品、买赠、限时抢购。库存子模块 stock：获取库存、批量获取库存、快速更新库存、获取库存流水（B 级目录）。

库存双体系（B 级，官方库存管理指南）

对比项通用库存区域仓库库存

3.6 微信小店 › 售后管理

入口

模块 API/channels-shop-aftersale/，含纠纷单、保障单。核心接口 获取售后单 getaftersaleorder POST api.weixin.qq.com/channels/ec/aftersale/getaftersaleorder，权限集 131，关联「售后单更新通知」事件（B 级接口页）。

关键字段

退款状态经 refund_resp.result_code 与 refund_resp.return_code 判断（均为 SUCCESS 表示成功，B 级官方社区答）。售后类型 type：1 退款、2 退款退货、3 换货（C 级接口示例）。2026-07 起获取售后单新增 aftersale_voucher_type / voucher_list / vourcher_code 等字段（B 级周报）。

3.7 微信小店 › 区域仓库

入口

模块 API/warehouse/，与 3.5 的「区域仓库库存」配套，提供区域仓的创建与库存管理（B 级库存管理指南）。多仓就近发货由平台按收货地址匹配优先级最高且有库存的仓库，与货灵 WMS「实体仓 + 库存分仓」模型可对应。

3.8 微信小店 › 代发管理

入口

模块 API/supplier/，分三组（B 级目录）：关联代发合作供货商（获取供货商列表 get_supplier_list、申请关联 invite_supplier）、自动分配设置（获取分配方式 get_distribute、设置手动 / 全店自动 / 按商品自动分配）、代发单管理（代发单列表、代发单详情含商品与发货状态、电子面单取号、代发单发货）。

奇门协议（ERP↔WMS 协同，C 级点三网解读）

代发模式要解决三个工程问题：身份映射、结果分组、职责划分。关键映射：代发单唯一标识 ds_order_id、供货商以 supplier_appid 标识、平台商品以 product_id + sku_id 标识。取号与发货职责由 ERP 或 WMS 显式约定。

3.9 微信小店 › 店铺管理与资金结算（目录级）

店铺管理 storemanage：获取店铺基本信息 mmecapi_basicinfo（权限集 129/131/192）、店铺口令等，用于 ERP 店铺档案落库。资金结算 funds：资金账户、银行卡、资金二维码，与货灵 ERP 财务对账相关，但字段级未验证（见第 7 节）。
