3.1 m3e-canvas › 草图与组件面板

入口

浏览器打开应用（静态站点或本地 npm run dev）即进入草图画布；部件从左侧部件面板拖入。无账号、无服务端。

结构分区

左侧部件面板（键盘可用、可收藏）、中央画布（手机 / 桌面）、右侧每个部件的专属配置面板（文本、样式、尺寸、对齐、点按行为标签页）。

3.2 m3e-canvas › 画布、导航与转场

入口

从部件面板拖出屏幕；任一屏幕可在标签上切换手机（412×892）与桌面（1280×800），栏自动伸缩、导航栏与导航轨互转。

结构分区

多屏幕管理、滚动屏（拖底部手柄或 1x~3x）、点按 / 滑动目标与转场（侧滑 / 淡入 / 展开 / 无）、流程箭头总览、图层面板、分组复制粘贴。

列表列与筛选

无传统列表；屏幕以标签管理，同名屏幕在提示词中合并为「同屏两宽」。

状态 × 动作

导航动作手机桌面预览播放
点按跳转（含 back 反向）可可可
滑动打开可未验证未验证
转场动画可（四选一）可可

交互与异常

预览态回放转场；back 反向播放。转场实际观感未实测，标「未验证」。

3.3 m3e-canvas › 主题系统

入口

主题面板一处统管：颜色、形状、字体、动效。

结构分区

七套调色板或单一种子色（自动生成完整 M3 方案并可微调）、明暗、三档对比 + 动态色；圆角（方 / 圆 / 全圆）全局生效；Roboto 系列或系统字体；标准或弹性 spring 动效（驱动预览）。

行与批量操作

主题切换一键应用到全部部件。

状态 × 动作

主题维度可选实时预览
调色板 / 种子色7 套 + 自定义可（未验证）
对比度3 档 + 动态色可（未验证）
圆角 / 字体 / 动效3 / 4 / 2 选可（未验证）

交互与异常

单一主题源避免散落；与我方 tokens.css.mjs 的「实现层唯一取值来源」思路一致，但具体视觉语言是 Material 3 Expressive，与我方 wx-* 体系不同（见第 4、6 节）。

3.4 m3e-canvas › 提示词生成

入口

画完草图后「Copy the prompt」：整份设计或单屏生成简洁 brief。

结构分区

输出语言（日 / 英 / 中 / 韩）、目标（Android / Web）、可编辑后复制、单屏可存 PNG；行、重叠与对齐网格的卡片会被显式写出，保证生成布局保形。

列表列与筛选

无列表；提示词文本可在复制前编辑。

交互与异常

实际生成文本结构未实测，标「未验证」。这一能力是目标 1「vibe-coding 工作法」的核心：把设计意图转成可喂给 AI 编码工具的精准 brief。

3.5 m3e-canvas › AI 助手、分享与工程部署

入口

可选 AI 助手（自带 key 直连 OpenAI / Claude / Gemini / DeepSeek）；分享链接打开他人画布；public/agent.md 给 Claude Code / Codex 的指令文件。

结构分区

AI 助手：从一句话起草设计、写部件行为备注、写屏幕描述，每次重写可撤销，请求直连厂商不外传。agent.md：描述需求 → 自动草图 → 回一个分享链接。

工程与部署

栈 Next.js 16.4 + React 19 + Tailwind 4 + TypeScript 7，npm run build 静态导出到 out/，GitHub Actions 发布 Pages；可设 NEXT_PUBLIC_BASE_PATH 支持子路径托管。

交互与异常

AI 助手与分享链接需 key / 联网，未实测，标「未验证」。源码中 public/agent.md 内容未读，仅 README 描述。

6 结论与落点

每条结论只允许三种判定：可借鉴、不跟随、待定。落不到具体落点的是描述，不是结论。

编号判定结论落点
C1不跟随不把 m3e-canvas 生成的 React/Web 应用替换现有手工 HTML 原型流程；我方产物由 build-app.mjs 从 modules.json + shared 装配，且设计语言非 M3prototypes/build-app.mjs（构建链不变）
C2不跟随不引入 Material 3 Expressive 视觉体系；强行换皮等于重做五端设计prototypes/shared/tokens.css.mjs（维持 wx-* 体系）

C5可借鉴把 vibe-coding 方法落到我方栈：新增 AGENT.md 规格，让 AI 编码工具按 shared/ui.mjs 组件与 wx-* 令牌从页面描述生成 HTML，补充（非替代）手工流程prototypes/AGENT.md（新增） + SKILL.md

C7待定提示词多语言（日英中韩）与 Android/Web 目标导出是否值得让我方页面生成器支持，取决于是否做海外仓英文界面定了影响 prototypes/AGENT.md
