调研报告

m3e-canvas 可视化画布设计思路在独立站店铺装修的迁移可行性

m3e-canvas 的"组件面板 + 画布 + 属性面板 + 实时预览"范式可迁移到独立站店铺装修；其"导出 AI 提示词重新生成代码"定位不适用生产环境，应改为 schema 驱动渲染、数据绑定与草稿发布。

日期2026-11-09 状态草案 版本v0.1 作者调研 报告对象m3e-canvas 与主流独立站店铺装修器范式（Shopify / 店匠 Shoplazza / BigCommerce / Webflow）

3 逐页记录

3.1 m3e-C › 编辑器主页

入口

浏览器打开即可使用，无需登录（C 级，来自文章）。页面类型为画布 / 设计器。可跳转去向：导出提示词（生成 AI 编程提示）。

结构分区

三栏：左栏 8 个面板（组件、颜色等）；中栏手机示例屏（画布，拖入组件后实时呈现）；右栏属性面板（选中组件后编辑其属性）。顶栏含预览与导出提示词入口。

列表列与筛选

左侧组件面板按类别列出 30+ 个 M3 组件（按钮、列表、抽屉等），以分类列表呈现，无跨页签筛选（C 级）。

行与批量操作

核心动作是"拖拽组件入画布"；磁吸连线把按钮与列表项连成一组，表达跳转 / 联动（未验证实操）。无批量操作概念。

状态 × 动作

状态编辑中导出提示词
空白画布可（拖入组件）可（生成提示词）
已拼装可（继续编辑）可（生成提示词）

m3e-C 无发布态与不可逆终态；其产物是 AI 提示词，交由 Claude Code 等外部工具生成代码。

交互与异常

空态为空白画布（C 级）；磁吸连线与导出失败等异常交互未实操，标"未验证"。

3.2 装修器范式 › 可视化页面编辑器（C 级，未验证）

入口

在线店铺 › 主题 › 自定义（典型路径，未验证）。页面类型为画布 / 设计器。可跳转去向：页面列表、模板市场、发布。

结构分区

三栏：左栏区块库（Section / Block，按营销 / 商品 / 基础分类）；中栏画布（拖入区块后实时呈现，支持上移下移与删除）；右栏属性面板（编辑区块标题、图片、链接等）。顶栏含设备切换（桌面 / 移动）、预览与发布。

列表列与筛选

区块库按类型分类列出（轮播 / Banner / 商品网格 / 分类列表 / 富文本 / 优惠券等），无跨页签筛选（未验证具体分类）。

行与批量操作

拖拽区块入画布；区块支持上移 / 下移 / 删除 / 复制；页面支持另存为模板（未验证具体按钮与可用条件）。

状态 × 动作

草稿→ 预览→ 发布

逆向：发布后可回退到草稿或历史版本（未验证回滚具体入口）；"发布"为对外可见的不可逆对外态，但内容可再改后重发。

交互与异常

空态为新页面无区块（未验证）；发布失败、部分区块数据缺失等异常未登录实系统，标"未验证"。

同名不同义必须先对照再用。下表区分 m3e-C 的通用设计词与装修器范式的电商词，并落到我方叫法。

对象原生叫法该对象下的判定口径我方叫法
m3e-C组件（Component）Material 3 通用 UI 部件，无业务语义装修组件（不引入 M3 视觉语言，见 C5）
装修器范式区块 / Section / Block带业务语义的电商单元（商品网格、优惠券等），可绑定动态数据装修区块

6 结论与落点

每条结论只允许三种判定：可借鉴、不跟随、待定。落不到具体落点的是描述，不是结论。

编号判定结论落点
C1可借鉴"组件（区块）面板 + 画布 + 属性面板 + 实时预览"三栏范式可直接用于独立站店铺装修器erp-app 独立站 nav-site-ops 下新增"店铺装修"段，页面 key 如 site-decorate-editor
C2可借鉴区块库 + 页面模板复用，减少重复搭建；首期区块库含轮播 / Banner / 商品网格 / 分类列表 / 富文本 / 优惠券 6 类装修器区块库数据 + 页面模板（落 site-decorate-editor 与站点内容）
C3不跟随m3e-C 的"导出 AI 提示词→重新生成代码"定位不适用生产店铺；应改为 schema 驱动渲染（配置即数据、稳定引擎渲染），便于热更新与回滚装修器渲染层（schema → renderer），不引入代码重生成
C4可借鉴其"AI 生成"思路可改为"AI 生成装修方案"：自然语言 → 区块布局 JSON（我方 schema）→ 预览 → 发布，比原版导出 Claude Code 提示词更贴合生产装修器 AI 助手模块（落 site-decorate-editor 扩展）
C5不跟随不应套用 Material 3 Expressive 的视觉语言到电商店铺；电商装修应用品牌化 / 营销化组件视觉装修器组件视觉规范（不引入 M3）
C6待定多端（App / 小程序）装修是否纳入同一装修器，待确认端定位；定了影响 site-decorate-editor 是否含移动端可视化视图nav-site / nav-site-ops 边界，决策人：产品
C7可借鉴数据绑定复用现有 站点商品（引用主档），发布复用 多端发布，角色复用 成员与权限，而非另起一套nav-site-ops 的 站点商品 / 多端发布 / 成员与权限 三页
