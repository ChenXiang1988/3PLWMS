# 调研报告索引（货灵供应链运营平台）

本文件夹是竞品、参考系统与需求来源调研报告的存放处。**一次调研窗口（≤24 小时）一份报告**，超期另起新文件，旧轮次正文只读。规范见 `.codebuddy/rules/调研颗粒度/RULE.mdc` 的「交付物」一节。

## 使用规则

1. **新增报告**：在本文件夹新建 `<命题>-<YYYY-MM-DD>.html` 与同名 `.assets/` 截图目录，在本索引追加一行、在 `docs/log.md` 追加一条；同日第二轮起文件名加 `-2`。
2. **新一轮取代旧结论**：不改旧文件，在新报告「结论与落点」写「修正 `<旧文件名>` 的 X 条」，并把旧行的「状态」改为「已被 `<新文件名>` 取代」。
3. **状态是唯一可改项**：除状态列，已发布轮次的正文与索引其余字段不追改；顶层 `docs/index.md` 的「最近更新」只记分类入口本身，不随单份报告变动。
4. **提交前自检**：`node .codebuddy/skills/research-report/scripts/check-report.mjs <报告.html>` 查八节与内容质量，`node docs/check.mjs` 查必需 meta、调研窗口不超过 24 小时、文件名与窗口起始日一致，以及本表与目录文件双向闭环；两份零错误再提交。
