# 技术栈选型

## 定位

现代、开源、成本可控的三方仓管理系统。**非 SaaS**：按私有化 / 单实例部署，不采用跨客户共享的多租户云架构。

## 前端

- Vue 3（Composition API）+ TypeScript
- Vite 构建，Pinia 状态管理，Vue Router 路由
- Element Plus / Ant Design Vue 组件库，ECharts 报表可视化
- Axios 对接后端

## 后端

- Java 21 + Spring Boot 3.x
- 持久层：MyBatis-Plus（或 JPA/Hibernate）
- Spring Security + JWT 鉴权，Spring Validation 参数校验
- 构建：Maven / Gradle；接口文档：Knife4j / OpenAPI
- 并发控制：Redis 分布式锁（拣货 / 分配）

## 数据存储

- PostgreSQL 16（主 OLTP：库存 / 批次 / 订单 / 计费；JSONB 存货主差异化属性；RLS 行级安全做多租户隔离；分区表撑大表）
- Redis 7（热库存缓存、分布式锁、会话）

## 基础设施 / 运维

- 容器化：Docker + Kubernetes
- 网关 / 反向代理：Nginx
- CI/CD：GitLab CI / GitHub Actions
- 监控：Prometheus + Grafana + 链路追踪

## 按需扩展

- 分析报表：ClickHouse（列存，计费 / BI 提速）
- 全局搜索：OpenSearch / Elasticsearch

## 货主数据隔离方案

本项目不是 SaaS，不做跨客户的共享多租户基础设施。系统服务于单一 3PL 服务商，内部存在多个「货主」业务实体：

- 以 `货主_id` 字段做数据隔离，应用层按角色 / 权限过滤，无需 RLS 或物理分库；
- 若确有强隔离诉求，PostgreSQL RLS 行级安全可作可选加固，但非架构必需；
- 部署形态为私有化 / 单实例，按需水平扩展，不预设多租户计费与自助开通。


## 分层架构（简述）

```
表现层      Vue3 SPA（货灵ERP / 运营中台 / 货灵WMS，按路由与权限区分）
网关层      Nginx + Spring Cloud Gateway（鉴权 / 限流 / 路由）
业务层      Spring Boot 微服务（基础数据 / 入库 / 出库 / 库存 / 计费 / 任务调度）
数据层      PostgreSQL（主库）+ Redis（缓存 / 锁）+ 按需 ClickHouse / OpenSearch
运维层      Docker / K8s + Prometheus / Grafana + CI/CD
```

多端共享同一后端服务集群，通过组织维度（服务商 / 仓库 / 货主）与角色权限区分数据可见范围。
