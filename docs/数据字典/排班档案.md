# 排班档案（数据字典）

> 实体：排班档案｜对应原型页面：作业资源 / 排班（`resource` 模块，货灵WMS）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。
一行是一「仓＋班组＋日期＋班次」的排班记录，不是人员主档。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `shiftCode` | 排班编码 | String | 20 | 是 | 全局唯一，业务引用主键 | 建议 `SF` + 6 位序号；不可改 |
| `workDate` | 作业日期 | Date | — | 是 | `YYYY-MM-DD` | 与班次共同定位 |
| `shiftType` | 班次 | Enum | — | 是 | 早班 / 中班 / 晚班 / 常白班 | 与班组档案 `shiftType` 一致 |
| `shiftStatus` | 排班状态 | Enum | — | 是 | 待确认 / 已确认 / 已取消 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `pending` | 待确认 | `pending` |
| `confirmed` | 已确认 | `enabled` |
| `cancelled` | 已取消 | `disabled` |

## 2. 归属与时段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `warehouseCode` | 所属仓库 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 排班按仓维护 |
| `teamCode` | 班组 | String | 20 | 是 | 关联班组档案 `teamCode` | |
| `startTime` | 开始时间 | String | 10 | 是 | `HH:mm` | |
| `endTime` | 结束时间 | String | 10 | 是 | `HH:mm` | 跨零点班次按次日计 |
| `unitCode` | 执行单元 | String | 20 | 否 | 关联执行单元档案 `unitCode` | 本班次负责区域 |

## 3. 人数与系统字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `planCount` | 计划出勤人数 | Int | — | 是 | 排班计划值 | |
| `actualCount` | 实际出勤人数 | Int | — | 否 | 交接班后回填 | |
| `leaderCode` | 值班负责人 | String | 20 | 否 | 关联人员档案 `staffCode` | |
| `remark` | 备注 | String | 300 | 否 | 自由文本 | 不进列表列 |
| `createTime` | 创建时间 | Datetime | — | 是 | 系统写入 | 列表列 |
| `updateTime` | 更新时间 | Datetime | — | 是 | 系统写入 | |
| `createBy` | 创建人 | String | 50 | 否 | 账号 | 关联 `system` 模块账号 |

## 4. 与其它主档的关系

- 仓库主档与班组档案：一行排班同时指向 `warehouseCode` 与 `teamCode`，班组决定默认班次类型。
- 人员档案：本档只存计划与实际人数，出勤名单由人员档案按 `teamCode` 与日期关联，不在此重复建人员清单。
- 执行单元档案：`unitCode` 给本班次负责的作业区域。
- 作业量预测：计划人数与时段是资源调度的输入，不写预测结果。

## 5. 原型衔接建议

- `resource/shift-list`（货灵WMS，list）：排班编码、作业日期、班次、班组、开始时间、结束时间、计划出勤人数、实际出勤人数、排班状态、创建时间。
- 筛选：班次、班组、排班状态、作业日期；状态页签 全部 / 待确认 / 已确认 / 已取消。
- 行按 `warehouseCode` 归属本仓，不带货主维度。
