# 自发货单（数据字典）

> 实体：自发货单｜对应原型页面：货灵ERP「自发货单」（`owner` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
自发货单是货主用自有仓、工厂或供应商直接发给终端消费者的执行单。它不锁 3PL 库存、不写 3PL 台账、不计仓储作业费；发货后回写来源订单并回传平台。

## 3. 与其它主档的关系

- 平台订单：`sourceDocType=平台订单` 时 `sourceDocNo` 取平台订单编号；发货后回写平台订单履约状态与发货时间。
- 代发采购单：`sourceDocType=代发采购单` 时 `sourceDocNo` 取代发单号；卖家侧与货源侧各自按登录货主查看。
- 履约单：自发货单是自发货方式的执行单，完成后形成一条履约单，来源单与履约单为一对多关系。
- 物流运单：自发货单可生成运单，`planNo` 为空，来源单据类型为自发货单。
- 库存台账：自发货不写 3PL 库存台账，也不校验 3PL 可用库存；只校验不超来源单行数量。

## 4. 原型衔接建议

- `owner/selfship-list`（货灵ERP，list）：自发货单号、来源订单、收货方、承运商、运单号、包裹数、自发货状态、发货时间。
- 状态页签：全部 / 待发货 / 已发货 / 已签收 / 已取消；筛选：来源单据类型、承运商、自发货状态。
- 工具条：新建、发货、取消、导出；发货抽屉录入承运商、运单号来源、运单号、包裹数、发货时间与面单、标签附件名；行详情展示收货地址与操作轨迹。
- 自助动作：申请运单号、打印面单、打印标签、发货；打印动作只写附件名与操作轨迹，不改变自发货状态，原型不调用打印机。
- 列表按登录货主限定，不提供货主筛选；发货前可取消，已发货只能走平台售后。
