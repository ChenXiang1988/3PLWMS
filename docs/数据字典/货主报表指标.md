# 货主报表指标（数据字典）

> 实体：货主报表指标｜对应原型页面：货灵ERP「货主数据报表」、货灵ERP「货主工作台」｜字段真值源

约定：报表指标全部由库存台账、批次效期、委托单、费用账单派生，不另存第二份汇总真相。多仓对比与趋势按维度聚合，同一指标在三端取同一口径。

## 3. 与其它主档的关系

- **库存台账**：在库、可用、冻结数量与库龄按台账流水聚合，周转库龄＝平均在库量除以期间出库量乘天数。
- **批次效期**：临期、禁售、过期批次数取效期状态枚举，按仓与货主汇总。
- **委托单**：入库趋势、出库趋势按提交时间与计划数量聚合；履约时效＝发货交接时间减委托提交时间。
- **费用账单**：费用构成按费用项目聚合金额；待确认账单取账单状态为待确认的张数。
- **差异异常单**：待处理异常取处理状态为待处理、处理中的张数。

## 4. 原型衔接建议

- 货灵ERP `owner/owner-report` 用 `ReportHero` + `StatRow` + `Block`，指标卡取本节枚举，分节标题取「明细」「构成」。
- 工作台 `workbench/workbench` 补库存概览与待确认账单两张指标卡，数值取同一指标口径，不另算一套。
- 趋势与多仓对比用 `Block` 内表格呈现，不引图表库；口径说明收进 `tipKey`。
- 报表页只读，不提供编辑类主操作；导出沿用工具条次操作。
