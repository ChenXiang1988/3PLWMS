# 设备档案（数据字典）

> 实体：设备档案｜对应原型页面：作业资源 / 设备档案、设备、设备调拨（`resource` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `deviceCode` | 设备编码 | String | 20 | 是 | 全局唯一，业务引用主键 | 建议 `DV` + 4 位序号；不可改 |
| `deviceName` | 设备名称 | String | 100 | 是 | 现场称呼 | 如「1 号电动叉车」 |
| `deviceType` | 设备类型 | Enum | — | 是 | 叉车 / AGV / 输送线 / 电子标签 / 称重设备 / 手持终端 | 与仓库主档 `handlingEquip` 分类对齐 |
| `hardwareModel` | 设备型号 | String | 50 | 否 | 厂商型号 | 关联设备型号清单 |
| `serialNo` | 出厂序列号 | String | 50 | 否 | 厂商唯一编号 | 维保追溯 |
| `deviceStatus` | 设备状态 | Enum | — | 是 | 启用 / 停用 / 维保 / 报废 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `active` | 启用 | `enabled` |
| `inactive` | 停用 | `disabled` |
| `maintaining` | 维保 | `pending` |
| `scrapped` | 报废 | `disabled` |

## 5. 与其它主档的关系

- 仓库主档：`warehouseCode` 外键；设备是某一座实体仓的现场资源，运营中台看全网设备，货灵WMS只看本仓。
- 库区库位：固定安装的设备按 `zoneCode` 归属库区；移动设备靠当前使用人与任务记录定位。
- 人员档案：`operator` 指向人员；班组与排班决定某时段谁可用这台设备。
- 货主主档：设备不与货主绑定，多货主共用仓内资源，不按货主隔离。

## 6. 原型衔接建议

- `resource/hardware-archive`（货灵运营中台管理端，list）：设备编码、设备名称、设备类型、设备型号、所属仓库、设备状态、购置日期、创建时间。
- `resource/hardware-list`（货灵WMS，list）：同上，行按 `warehouseCode` 归属本仓。
- `resource/hardware-transfer`（货灵运营中台管理端，list）：调拨单号、设备编码、设备名称、调出仓库、调入仓库、调拨状态、创建时间。
- 筛选：设备类型、设备状态、所属仓库；状态页签 全部 / 启用 / 停用 / 维保 / 报废。
