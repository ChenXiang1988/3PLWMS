# 仓库主档（数据字典）

> 实体：仓库主档（Warehouse Master）｜对应原型页面：基础资料 / 仓库档案（`base` 模块，拟新增 `warehouse-list`）
> 示例模拟数据：[仓库主档-示例数据.md](samples/仓库主档-示例数据.md)（3 个覆盖典型场景的模拟仓，供原型演示/测试用）
> 定位：描述**真实物理仓库**的主档，与逻辑仓、虚拟仓、货主视图仓区分。
> 本文件是字段真值源；后续生成原型页面时，列名与取值须逐字取自本文件，并在 `glossary.md` 登记。
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯；类型以 PostgreSQL 风格标注。

约定：
- 必填：是=创建时不可为空；否=可空。
- 枚举（Enum）：固定取值集合，原型中以 `select` 呈现，首项「全部」。
- 多值（multi）：可多选，存储为数组 / JSONB，原型标签/筛选用逗号拼接展示。
- 关联：指向其它主档的外键，原型列展示其「名称」，详情页可跳转。

## 3. 物理结构与容量

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `warehouseType` | 仓库类型 | Enum | — | 是 | 中心仓 / 前置仓 / 分拨仓 / 保税仓 / 转运仓 | 决定作业与计费模式 |
| `buildingStructure` | 建筑形态 | Enum | — | 否 | 单层 / 多层 / 立体库 | |
| `floorCount` | 层数 | Int | — | 否 | 多层 / 立体库为楼层数；单层为 1 | 与 `floors` 一致 |
| `totalArea` | 总面积 | Decimal(10,2) | — | 否 | 单位 ㎡，多层时为各层 `floorArea` 之和 | |
| `usableArea` | 可用面积 | Decimal(10,2) | — | 否 | 单位 ㎡ | 扣除通道/办公 |
| `storageArea` | 存储面积 | Decimal(10,2) | — | 否 | 单位 ㎡ | |
| `zoneCount` | 库区数 | Int | — | 否 | 关联库区主档计数 | 与 `warehouse` 模块 `location-list` 联动 |
| `binCount` | 库位数 | Int | — | 否 | 关联库位主档计数 | 同上 |
| `dockCount` | 月台数 | Int | — | 否 | 装卸月台 / Dock 数 | |
| `clearanceHeight` | 层高 | Decimal(5,2) | — | 否 | 单位 m | |
| `floorLoad` | 地坪承重 | Decimal(10,2) | — | 否 | 单位 kg/㎡ | |
| `rackType` | 货架类型 | Enum | — | 否 | 横梁 / 驶入式 / 流利式 / 自动化立库 / 其他 | 仓库主类型概述；逐货架类型见「库区库位」货架主档 `rackType` |
| `tempZones` | 温区配置 | Enum(multi) | — | 否 | 常温 / 恒温 / 冷藏 / 冷冻 | 多温区并存分别描述 |
| `floors` | 楼层结构 | Array\<object\> | — | 否 | 单层面积与按层用途，详见下方对象说明 | 多层 / 立体库必填；单层可仅一条 |

> `floors` 为数组，每层对象结构：
> | 字段 | 中文 | 类型 | 必填 | 口径 |
> | --- | --- | --- | --- | --- |
> | `floorNo` | 楼层号 | Int | 是 | 1=1F，B1=地下一层 |
> | `floorArea` | 单层面积 | Decimal(10,2) | 是 | 单位 ㎡，多层时为该层面积 |
> | `clearanceHeight` | 层高 | Decimal(5,2) | 否 | 单位 m |
> | `usage` | 楼层用途 | Enum | 否 | 仓储 / 拣选 / 暂存 / 办公 / 设备 / 其它 |
>
> 说明：`totalArea` = Σ `floorArea`；单层建筑 `floors` 仅一条且 `floorArea` = `totalArea`。详细的**库区划分与库位类型**不在此档，归属「库区库位」主档（`warehouse` 模块 `location-list`）。

## 8. 与其它主档的关系

- **货主主档（owner）**：`serviceOwners` 多对多；仓库为「资源」，货主为「货主业务维度」，二者解耦。
- **库区库位（location）**：`warehouse` 模块持有，按 `warehouseCode` 归属；`zoneCount` / `binCount` 为派生计数，不冗余存储。
- **商品 / 承运商主档**：与仓库无直接外键，通过单据（ASN / SO）在业务流中关联。
- **费用规则（billing）**：`billingBasis` 决定该仓适用的仓租计费方式。
