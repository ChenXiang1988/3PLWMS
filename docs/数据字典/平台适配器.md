# 平台适配器（数据字典）

> 实体：平台适配器｜对应原型页面：货灵ERP「平台适配器」（`owner/platform-adapter-list`）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
平台适配器按「平台 × 平台模式」一条，是部署级接入契约，不按货主分别持有；字段映射、状态映射与能力都挂在这一条上，不复制进平台店铺。原型按演示身份渲染，所以演示行带 `owner` 归属，仅为可见性，不改变实体口径。

## 1. 适配器标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `adapterCode` | 适配器编码 | String | 30 | 是 | 全局唯一，业务引用主键 | `ADP` + 平台 + 模式；不可改 |
| `platform` | 平台 | Enum | — | 是 | 速卖通 / Amazon / Temu / TikTok Shop / Shopee / Lazada / 美客多 / 其他 | 取 glossary 平台枚举 |
| `platformMode` | 平台模式 | Enum | — | 是 | 全托管 / 半托管 / POP / 跨境店 / FBA / FBM / 自营 | 与「店铺类型」不共枚举：本字段是接入模式，店铺类型是店铺属性 |
| `authMode` | 授权方式 | Enum | — | 是 | 产品库存 Token / 订单发货 Token / 合规 API Token / 站点市场服务 / OAuth / 区域授权 / supplier_id | 取平台店铺同名字段 |
| `rawOrder` | 原单有无 | Enum | — | 是 | 有原单 / 无原单（备货单） | 全托管与 FBA 按备货单接入，不产生终端消费者订单 |
| `labelSource` | 面单来源 | Enum | — | 是 | 平台面单 / 承运商面单 / 卖家自备 / 无面单 | 决定面单申请走平台还是承运商 |
| `fulfillDuty` | 履约责任 | Enum | — | 是 | 平台 / 卖家 | 全托管由平台承担，其余由卖家承担 |
| `rateLimit` | 限流 | String | 20 | 是 | 如 `60 次/分钟` | 各平台配额不同，驱动同步任务节流 |
| `releaseStatus` | 发布状态 | Enum | — | 是 | 已发布 / 草稿 / 已停用 | 停用后该平台模式停止拉单与回传 |
| `adapterVersion` | 适配器版本 | String | 20 | 是 | 如 `2026.11` | 跟随软件版本发布，单据不引用该版本 |

### 发布状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `released` | 已发布 | `enabled` |
| `draft` | 草稿 | `pending` |
| `disabled` | 已停用 | `disabled` |

## 2. 映射明细（行内明细表）

一条适配器对应多条映射明细。三类映射共用一张明细表，用「映射类型」列区分，不在页面上拆三张表。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `mapType` | 映射类型 | Enum | — | 是 | 字段映射 / 状态映射 / 能力 | 三类合并展示 |
| `platformSide` | 平台字段或状态 | String | 60 | 是 | 平台原字段名、状态原文或能力名 | 原文照录，不做归一化 |
| `erpSide` | ERP 字段或状态 | String | 60 | 是 | 本系统字段名、处理状态或能力落点 | 字段映射取字典字段中文名，状态映射取原单处理状态 |
| `support` | 支持情况 | Enum | — | 是 | 支持 / 不支持 / 平台侧 / 卖家侧 | 不支持表示该平台模式无此能力 |
| `appVersion` | 适用版本 | String | 20 | 是 | 关联 `adapterVersion` | 逐行标注，便于看版本差异 |

### 能力项枚举

| 值 | 口径 |
| --- | --- |
| 拉单 | 平台侧/支持：拉回平台订单或备货单 |
| 回传 | 运单号、发货、预约状态回传平台 |
| 申请面单 | 平台面单、承运商面单或不支持 |
| 取消订单 | 平台是否接受取消回传 |
| 改地址 | 平台改地址后是否允许重新同步覆盖 |
| 售后 | 是否产生平台售后单 |
| 库存推送 | 是否向平台推送可售库存 |

## 3. 与其它主档的关系

- 平台店铺：`platform` × `platformMode` 命中一条适配器，`平台店铺.adapterCode` 回指；四个适配要点由本实体派生，店铺不另存一份。
- 平台订单：`platformStatus` 按本实体状态映射转 `processStatus`；拉单、回传、拆单后的状态回传都按能力矩阵判定是否可用。
- 同步任务：`rateLimit` 驱动每店铺队列节流；`releaseStatus=已停用` 时该平台模式停止拉单与回传。
- 平台应用（运营中台）：平台应用管部署级凭证、应用审核与限流总配额；平台适配器管平台×模式的映射契约与能力。两者层级不同，不互相复制字段。

## 4. 原型衔接建议

- 货灵ERP `owner/platform-adapter-list`（list）：适配器编码、平台、平台模式、授权方式、原单有无、面单来源、履约责任、限流、发布状态、适配器版本、操作。
- 状态页签取 `releaseStatus`：全部 / 已发布 / 草稿 / 已停用；筛选：平台、平台模式。发布状态只走页签，不重复设筛选。
- 适配器是部署级配置，两个演示身份看到同一套完整清单；映射明细按 `adapterCode` 索引在 `config.adapterDetails`，不随身份过滤丢失。
- 行抽屉：`DrawerDetail` 抬头取授权方式、原单有无、面单来源、履约责任、限流、字段映射/状态映射/能力条数、适配器版本；明细表列取映射类型、平台字段或状态、ERP 字段或状态、支持情况、适用版本；附版本发布轨迹。
- 表单动作：发布、停用、关闭。发布与停用只写演示行的 `releaseStatus` 与操作轨迹，不调平台接口、不改已生成的单据。
- 「发布」与「停用」的后果提示按文案纪律保留：停用后停止拉单与回传，已生成单据不受影响。
