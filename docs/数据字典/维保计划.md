# 维保计划（数据字典）

> 实体：维保计划（Maintenance Plan）｜对应原型页面：作业资源 / 维保计划（`resource` 模块 `maintenance-plan`）
> 定位：设备定期维保的排期与完成记录；字段为 C 级推断，原型只做结构与演示值。

## 1. 维保字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `planNo` | 计划号 | String | 24 | 是 | `MP` + 日期 + 流水 | 全局唯一 |
| `deviceCode` | 设备编码 | String | 20 | 是 | 关联设备档案 | |
| `maintenanceType` | 维保类型 | Enum | — | 是 | 日常保养 / 定期检修 / 大修 | |
| `cycleDays` | 周期天数 | Int | — | 是 | | |
| `nextDueAt` | 下次到期 | Date | — | 是 | | |
| `lastDoneAt` | 上次完成 | Date | — | 否 | | |
| `vendor` | 供应商 | String | 60 | 否 | | |
| `planStatus` | 状态 | Enum | — | 是 | 待维保 / 已排期 / 已完成 / 已逾期 | |

## 2. 状态与口径

- 下次到期由上次完成加周期派生，不手工改。
- 逾期 = 到期日早于当前日期且未完成。
- 完成时写上次完成时间并滚动下一次到期。

## 3. 与其它主档的关系

- 设备档案：`deviceCode` 为外键。
- 故障工单：修复后可生成维保计划。
- 设备利用率：维保停机计入故障小时。

## 4. 原型衔接建议

- 页面：`resource/maintenance-plan`，list 骨架，按到期状态页签。
- 表单抽屉：设备编码、维保类型、周期天数、下次到期、供应商；动作「完成维保」。
