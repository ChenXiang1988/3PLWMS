# 调拨申请单（数据字典）

> 实体：调拨申请单｜对应原型页面：货灵ERP「调拨申请」、货灵运营中台管理端「跨仓调拨」｜字段真值源

约定：货主发起跨仓调拨申请，运营中台受理审批后拆成出仓与入仓两端作业单据，在途库存单列。申请单本身不执行仓内作业，也不直接改写库存台账。

## 1. 申请标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `transferNo` | 调拨单号 | String | 24 | 是 | 系统生成，全局唯一 | 列表主键 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 按登录身份限定 |
| `fromWarehouse` | 调出仓库 | String | 20 | 是 | 关联仓库主档 | |
| `toWarehouse` | 调入仓库 | String | 20 | 是 | 关联仓库主档，不得等于调出仓 | |
| `skuCode` | 商品编码 | String | 20 | 是 | 关联商品主档 | |
| `batchNo` | 批次号 | String | 24 | 否 | 关联批次效期 | |
| `planQty` | 计划数量 | Int | 12 | 是 | 货主填写 | 右对齐数字列 |
| `transferStatus` | 调拨状态 | Enum | 20 | 是 | 见状态枚举 | 页签依据 |
| `submitTime` | 提交时间 | Datetime | — | 是 | 提交时刻 | |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `draft` | 草稿 | `disabled` |
| `pendingConfirm` | 待受理 | `pending` |
| `dispatched` | 已分发 | `enabled` |
| `inTransit` | 在途 | `pending` |
| `finished` | 已完成 | `disabled` |
| `cancelled` | 已取消 | `disabled` |

## 2. 受理与在途

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `outDocNo` | 出仓单据号 | String | 24 | 否 | 关联出库单据 | 受理后写入 |
| `inDocNo` | 入仓单据号 | String | 24 | 否 | 关联入库单据 | 受理后写入 |
| `inTransitQty` | 在途数量 | Int | 12 | 否 | 出仓已发、入仓未收 | |
| `receivedQty` | 已收数量 | Int | 12 | 否 | 入仓验收写入 | |
| `reviewer` | 受理人 | String | 30 | 否 | 运营中台账号 | |
| `reviewTime` | 受理时间 | Datetime | — | 否 | 运营中台受理时刻 | |
| `cancelReason` | 取消原因 | String | 500 | 否 | 未分发前取消必填 | 留痕 |
| `trace` | 操作轨迹 | String | 1000 | 否 | 提交、受理、分发、收货、取消 | 留痕不可删 |

## 3. 与其它主档的关系

- **仓库主档**：调出与调入仓都取仓库主档，仓能力校验在受理环节完成。
- **商品主档**：商品编码取已发布主档，未发布商品不可发起调拨。
- **库存台账**：出仓与入仓分别写台账流水，在途数量不计入任一端可用库存。
- **委托单**：调拨申请是委托单的一种业务类型，统一在委托单据中心可查。

## 4. 原型衔接建议

- 货灵ERP `owner/transfer-apply-list` 页签取调拨状态枚举；工具条「新增」「提交」「撤回」，表单抽屉录入调出调入仓、商品与数量。
- 运营中台 `network/transfer-order` 展示受理与在途进度，审批动作归运营中台，不在货灵ERP出现。
- 未分发前可撤回并留痕；已分发或已产生在途数量时不可逆，按取消或新申请处理。
- 列表货主维度由登录身份限定，不提供货主筛选。
