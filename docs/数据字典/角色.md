# 角色（数据字典）

> 实体：角色｜对应原型页面：货灵ERP「角色权限」、货灵运营中台管理端「角色权限」｜字段真值源

约定：角色 = 菜单权限 + 动作权限 + 数据范围。角色分系统内置与自定义，按归属分运营方、货主、仓内三类；货主角色只在货灵ERP建，运营方与仓内角色只在货灵运营中台管理端建；一个账号一个主角色，需要多角色时新建组合角色，不叠加。角色停用后不能再分配给新账号，已有账号保留原权限直到改派。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `roleCode` | 角色编码 | String | 20 | 是 | 本部署内唯一 | `RO` + 4 位序号；不可改 |
| `roleName` | 角色名称 | String | 50 | 是 | 本部署内唯一 | 列表主键展示 |
| `roleType` | 角色类型 | Enum | 20 | 是 | 系统内置 / 自定义 | 内置不可删除 |
| `roleScope` | 角色归属 | Enum | 20 | 是 | 运营方 / 货主 / 仓内 | 决定可分配账号范围 |
| `roleStatus` | 角色状态 | Enum | 20 | 是 | 启用 / 停用 | 页签依据 |
| `description` | 角色说明 | String | 200 | 否 | 自由文本 | 不进列表列 |
| `createTime` | 创建时间 | Datetime | — | 是 | 系统写入 | |
| `updateTime` | 更新时间 | Datetime | — | 是 | 权限或状态变更时写入 | |

## 2. 权限与数据范围

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `menuScope` | 菜单权限 | multi | — | 是 | 一级菜单名 | 至少一项 |
| `actionScope` | 动作权限 | multi | — | 是 | 查看 / 新增 / 编辑 / 停用 / 导出 / 审核 / 发货 / 退款 | 页面内按钮依据 |
| `dataScope` | 数据范围 | multi | — | 是 | 全部货主 / 指定货主 / 全部仓库 / 指定仓库 / 全部业务 / 指定业务 | 角色级范围，账号可再收窄 |
| `pageScope` | 页面权限 | multi | — | 否 | 注册表页 key | 页面级权限，原型按一级菜单聚合 |
| `accountCount` | 账号数 | Int | — | 是 | 启用账号数，派生 | 列表列 |
| `permissionCount` | 权限数 | Int | — | 是 | 菜单与动作去重后的数量，派生 | 列表列 |

## 3. 与其它主档的关系

- **账号**：账号的 `roleCode` 指向本档；角色停用前先把启用账号改派到其它角色。
- **货主主档**：货主角色的 `roleScope=owner`，只能用于本货主账号；运营中台创建货主角色时须绑定货主。
- **仓库主档**：仓内角色的 `roleScope=warehouse`，数据范围至少指定一个仓库。
- **操作日志**：角色新增、权限变更、停用与复制都写日志，日志不改写本档。

## 4. 原型衔接建议

- 货灵运营中台管理端 `system/role-list`（list）：角色名称、角色编码、角色类型、角色归属、账号数、权限数、数据范围、状态、更新时间；工具条新增、复制、导出；行操作编辑、配置权限、停用。
- 货灵ERP `owner/role-list`（list）：只列货主角色；菜单权限只出现货主可用段，数据范围固定本货主。
- 角色权限抽屉用 `checks` 多选：角色信息 → 菜单权限 → 动作权限 → 数据范围；保存后列表权限数与状态同步。
- 内置角色不可删除、不可改编码与归属；自定义角色可停用、可复制，不物理删除。
