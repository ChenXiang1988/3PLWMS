# 库存台账（数据字典）

> 实体：库存台账｜对应原型页面：货灵ERP「本货主库存台账」、货灵WMS「库存台账」｜字段真值源

约定：台账是库存变动的流水记录，只追加不改写。库存粒度为「货主＋商品＋批次＋库位」，在库、可用、冻结、锁定四类数量由台账派生，不另存一份真相。

## 3. ATP 派生口径

ATP（可承诺库存）不另存一张账，按「货主 × 商品 × 仓库」从台账与订单占用派生：

`ATP = 可用数量 − 未发订单占用 + 在途入库`

- 可用数量：台账派生的在库减冻结、锁定。
- 未发订单占用：已下发未发货、待发货履约单的占用数量。
- 在途入库：已确认未收货的入库计划单数量。
- 数据截止：展示 `atpUpdatedAt`，避免把快照当实时。
- 原型只在库存查询页与订单 360 的 ATP 检查展示演示值，不实现实时计算。

## 4. 与其它主档的关系

- **商品主档**：`skuCode` 多对一；商品档只定义策略，不持有数量。
- **批次效期**：`batchNo` 关联批次，效期状态影响台账可出库数量。
- **库区库位**：`locationCode` 关联库位，移库产生一出一入两条流水。
- **货主主档**：`ownerCode` 决定数据可见范围，跨货主台账不合并展示。

## 5. 原型衔接建议

- 货灵ERP `owner/stock-ledger-list` 与既有 `inventory/ledger-owner-list` 列名逐字取本节字段；筛选按业务类型、单据编号、发生时间。
- 冲正流水与原流水成对展示，原行标「已冲正」但保留可查，不做物理删除。
- 台账页只读，不提供编辑类主操作；导出沿用工具条次操作。
