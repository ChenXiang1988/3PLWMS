# 物流运单（数据字典）

> 实体：物流运单｜对应原型页面：货灵ERP「物流跟踪」、货灵WMS「交接单」｜字段真值源

约定：运单由发货交接产生，货灵ERP只读查看在途节点、签收回单与异常件。运单不持有库存，也不改写出库单据状态以外的数据。

## 3. 与其它主档的关系

- **出库订单**：`sourceDocType=出库订单` 时 `planNo` 关联出库单据，运单只在发货交接后产生。
- **自发货单**：`sourceDocType=自发货单` 时 `sourceDocNo` 取自发货单号，运单号由货主录入，`planNo` 为空。
- **平台备货单**：`sourceDocType=平台备货单` 时 `sourceDocNo` 取备货单号；平台备货不产生消费者运单的，本实体可无记录。
- **交接单**：`handoverNo` 关联货灵WMS交接单，包裹数与承运商取其快照。
- **差异异常单**：异常件登记异常单，货灵ERP在差异与异常协同里确认或申诉。
- **货主主档**：货灵ERP按登录身份限定，只看本货主运单。

## 4. 原型衔接建议

- 货灵ERP `owner/tracking-list` 页签取运单状态五值；列表展示运单号、来源单据类型、来源单号、承运商、包裹数、发货交接时间、运单状态。
- 详情抽屉以时间轴展示在途节点，已签收展示签收人、签收时间与回单号。
- 异常件跳转差异异常单，异常类型逐字取本节枚举。
- 本页只读，不提供发货、签收等仓内作业类主操作；仓发货、自发货与平台备货的运单在同一页可查。
