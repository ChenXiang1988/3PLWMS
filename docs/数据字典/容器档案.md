# 容器档案（数据字典）

> 实体：容器档案｜对应原型页面：作业资源 / 容器档案、容器管理（`resource` 模块）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `containerCode` | 容器编码 | String | 20 | 是 | 全局唯一，业务引用主键 | 建议 `CT` + 5 位序号；不可改 |
| `containerType` | 容器类型 | Enum | — | 是 | 托盘 / 周转箱 / 笼车 / 料箱 | 关联容器类型清单 |
| `spec` | 规格 | String | 50 | 否 | 长宽高或口径描述 | 如「1200×1000mm」 |
| `loadCapacity` | 额定载重 | Decimal(8,2) | — | 否 | 单位千克 | 超重拦截依据 |
| `containerStatus` | 容器状态 | Enum | — | 是 | 空闲 / 在用 / 维修 / 报废 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `idle` | 空闲 | `info` |
| `busy` | 在用 | `enabled` |
| `repairing` | 维修 | `pending` |
| `scrapped` | 报废 | `disabled` |

## 5. 与其它主档的关系

- 仓库主档与库区库位：`warehouseCode` / `zoneCode` / `binCode` 三级定位，容器不单独建库位真相。
- 货主主档：`ownerCode` 只在货主自备容器时有值；共用容器属于仓，不按货主隔离。
- 设备档案：容器是被搬运对象，叉车、AGV 是搬运资源，二者不互相引用。
- 单据：占用中的容器由 `bizNo` 指向单据，随作业完成释放。

## 6. 原型衔接建议

- `resource/container-archive`（仓网管理端，list）：容器编码、容器类型、规格、所属仓库、容器状态、归属货主、购置日期、创建时间。
- `resource/container-list`（单仓端，list）：同上，行按 `warehouseCode` 归属本仓，另可看当前库位与占用单据号。
- 筛选：容器类型、容器状态、所属仓库；状态页签 全部 / 空闲 / 在用 / 维修 / 报废。
