# 同步任务（数据字典）

> 实体：同步任务｜对应原型页面：货灵ERP「同步任务」（`owner` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
同步任务记录一次拉单、回传或售后同步的执行结果。每店队列、平台限流、全局并发上限由产品侧实现，原型只展示任务状态、成功失败数与失败原因。

## 1. 任务标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `taskNo` | 任务号 | String | 24 | 是 | 全局唯一，业务引用主键 | `ST` + 日期 + 4 位流水；不可改 |
| `shopCode` | 店铺编码 | String | 30 | 是 | 关联平台店铺 `shopCode` | 每店一条队列 |
| `syncType` | 同步类型 | Enum | — | 是 | 拉单 / 回传 / 售后 | 见枚举 |
| `triggerType` | 触发方式 | Enum | — | 是 | 定时 / 手动 / 重试 | 定时为默认 |
| `windowStart` | 时间窗起 | Datetime | — | 否 | 本次同步覆盖的起始时间 | 增量拉单用 |
| `windowEnd` | 时间窗止 | Datetime | — | 否 | 本次同步覆盖的结束时间 | 增量拉单用 |
| `taskStatus` | 任务状态 | Enum | — | 是 | 待执行 / 执行中 / 成功 / 部分失败 / 失败 | 见状态枚举 |
| `successCount` | 成功数 | Int | — | 是 | 成功处理的单据数 | 初始 0 |
| `failCount` | 失败数 | Int | — | 是 | 失败的单据数 | 初始 0 |
| `retryCount` | 重试次数 | Int | — | 是 | 已重试次数 | 初始 0 |
| `startTime` | 开始时间 | Datetime | — | 否 | 任务开始时刻 | |
| `endTime` | 结束时间 | Datetime | — | 否 | 任务结束时刻 | 执行中为空 |
| `failReason` | 失败原因 | String | 300 | 否 | 平台报错或校验不通过 | 留痕不可删 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `queued` | 待执行 | `pending` |
| `running` | 执行中 | `info` |
| `success` | 成功 | `enabled` |
| `partial` | 部分失败 | `pending` |
| `failed` | 失败 | `rejected` |

## 2. 游标与重试

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `cursor` | 同步游标 | String | 100 | 否 | 平台分页或时间游标 | 按店铺按类型各存一份 |
| `pageCount` | 分页数 | Int | — | 否 | 本次拉取页数 | 原型可空 |
| `lastSuccessTime` | 最近成功时间 | Datetime | — | 否 | 该店该类型最近成功时刻 | 健康度 |
| `nextRetryTime` | 下次重试时间 | Datetime | — | 否 | 退避后的重试时刻 | 失败时填写 |
| `operator` | 操作人 | String | 30 | 否 | 手动触发或重试的账号 | 定时任务为空 |

## 3. 与其它主档的关系

- 平台店铺：`shopCode` 外键，任务按店铺隔离；授权过期时任务失败原因回指平台店铺授权状态。
- 平台订单：拉单成功写平台订单，幂等键为 `shopCode + platformOrderNo`，重复拉取只更新不新增。
- 平台售后单：售后同步成功写平台售后单，幂等键为 `platformAfterSaleNo`。
- 物流运单：回传任务回写运单号与发货时间，失败进入重试，不改写已发货履约单。
- 平台限流：按平台声明按应用、按店铺或按接口，不在页面展示限流参数。

## 4. 原型衔接建议

- `owner/sync-task-list`（货灵ERP，list）：任务号、店铺、同步类型、触发方式、时间窗、任务状态、成功数、失败数、失败原因、重试次数。
- 状态页签：全部 / 待执行 / 执行中 / 成功 / 部分失败 / 失败；筛选：店铺、同步类型、触发方式。
- 工具条：重试、导出；行详情展示游标、最近成功时间、下次重试时间与失败明细。
- 列表按登录货主限定，不提供货主筛选；只展示任务结果，不在页面暴露队列与限流实现。
