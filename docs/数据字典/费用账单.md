# 费用账单（数据字典）

> 实体：费用账单｜对应原型页面：货灵ERP「本货主费用账单」「费用规则查看」、货灵运营中台管理端「费用账单」「费用规则」｜字段真值源

约定：账单按货主与账期汇总，同一货主同一账期可按账单类型拆多张；运营中台生成、调整与出账，货灵ERP只读查看明细、确认、提出对账申诉。确认与申诉只改账单状态与留痕，不改写已出账明细。

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `pending` | 待确认 | `pending` |
| `disputed` | 已申诉 | `info` |
| `confirmed` | 已确认 | `enabled` |
| `closed` | 已关闭 | `disabled` |

开票与收款不再作为账单状态：开票状态由结算单派生；收款状态只在发票与收款实体维护。账单状态与开票状态正交。

## 4. 与其它主档的关系

- **货主主档**：计费口径、结算周期、信用额度取货主主档，本表不复制。
- **服务目录与报价**：`feeItem` 取项目名称，单价与税率取报价版本快照；报价是价格的唯一来源。
- **费用规则**：`ruleNo` + `ruleVersion` 固定出账时的计费口径与单价，规则变更不回溯已出账明细。
- **结算单**：一张结算单汇总同一货主同一账期的多张账单；账单 `invoiceStatus` 由结算单派生。
- **发票与收款**：发票通过结算单关联，收款状态只在发票维护，账单不重复记录。
- **差异异常单**：对账申诉落差异异常单，处理结果回写申诉状态。
- **库存台账与作业单据**：计费量来源于台账与作业单据，不另建第二份作业真相。

## 5. 原型衔接

- 中台 `billing/bill-list`：页签取账单状态四值；列含开票状态、差异金额、生成时间；抽屉为账单头 + 明细，动作确认、申诉处理、账单调整。
- 货灵ERP `billing/bill-owner-list`：一行一张账单头；页签与中台逐字一致；抽屉看明细；动作确认与异议申诉，申诉落 `disputed`。
- `billing/rate-owner-list` 只读展示费用项目、计费单位、计费周期、参考单价与生效期，不提供编辑类主操作。
- 金额列统一写「￥」加两位小数，右对齐；差异金额由 `totalAmount - confirmedAmount` 派生。
- 账单头与明细的演示数据必须由同一组明细汇总，禁止两端各写一套金额。

## 6. 2026-11-12 口径调整

- 账单拆为账单头与账单明细两级，`billNo` 在两端同号同额。
- 账单状态收敛为待确认 / 已申诉 / 已确认 / 已关闭；已开票、已付款改由结算单与发票承载。
- 新增 `invoiceStatus` 派生字段、`differenceAmount` 派生字段、`ruleVersion` 与 `snapshotDate` 明细留痕字段。
- `feeItem` 改为引用服务目录项目名称，不再使用固化的五项枚举。
