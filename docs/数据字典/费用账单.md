# 费用账单（数据字典）

> 实体：费用账单｜对应原型页面：货灵ERP「本货主费用账单」「费用规则查看」、货灵运营中台管理端「费用账单」｜字段真值源

约定：账单按货主与账期汇总，运营中台生成与审核调整，货灵ERP只读查看明细、确认、提出对账申诉。确认与申诉只改变账单状态与留痕，不改写已出账的费用明细。

## 3. 与其它主档的关系

- **货主主档**：计费口径、结算周期、信用额度取货主主档，本表不复制。
- **费用规则**：单价与计费方式取规则表快照，规则变更不回溯已出账明细。
- **差异异常单**：对账申诉落差异异常单，处理结果回写申诉状态。
- **库存台账与作业单据**：计费量来源于台账与作业单据，不另建第二份作业真相。

## 4. 原型衔接建议

- 货灵ERP `billing/bill-owner-list` 页签取账单状态五值；工具条增加「确认」与「对账申诉」，确认抽屉展示明细，申诉抽屉录入原因。
- `billing/rate-owner-list` 只读展示费用项目、计费方式、单价与生效日期，不提供编辑类主操作。
- 已确认及之后的状态不再出现「确认」入口；申诉只在待确认状态可发起，已处理或已驳回留痕。
- 金额列统一写「￥」加两位小数，右对齐。
