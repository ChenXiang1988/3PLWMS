# 子账号（数据字典）

> 实体：账号（子账号，按产品域分）｜对应原型页面：货灵ERP「子账号与权限」「角色权限」「操作日志」、货灵运营中台管理端「账号管理」「角色权限」「操作日志」｜字段真值源

约定：账号按产品域分两套管理边界：货灵ERP货主域、货灵运营中台管理端运营域。同一部署内并存，但登录、账号、角色与日志互不越界；货主账号只在货灵ERP建，运营方与仓内账号只在运营中台建。角色、菜单权限、动作权限与数据范围决定可访问的页面与仓库，操作日志只追加不改写。

## 3. 与其它主档的关系

- **角色**：`roleCode` 外键，角色决定菜单、动作与数据范围；角色停用后账号保留原权限直到改派。
- **货主主档**：货主账号的 `ownerCode` 必填，货主管理员只管理本货主账号。
- **仓库主档**：仓内账号的 `warehouseCode` 必填，`visibleWarehouses` 取仓库主档编码，不复制仓库属性。
- **人员档案**：仓内人员归 `resource` 模块，人员档案的 `account` 指向本档；无账号的人员只作台账。
- **跨域关系**：同一自然人如果既要用货灵ERP又要进货灵运营中台管理端，开两个账号；`accountDomain` 不同，不共享登录与角色。
- **操作日志**：账号的新增、状态变更、角色变更、重置密码与登录都写日志，日志不改写本档；货灵ERP日志与运营中台日志按域分页。

## 4. 原型衔接建议

- 货灵ERP `owner/account-list`（list）：账号、姓名、账号类型、角色、可见仓库范围、可见业务范围、账号状态、最近登录、操作；工具条新增、导出；行操作编辑、停用、重置密码、查看日志。
- 货灵ERP `owner/role-owner-list`（list）：本货主自定义角色；权限抽屉按菜单、动作、数据范围分组勾选。
- 货灵ERP `owner/audit-owner-log`（list）：本货主账号日志，按模块、动作、时间筛选。
- 货灵运营中台管理端 `system/user-list`（list）：运营方与仓内账号，账号、姓名、账号类型、所属组织、角色、数据范围、账号状态、最近登录；工具条新增、导出；不列 `ow.*` 货主账号。
- 货灵运营中台管理端 `system/role-list`（list）：运营方与仓内角色；角色名称、角色编码、角色类型、角色归属、账号数、权限数、数据范围、状态、更新时间。
- 货灵运营中台管理端 `system/audit-log`（list）：时间、操作人、所属端、模块、动作、对象、结果、IP；只含运营中台、货灵WMS、PDA，不含货灵ERP。
- 所有账号页保持单部署单主体口径；货主账号按登录货主限定，仓内账号按仓库限定；跨域不共享账号。
