# 装修区块

## 1. 实体说明

独立站 `site-content` 的页面装修数据。页面以 `pageSchema` 作为编辑、预览、草稿与发布的唯一真相源，发布产物只由 Schema 渲染，不持久化 HTML。

## 2. 页面内容字段

| 字段 key | 类型 | 必填 | 枚举 / 格式 | 默认值 | 校验 / 唯一性 | 来源 | 展示格式 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `contentId` | string | 是 | `CONTENT-<站点>-<栏目>` | — | 全局唯一 | 站点内容 | 内容编码 |
| `siteCode` | string | 是 | 站点编码 | — | 引用站点主档 | 站点主档 | 站点编码 |
| `title` | string | 是 | — | — | 1~80 字 | 内容编辑 | 内容标题 |
| `columnName` | enum | 是 | 首页 / 品牌故事 / 门店网点 / 站点商品 | — | 与站点栏目一致 | 站点内容 | 栏目 |
| `contentType` | enum | 是 | 页面 / 图文 / 轮播 | — | 与页面模板一致 | 站点内容 | 内容类型 |
| `status` | enum | 是 | 草稿 / 待发布 / 已发布 / 已下线 | 草稿 | 按发布动作流转 | 站点内容 | 内容状态 |
| `publishedVersion` | string | 否 | `v主版本.次版本.修订号` | — | 发布成功生成 | 版本记录 | 发布版本 |
| `publisher` | string | 否 | 成员姓名 | — | 发布时写入 | 成员与权限 | 发布人 |
| `publishAt` | datetime | 否 | `YYYY-MM-DD HH:mm` | — | 发布成功写入 | 发布动作 | 发布时间 |
| `permissions` | object | 是 | 查看 / 编辑 / 删除 / 发布 / 区块级操作 | — | 按成员权限计算 | 成员与权限 | 操作能力 |

## 3. 页面 Schema 字段

| 字段 key | 类型 | 必填 | 枚举 / 格式 | 默认值 | 校验 / 唯一性 | 来源 | 展示格式 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `schemaVersion` | string | 是 | `1.0` | `1.0` | 编辑器兼容版本 | 系统 | Schema 版本 |
| `root` | string | 是 | 根节点 ID | `page-root` | 当前页面唯一 | 系统 | 根节点 |
| `blocks` | array | 是 | 区块实例数组 | `[]` | `id` 在页面内唯一，按数组顺序渲染 | 编辑器 | 区块树 |
| `links` | array | 否 | 页面内链接数组 | `[]` | 链接 ID 在页面内唯一 | 编辑器 | 链接目标 |
| `responsive` | object | 是 | `desktop` / `mobile` | `{}` | 只允许终端覆盖配置，不复制 Schema | 编辑器 | 终端配置 |

## 4. 区块实例字段

| 字段 key | 类型 | 必填 | 枚举 / 格式 | 默认值 | 校验 / 唯一性 | 来源 | 展示格式 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `id` | string | 是 | 页面内区块 ID | — | 页面内唯一 | 编辑器 | 区块 ID |
| `type` | enum | 是 | carousel / richText / page / productGrid / categoryNav / coupon | — | 必须存在区块定义 | 区块库 | 区块名称 |
| `props` | object | 是 | 由区块字段定义决定 | 区块默认值 | 必填字段与字段类型校验 | 属性面板 | 区块属性 |
| `responsive` | object | 是 | `desktop` / `mobile` | `{}` | 只保存差异配置 | 属性面板 | 终端差异 |
| `visibility` | object | 是 | 终端布尔值 | `true` | 至少保留一个终端可见 | 属性面板 | 可见性 |
| `binding` | object | 否 | 站点商品等引用关系 | — | 只允许引用主档，不复制价格库存 | 数据绑定 | 数据来源 |

首期区块字段：

| 区块类型 | 必填字段 | 可选字段 | 数据 / 链接规则 |
| --- | --- | --- | --- |
| `carousel` 轮播 | `title` | `link` | 多张素材按顺序展示，跳转使用站点路由 |
| `richText` 图文 | `title`、`body` | — | 正文长度由页面校验 |
| `page` 页面 | `title` | `link` | 只能跳转站点内页面 |
| `productGrid` 商品网格 | `siteSkuCodes` | `title`、`columns` | 引用 `site-sku`；商品价格、库存从站点商品主档读取 |
| `categoryNav` 分类导航 | `categories` | `title` | 分类值必须属于站点可用分类 |
| `coupon` 优惠券 | `title`、`couponCode` | `link` | 优惠券编码引用营销主档，领取失败保留错误反馈 |

## 5. 数据绑定与链接

| 字段 | 类型 | 必填 | 口径 |
| --- | --- | --- | --- |
| `binding.type` | enum | 是 | `site-sku` / `site-category` / `coupon` |
| `binding.ref` | string | 是 | 站点编码或业务主档编码 |
| `binding.fields` | array | 是 | 允许展示的字段清单 | 
| `links[].id` | string | 是 | 页面内唯一链接 ID |
| `links[].targetType` | enum | 是 | `site-route` / `site-sku` / `coupon` |
| `links[].target` | string | 是 | 站点内路由或主档编码 |

## 6. 版本记录字段

| 字段 | 类型 | 必填 | 枚举 / 格式 | 口径 |
| --- | --- | --- | --- | --- |
| `version` | string | 是 | `v主版本.次版本.修订号` | 发布成功生成 |
| `status` | enum | 是 | 草稿 / 待发布 / 已发布 / 已下线 | 与内容状态一致 |
| `editor` | string | 是 | 成员姓名 | 保存或发布动作写入 |
| `updatedAt` | datetime | 是 | `YYYY-MM-DD HH:mm` | 动作完成时间 |
| `sourceVersion` | string | 否 | 版本号 | 回滚或重新发布来源 |
| `errorReason` | string | 否 | — | 发布失败原因，不清空草稿 |

## 7. 与其它主档的关系

- 站点主档：`siteCode` 关联站点主档；内容只属于一个站点，站点停用时已发布内容不再同步到前台。
- 站点商品：`productGrid.binding` 通过站点编码与 `siteSkuCodes` 引用站点商品主档；价格、库存和商品名称不在 Schema 中复制。
- 站点发布：`site-channel` 按页面版本同步 Web、APP、微信小程序、支付宝小程序的发布任务与结果，不在页面 Schema 中重复保存端状态。
- 站点成员：`permissions` 关联成员与角色权限；页面级发布权限与区块级操作权限由成员权限页维护。
- 站点路由：`links[].target` 只能指向当前站点可用页面或主档编码，删除目标前需提示受影响内容。

## 8. 校验与权限

发布前校验 Schema 版本、根节点、区块类型、必填字段、终端配置、站点内链接、数据绑定和成员发布权限。查看权限只允许预览；编辑权限控制属性与区块操作；删除权限控制删除区块；发布权限控制保存并发布、下线和重新发布。校验失败时保留未保存 Schema，不产生发布版本。

## 9. 原型衔接

- `prototypes/site/pages/site-content.mjs`：列表、编辑入口、装修抽屉。
- `prototypes/site/data/site-content.json`：内容行、Schema、版本、权限演示数据。
- `prototypes/site/pages/site-channel.mjs`：站点与 Web、APP、微信小程序、支付宝小程序的发布状态。
- `prototypes/site/pages/site-member.mjs`：成员与页面、区块级权限入口。
