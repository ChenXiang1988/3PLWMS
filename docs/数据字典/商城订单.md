# 商城订单（数据字典）

> 实体：商城订单｜对应原型页面：仓网管理 / 商城管理（`mall-admin` 模块，仓网管理端）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
商城订单是采购方在前台下单产生的订单，履约落到出库订单，不在商城侧重复建模仓储作业。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `orderNo` | 订单编号 | String | 24 | 是 | 全局唯一，业务引用主键 | `MO` + 日期 + 4 位流水 |
| `account` | 下单账号 | String | 50 | 是 | 采购方登录账号 | 列表列 |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 订单只含一家货主的商品 |
| `orderAmount` | 订单金额 | Decimal(12,2) | — | 是 | 单位元，两位小数 | 列表列 |
| `orderStatus` | 订单状态 | Enum | — | 是 | 待付款 / 待发货 / 已发货 / 已完成 / 已取消 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `unpaid` | 待付款 | `pending` |
| `unshipped` | 待发货 | `info` |
| `shipped` | 已发货 | `enabled` |
| `finished` | 已完成 | `disabled` |
| `cancelled` | 已取消 | `disabled` |

## 2. 履约与收货

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `obNo` | 履约出库单号 | String | 24 | 否 | 关联出库订单 `soNo` | 待发货时为空 |
| `receiverName` | 收货方 | String | 100 | 是 | 收货单位或个人 | 前台下单填写 |
| `receiverAddress` | 收货地址 | String | 300 | 是 | 省市区与详细地址 | 前台下单填写 |
| `carrierName` | 承运商 | String | 100 | 否 | 关联承运商主档 | 由出库订单回写 |

## 3. 系统字段

| 字段 key | 中文名 | 类型 | 必填 | 取值 / 口径 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `createTime` | 下单时间 | Datetime | 是 | 系统写入 | 列表列 |
| `payTime` | 付款时间 | Datetime | 否 | 支付成功后写入 | |
| `shipTime` | 发货时间 | Datetime | 否 | 出库交接后写入 | |

## 4. 与其它主档的关系

- 货主主档：`ownerName` 外键，订单商品只来自该货主的店铺。
- 商城商品：订单行取商城商品的单价与在仓现货，下单后扣减可用数量。
- 出库订单：`obNo` 指向履约出库单，仓储作业在单仓端的出库订单里执行。
- 承运商主档：`carrierName` 由履约出库单回写。

## 5. 原型衔接建议

- `mall-admin/mall-order-list`（仓网管理端，list）：订单编号、下单账号、订单金额、履约出库单号、订单状态、下单时间。
- 筛选：货主、订单状态、订单编号；状态页签 全部 / 待付款 / 待发货 / 已发货 / 已完成 / 已取消。
