# 商城订单（数据字典）

> 实体：商城订单｜对应原型页面：仓网管理 / 商城管理（`mall-admin` 模块，货灵运营中台管理端）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
商城订单是买家货主在前台从别的货主店铺下单产生的订单，履约落到出库订单，不在商城侧重复建模仓储作业。一张订单只含一家店铺、一个卖家货主的商品；买家货主与卖家货主不得相同，不允许自买自卖。买家从不同店铺加购时按店铺拆成多张订单。货只发外部收货地址，不做仓内货权转移。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `orderNo` | 订单编号 | String | 24 | 是 | 全局唯一，业务引用主键 | `MO` + 日期 + 4 位流水 |
| `account` | 下单账号 | String | 50 | 是 | 买家货主的登录账号 | 列表列；一个账号绑定一家货主 |
| `buyerOwnerName` | 买家货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 下单方归属，按登录身份写入 |
| `ownerName` | 卖家货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 店铺归属货主；与 `buyerOwnerName` 不得相同 |
| `shopCode` | 店铺编码 | String | 20 | 是 | 关联店铺 `shopCode` | 一张订单只对应一家店铺 |
| `orderAmount` | 订单金额 | Decimal(12,2) | — | 是 | 单位元，两位小数 | 列表列 |
| `orderStatus` | 订单状态 | Enum | — | 是 | 待付款 / 待发货 / 部分发货 / 已发货 / 已完成 / 已取消 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `unpaid` | 待付款 | `pending` |
| `unshipped` | 待发货 | `info` |
| `partialShipped` | 部分发货 | `pending` |
| `shipped` | 已发货 | `enabled` |
| `finished` | 已完成 | `disabled` |
| `cancelled` | 已取消 | `disabled` |

## 2. 履约与收货

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `obNo` | 主履约单号 | String | 24 | 否 | 首张履约单的执行单号；仓发货为出库执行单 `planNo` | 待付款时为空；一对多，全部履约单见履约单视图 |
| `fulfillmentCount` | 履约单数 | Int | — | 是 | 本订单已生成的履约单数，初始 0 | 由履约单派生；部分发货时大于 1 |
| `receiverName` | 收货方 | String | 100 | 是 | 收货单位或个人 | 前台下单填写 |
| `receiverPhone` | 联系电话 | String | 30 | 是 | 11 位手机号或座机 | 前台下单填写；出库订单自动带入 |
| `receiverAddress` | 收货地址 | String | 300 | 是 | 外部收货地址，省市区与详细地址 | 前台下单填写；不填本部署仓库地址，不生成仓内过户单 |
| `carrierName` | 承运商 | String | 100 | 否 | 关联承运商主档 | 由出库订单回写 |

## 4. 订单拆分与三处校验

| 校验点 | 触发条件 | 处理动作 | 归宿 |
| --- | --- | --- | --- |
| 自买自卖 | 店铺 `ownerName` 等于 `buyerOwnerName` | 拦截加购、结算、提交，提示不允许买自己的货 | 退回选货或结算页 |
| 拆单 | 进货单行跨多家店铺 | 按店铺货主分组成多张订单，分别填收货信息、分别算金额 | 分别生成 `orderNo` 与 `obNo` |
| 收货范围 | 地址填本部署仓库地址 | 拦截并提示只发外部收货地址 | 退回结算页补录 |
| 可用量 | 提交时库存不足、商品已下架或效期禁售 | 拦截提交并登记原因 | 退回结算页改量 |
| 重复提交 | 同一订单号再次提交 | 幂等拦截，不生成第二张单 | 保留原订单 |

## 5. 与出库订单的状态映射

| 商城订单状态 | 触发 | 出库订单单据状态 | `obNo` | 可逆向 |
| --- | --- | --- | --- | --- |
| 待付款 | 提交订单 | 无出库单 | 空 | 可取消至已取消 |
| 待发货 | 支付成功，自动生成出库订单 | 待处理 → 进行中 | 已回写首张 | 可取消，触发出库单取消与返仓 |
| 部分发货 | 一张出库单已交接，仍有履约单未完成 | 已完成为主，其余进行中 | 首张已回写 | 未发部分可继续履约或取消；已发部分不可撤回 |
| 已发货 | 全部履约单交接完成 | 全部已完成 | 首张已回写 | 不可取消，只能走退货退仓 |
| 已完成 | 签收或超时确认 | 全部已完成 | 首张已回写 | 不可逆终态 |
| 已取消 | 待付款或待发货时取消 | 已取消或无出库单 | 视取消时点 | 不可逆终态 |

一个商城订单可以拆多张出库单：部分发货时停在「部分发货」，`obNo` 只存首张主履约单号，全部履约单见履约单视图。拆分与部分发货不改变「只发外部收货地址、只走仓发货」的既有约束。

出库订单进「异常待处理」时，商城订单停在「待发货」并提示，不自行跳到已发货或已取消；异常处置完回「进行中」继续履约。取消与退货的留痕按 `出库订单.md`：未拣货可直接取消，已拣货未交接要返仓回上架并释放锁库，已交接只能走退货退仓生成逆向入库单。已完成与已取消是终态，只能新建逆向单据，原单据行、任务行、扫码原值、批次与时间戳不物理删除。

## 6. 与其它主档的关系

- 货主主档：`ownerName`（卖家货主）与 `buyerOwnerName`（买家货主）都是外键，两者不得相同；买家角色登录后默认具备，店主角色由是否开通店铺派生，不落成主档字段。
- 店铺：`shopCode` 外键，一张订单只来自一家店铺，店铺货主即 `ownerName`。
- 商城商品：订单行取商城商品的单价与在仓现货，下单后扣减可用数量。
- 履约单：一个商城订单对应多张履约单，`obNo` 只存首张主履约单号；履约单记录每次发货的执行单号、包裹与运单，全部完成才转已发货。
- 出库订单：`sourceDocType` 为商城订单、`sourceDocNo` 为 `orderNo`；收货信息自动带入，仓储作业在货灵WMS的出库订单里执行。
- 承运商主档：`carrierName` 由履约出库单回写。

## 7. 原型衔接建议

- `mall-admin/mall-order-list`（货灵运营中台管理端，list）：订单编号、下单账号、订单金额、履约出库单号、订单状态、下单时间；运营方全局视图与审核，不代货主操作。
- 货灵ERP店主侧（拟名待确认，list）：本店铺订单、买家货主、订单状态、履约出库单号、下单时间；只读，不带发货动作。
- 货灵商城 `mall/orders`（shop）：我的订单按买家货主过滤，显示订单状态、金额、履约单号。
- 筛选：卖家货主、买家货主、订单状态、订单编号；状态页签 全部 / 待付款 / 待发货 / 已发货 / 已完成 / 已取消。
- 原型页面名与列名须先在 `glossary.md` 登记，登记前不得写进页面。
