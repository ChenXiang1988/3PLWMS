# 承运商主档（数据字典）

> 实体：承运商主档（Carrier）｜对应原型页面：基础资料 / 承运商档案（`base` 模块 `carrier-list`）
> 定位：描述**为 3PL 提供运输服务的承运商**，是出库订单的运力来源；其 `billingMode` 是 3PL 的运输**成本侧**（与仓库主档 `billingBasis` 向货主收的方向不同）。
> 本文件是字段真值源；生成原型页面时列名与取值逐字取自本文件，并在 `glossary.md` 登记。
> 示例模拟数据：[承运商主档-示例数据.md](samples/承运商主档-示例数据.md)（CR001~003，`serviceWarehouses` 指向 WH0001~WH0004）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。

约定：
- 必填：是=创建时不可为空；否=可空。
- 枚举（Enum）：固定取值集合，原型中以 `select` 呈现，首项「全部」。
- 多值（multi）：可多选，存储为数组，原型用逗号拼接展示。
- 关联：指向其它主档的外键，原型列展示其「名称」。

## 7. 与其它主档的关系

- **仓库主档**：`serviceWarehouses` 多对多指向 `仓库主档.warehouseCode`，标识可揽收的仓库；本档不要求仓库反向引用。
- **出库订单**：出库分配承运商并回写运单号 / 轨迹（`outbound` 模块 `out-plan-list`）；`carrierType` / `supportedTempZone` 约束可承接的订单。
- **货主主档**：经出库订单间接关联；货主可指定偏好承运商，最终以承运商服务范围为准。
- **计费方向**：`billingMode` 是 3PL 的运输**成本侧**；与 `仓库主档.billingBasis`（向货主收）方向相反，勿混。
