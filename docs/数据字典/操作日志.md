# 操作日志（数据字典）

> 实体：操作日志｜对应原型页面：货灵ERP「操作日志」、货灵运营中台管理端「操作日志」｜字段真值源

约定：操作日志只追加，不提供删除与修改入口；成功与失败都记录，失败写原因。货主账号只看本货主日志；运营中台「账号与权限 → 操作日志」只看运营中台、货灵WMS、PDA，不含货灵ERP；跨货主 ERP 审计走「ERP 运营 → 全局审计」，两页分开。货灵WMS与 PDA 不建日志页。

## 1. 标识与操作者

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `logNo` | 日志编号 | String | 24 | 是 | 本部署内唯一 | `LG` + 日期 + 4 位流水；不可改 |
| `logTime` | 操作时间 | Datetime | — | 是 | 系统写入 | 列表列 |
| `operator` | 操作人 | String | 30 | 是 | 关联账号 `accountId` | 列表列 |
| `operatorName` | 操作人姓名 | String | 30 | 是 | 取账号姓名 | 列表列 |
| `endName` | 所属端 | Enum | 20 | 是 | 货灵ERP / 货灵运营中台管理端 / 货灵WMS / PDA 作业端 / 货灵商城 | 列表列 |
| `moduleName` | 模块 | String | 50 | 是 | 一级菜单或模块名 | 列表列 |
| `actionName` | 动作 | String | 50 | 是 | 登录 / 退出 / 新增 / 编辑 / 启用 / 冻结 / 解冻 / 停用 / 重置密码 / 角色变更 / 权限变更 / 导出 / 审核 / 发货 / 退款 / 代维 | 列表列 |
| `ip` | IP | String | 45 | 否 | IPv4 或 IPv6 | 列表列 |

## 2. 对象与结果

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `objectType` | 对象类型 | String | 30 | 否 | 账号 / 角色 / 订单 / 履约单 / 出库计划单 / 售后单 | 业务对象 |
| `objectNo` | 对象编号 | String | 40 | 否 | 业务主键 | 追溯入口 |
| `result` | 操作结果 | Enum | 10 | 是 | 成功 / 失败 | 见结果枚举 |
| `failReason` | 失败原因 | String | 300 | 否 | 校验失败、权限不足、接口超时等 | 失败时必填 |
| `detail` | 操作详情 | String | 1000 | 否 | 变更前后值或操作摘要 | 详情抽屉 |

### 结果枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `success` | 成功 | `enabled` |
| `failed` | 失败 | `rejected` |

## 3. 与其它主档的关系

- **账号**：`operator` 指向 `子账号.accountId`；账号停用后历史日志保留。
- **角色**：角色变更与权限变更日志的 `objectType=角色`，`objectNo=roleCode`。
- **业务单据**：审核、发货、退款日志的 `objectNo` 指向业务单据主键，不改写业务单据状态。
- **货灵商城**：买家与店主操作只记登录、下单、售后，不记账号管理类动作。

## 4. 原型衔接建议

- 货灵运营中台管理端 `system/audit-log`（list）：时间、操作人、所属端、模块、动作、对象、结果、IP；筛选端、模块、动作、时间范围。
- 货灵ERP `owner/audit-log`（list）：只出现本货主账号的操作日志；列同上。
- 行详情抽屉取日志编号、操作时间、操作人、端、模块、动作、对象、结果、失败原因、详情。
- 日志页不提供删除、清空与导出全部；导出动作本身也写日志。
