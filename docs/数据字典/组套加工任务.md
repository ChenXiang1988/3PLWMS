# 组套加工任务（数据字典）

> 实体：组套加工任务（Kitting Task）｜对应原型页面：库内作业 / 组套与库内加工（`warehouse` 模块 `kitting-task`）
> 定位：组套、拆套、换标、贴标与返工的库内加工任务，按源商品与目标商品记录耗用。

## 1. 加工字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `taskNo` | 任务号 | String | 24 | 是 | `KT` + 日期 + 流水 | 全局唯一 |
| `taskType` | 加工类型 | Enum | — | 是 | 组套 / 拆套 / 换标 / 贴标 / 返工 | |
| `ownerCode` | 货主 | String | 20 | 是 | 关联货主主档 | |
| `srcSkuCode` | 源商品 | String | 24 | 是 | 关联商品主档 | |
| `destSkuCode` | 目标商品 | String | 24 | 否 | 组套或换标后商品 | |
| `qty` | 数量 | Decimal(14,3) | — | 是 | 产出数量 | |
| `consumeQty` | 耗用数量 | Decimal(14,3) | — | 是 | 源商品耗用 | |
| `teamCode` | 班组 | String | 20 | 否 | 执行班组 | |
| `kittingStatus` | 加工状态 | Enum | — | 是 | 待开始 / 进行中 / 已完成 / 已取消 | |

## 2. 状态与口径

- 组套与拆套按 BOM 校验耗用；换标与贴标不改库存数量。
- 完成后按目标商品过账，源商品扣减；已完成后不可撤销，只能反向加工。
- 返工耗用与产出按同一商品记录。

## 3. 与其它主档的关系

- 商品主档：`srcSkuCode`、`destSkuCode` 为外键。
- 班组档案：`teamCode` 为外键。
- 库存台账：加工完成写一笔调整流水。

## 4. 原型衔接建议

- 页面：`warehouse/kitting-task`，list 骨架，按状态页签。
- 表单抽屉：加工类型、源商品、目标商品、数量、耗用数量、班组；动作「开始」「完成」。
