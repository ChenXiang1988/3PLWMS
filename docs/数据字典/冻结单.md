# 冻结单（数据字典）

> 实体：冻结单（Freeze Order）｜对应原型页面：库内作业 / 冻结与解冻（`warehouse` 模块 `freeze-list`）
> 定位：按商品、批次、库位冻结库存，解冻走审批。

## 1. 冻结字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `freezeNo` | 冻结号 | String | 24 | 是 | `FZ` + 日期 + 流水 | 全局唯一 |
| `ownerCode` | 货主 | String | 20 | 是 | 关联货主主档 | |
| `skuCode` | 商品编码 | String | 24 | 是 | 关联商品主档 | |
| `batchNo` | 批次号 | String | 24 | 否 | | |
| `locationCode` | 库位 | String | 20 | 否 | | |
| `freezeQty` | 冻结数量 | Decimal(14,3) | — | 是 | 不超过可用数量 | |
| `reasonType` | 原因类型 | Enum | — | 是 | 质检待判 / 盘点差异 / 客户要求 / 异常调查 | |
| `reason` | 原因 | String | 200 | 是 | 自由文本 | |
| `freezeStatus` | 冻结状态 | Enum | — | 是 | 已冻结 / 解冻审批中 / 已解冻 | |

## 2. 状态与口径

- 冻结即时生效，可用数量减少；解冻审批通过后释放。
- 冻结数量不得超过当前可用数量。
- 盘点冻结与计划单锁定分开展示，不合并口径。

## 3. 与其它主档的关系

- 商品主档、批次效期、库区库位：三个外键。
- 库存台账：冻结与解冻各写一笔流水。
- 差异异常单：异常调查可关联。

## 4. 原型衔接建议

- 页面：`warehouse/freeze-list`，list 骨架，按状态页签。
- 表单抽屉：货主、商品、批次、库位、冻结数量、原因类型、原因；动作「申请解冻」。
