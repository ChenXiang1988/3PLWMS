# 出库计划单（数据字典）

> 实体：出库计划单｜对应原型页面：货主端「出库计划单」、仓网管理端「出库计划单确认」
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
出库计划单是货主对一批出库货的预约，**一票一仓**，**提交即锁库**。确认生效后系统生成一张出库订单交给仓库执行，执行细节在单仓端，货主只看计划单状态。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `planNo` | 计划单号 | String | 24 | 是 | 全局唯一，业务引用主键 | `OP` + 日期 + 4 位流水；不可改 |
| `bizType` | 出库类型 | Enum | — | 是 | 销售出库 / 调拨出库 / 退货出库 / 加工出库 | 决定默认工序编排 |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | |
| `targetWarehouse` | 目标仓库 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 一票一仓，定在单头；提交后不可改 |
| `planStatus` | 计划单状态 | Enum | — | 是 | 草稿 / 待确认 / 已生效 / 已分发 / 已关闭 | 见状态枚举 |
| `confirmMode` | 确认方式 | Enum | — | 是 | 自动确认 / 人工确认 | 自动确认时提交即生效 |

## 3. 明细行

一张计划单至少一行。行上不带目标仓，仓定在单头。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `lineNo` | 行号 | Int | — | 是 | 单内唯一，从 1 开始 | |
| `skuCode` | 商品编码 | String | 20 | 是 | 关联商品主档 `skuCode` | 只允许本单货主商品 |
| `skuName` | 商品名称 | String | 200 | 是 | 取商品主档 | 展示用 |
| `batchNo` | 批次号 | String | 40 | 否 | 按分配规则选批次 | 效期或批次管理商品填 |
| `planQty` | 计划数量 | Int | — | 是 | 行级计划数量 | 锁定量恒等于本值 |

## 4. 与其它主档的关系

- 货主主档：`ownerName` 外键，计划单归属货主。
- 商品主档：`skuCode` 外键，出库分配规则取主档策略。
- 仓库主档：`targetWarehouse` 单头外键；确认前按该仓校验能力与温区，不通过则不能确认。
- 库存查询与仓位库存：提交时按「商品 × 批次 × 仓」全量校验可用量并冻结。**可用量不足时不允许提交**，提示可锁量与缺口，货主改量或补货后重提；系统不保存部分锁定的记录。计划单不写台账，台账只记变动，冻结体现在冻结数量列。
- 工序单：确认推送后由单仓基于本票生成拣货单、复核单、交接单，计划单与工序单 1:N；工序单回写 `sourcePlans`，计划单派生 `processCount`。锁定量随拣货工序出库扣减，工序单在单仓端流转，货主侧不看单号。
- 释放：草稿删除、计划单关闭、确认被驳回时释放全部锁定，`lockStatus` 转已释放。
- 时效协议：生成订单时按「仓 × 货主 × 出库」取当刻生效的协议，含截单时间，快照 `slaCode`、`slaDueTime`、`slaStatus`。

## 5. 原型衔接建议

- `outbound/plan-owner-list`（货主端，list）：计划单号、计划单状态、出库类型、目标仓库、计划出库日期、品类数、计划数量、锁库状态、创建时间。
- 状态页签：全部 / 草稿 / 待确认 / 已生效 / 已分发 / 已关闭；筛选：出库类型、目标仓库、锁库状态、计划出库日期。
- `outbound/plan-confirm-list`（仓网管理端，list）：计划单号、货主、出库类型、目标仓库、计划出库日期、品类数、计划数量、计划单状态、锁库状态、确认方式、确认时间。
- 工具条：确认、驳回、查看执行单、导出。改仓只在待确认态可做，需先释放锁定再按新仓重锁；确认后执行单已生成，不再允许改仓。
