# 企业资质认证（数据字典）

> 实体：企业资质认证｜对应原型页面：货灵ERP「企业资质认证」、货灵运营中台管理端「认证审批」（`mall-shop` 与 `mall-admin` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
货主在商城开店前要完成企业资质认证，材料是企业营业执照，由货灵运营中台管理端审批。认证结论归货主，一次认证对本货主的商城动作长期生效，不开店也可以先认证。一个货主同一时刻只有一张有效认证单。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `certNo` | 认证单号 | String | 24 | 是 | 全局唯一，业务引用主键 | `EC` + 日期 + 4 位流水 |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 一个货主一张有效认证单 |
| `enterpriseName` | 企业名称 | String | 100 | 是 | 营业执照上的企业全称 | 与货主主档名称一致方可提交 |
| `licenseNo` | 统一社会信用代码 | String | 18 | 是 | 全局唯一 | 重复提交按同一企业拦截 |
| `certStatus` | 认证状态 | Enum | — | 是 | 未认证 / 待审核 / 已通过 / 已驳回 / 已撤回 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `unverified` | 未认证 | `disabled` |
| `pendingReview` | 待审核 | `pending` |
| `approved` | 已通过 | `enabled` |
| `rejectedReview` | 已驳回 | `rejected` |
| `withdrawn` | 已撤回 | `disabled` |

## 2. 认证材料

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `licenseFile` | 营业执照 | String | 200 | 是 | 附件名与存储路径 | 提交认证时上传；缺失或格式不符拦截 |
| `licenseExpiry` | 营业执照有效期 | Date | — | 否 | `YYYY-MM-DD` | 过期需重传 |
| `submitTime` | 提交时间 | Datetime | — | 否 | 系统写入 | 未提交时为空 |

## 3. 审批与留痕

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `reviewer` | 审核人 | String | 50 | 否 | 货灵运营中台管理端操作账号 | 审批后写入 |
| `reviewTime` | 审核时间 | Datetime | — | 否 | 系统写入 | 审批后写入 |
| `reviewRemark` | 审批意见 | String | 300 | 否 | 驳回时必填 | 驳回重传的依据，不随重传删除 |
| `createTime` | 创建时间 | Datetime | — | 是 | 系统写入 | 列表列 |
| `updateTime` | 更新时间 | Datetime | — | 是 | 系统写入 | 每次状态变更写入 |

撤回、驳回重传、反审核都保留原认证单与审批意见，不物理删除。已通过后可反审核回「待审核」，原审批意见留痕；重复提交在「待审核」状态被拦截。

## 4. 与其它主档的关系

- 货主主档：`ownerName` 外键，认证结论归货主，不落货主主档字段，避免认证状态随店铺启停反复改主档。
- 店铺：认证状态「已通过」是开店的前置条件；一个货主当前只能开一个店铺，店铺的 `ownerName` 有唯一约束。
- 商城订单：认证只影响能否开店与上架，不进入订单字段。

## 5. 原型衔接建议

- `mall-shop/shop-cert`（货灵ERP，detail）：认证单号、货主、企业名称、统一社会信用代码、营业执照、认证状态、提交时间、审核人、审核时间、审批意见；未认证时提供上传营业执照与提交认证，已驳回时按审批意见重新提交。
- `mall-admin/shop-cert-audit`（货灵运营中台管理端，list）：认证单号、货主、企业名称、统一社会信用代码、认证状态、提交时间、审核人；状态页签 全部 / 未认证 / 待审核 / 已通过 / 已驳回 / 已撤回。
- 招商页按认证状态分两支：「已通过」可直接开店，其余状态引导到认证页。
