# 批次效期（数据字典）

> 实体：批次效期｜对应原型页面：货灵ERP「批次效期查询」、货灵运营中台管理端「批次效期总览」、货灵WMS「批次效期」｜字段真值源

约定：批次不是商品主档字段，是库存维度；主档只定义是否管理批次、编码规则与属性集合。剩余天数按天重算不落库，效期状态由剩余天数与商品主档的临期预警天数、禁售天数比对得出。

## 1. 批次标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `batchNo` | 批次号 | String | 24 | 是 | 生产日期加到货日期加流水，或沿用供应商批次号 | 全局唯一 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 按登录身份限定 |
| `skuCode` | 商品编码 | String | 20 | 是 | 关联商品主档 | |

| `warehouseCode` | 仓库编码 | String | 20 | 是 | 关联仓库主档 | 多仓汇总维度 |
| `produceDate` | 生产日期 | Date | — | 否 | 效期管理商品收货必录 | 供应商给定失效日期时校验一致性 |

## 2. 效期与处置

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `remainDays` | 剩余天数 | Int | 10 | 是 | 失效日期减当前日期，按天重算 | 不落库 |
| `expiryStatus` | 效期状态 | Enum | 20 | 是 | 见状态枚举 | 页签依据 |
| `stockQty` | 在库数量 | Int | 12 | 是 | 货主＋商品＋批次＋库位 | 右对齐数字列 |
| `frozenQty` | 冻结数量 | Int | 12 | 否 | 禁售、盘点、差异挂起 | |
| `disposalOpinion` | 临期处置意见 | Enum | 20 | 否 | 退货 / 销毁 / 降价出库 | 货灵ERP确认，货灵WMS执行 |
| `disposalTime` | 处置确认时间 | Datetime | — | 否 | 货主确认时写入 | 留痕 |

## 3. 与其它主档的关系

- **商品主档**：效期管理开关、保质期天数、失效日期来源、临期预警天数、禁售天数都取主档，本表不复制策略。
- **库存台账**：批次号是台账流水的维度之一，台账变动不改本表批次属性。
- **委托单**：临期批次出库前需货主确认处置意见，过期与禁售批次不可分配。
- **货主主档**：运营中台汇总临期批次后，按货主分发待确认意见。

## 4. 原型衔接建议

- 货灵ERP `inventory/batch-owner-list` 页签取效期状态四值；主操作「确认处置」写入 `disposalOpinion` 与 `disposalTime`。
- 运营中台 `inventory/batch-network-report` 按仓与货主汇总批次数、临期、禁售、过期与在库数量。
- 剩余天数按当前日期派生，不写进演示数据；表头口径说明用 `tipKey` 表达计算方式。
- 冻结与解冻同步到库存台账，处置执行留痕不可删。
