# 故障工单（数据字典）

> 实体：故障工单（Fault Work Order）｜对应原型页面：设备与容器 / 告警与故障工单（`resource` 模块 `device-alarm`）
> 定位：设备故障的维修工单，承接告警转单、维修过程与停机统计。

## 1. 工单字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `workOrderNo` | 工单号 | String | 24 | 是 | `WO` + 日期 + 流水 | 全局唯一 |
| `alarmNo` | 告警号 | String | 24 | 否 | 来源设备告警 | |
| `deviceCode` | 设备编码 | String | 20 | 是 | 关联设备档案 | |
| `faultType` | 故障类型 | Enum | — | 是 | 机械 / 电气 / 通信 / 软件 / 其他 | |
| `reportedAt` | 报修时间 | Datetime | — | 是 | | |
| `repairStatus` | 维修状态 | Enum | — | 是 | 待维修 / 维修中 / 已修复 / 已关闭 | |
| `repairer` | 维修人 | String | 50 | 否 | | |
| `finishedAt` | 完成时间 | Datetime | — | 否 | | |

## 2. 状态与口径

- 已修复后由复核人关闭；关闭前不计恢复。
- 同一设备同一时间只允许一张未关闭工单。
- 停机分钟同时回写设备告警。

## 3. 与其它主档的关系

- 设备告警：`alarmNo` 为外键。
- 设备档案：`deviceCode` 为外键。
- 维保计划：修复后可生成维保项。

## 4. 原型衔接建议

- 页面：并入 `resource/device-alarm` 的行动作与抽屉，不单开页。
- 动作：转工单、恢复、关闭；抽屉展示维修轨迹。
