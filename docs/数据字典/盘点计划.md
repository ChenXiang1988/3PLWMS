# 盘点计划（数据字典）

> 实体：盘点计划｜对应原型页面：货灵WMS「盘点计划」、货灵ERP「委托单据中心」（委托类型盘点）｜字段真值源

约定：盘点计划是盘点的发起与排期层，向下生成盘点单（工序单），再拆盘点任务。来源有四类：仓网下发、货主下发、单仓自建、日常盘点。计划本身不产生差异，差异在任务行上记录、在盘点单上汇总。必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。

## 1. 计划标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `planNo` | 盘点计划号 | String | 24 | 是 | `CP` + 日期 + 4 位流水，全局唯一 | 列表主键，不可改 |
| `countType` | 盘点类型 | Enum | 20 | 是 | 全盘 / 抽盘 / 循环盘点 / 专项盘点 | 决定盘点范围与频次口径 |
| `sourceType` | 来源类型 | Enum | 20 | 是 | 仓网下发 / 货主下发 / 单仓自建 / 日常盘点 | 决定受理动作与可见范围 |
| `planStatus` | 计划状态 | Enum | 20 | 是 | 见状态枚举 | 页签依据 |
| `warehouseCode` | 仓库 | String | 20 | 是 | 关联仓库主档 | 一单只落一座仓 |
| `ownerCode` | 货主编码 | String | 20 | 否 | 关联货主主档 | 货主下发时必填；仓网下发与单仓自建可空，表示覆盖本仓全部货主 |
| `creator` | 创建人 | String | 30 | 是 | 取发起端账号 | 货主下发时为货主子账号 |
| `createTime` | 创建时间 | Datetime | — | 是 | 发起时刻 | 列表列 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `pending` | 待受理 | `pending` |
| `accepted` | 已受理 | `enabled` |
| `effective` | 已生效 | `info` |
| `completed` | 已完成 | `disabled` |
| `cancelled` | 已取消 | `disabled` |

货主下发与仓网下发的计划从待受理起步，须由货灵WMS受理排期才生效；单仓自建与日常盘点直接落「已受理」，不再走受理动作。

## 2. 范围与排期

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `skuScope` | 商品范围 | String | 500 | 否 | 逗号拼接的 `skuCode` | 货主下发时由货主选；为空表示按仓库或库区全量 |
| `zoneScope` | 库区范围 | String | 200 | 否 | 逗号拼接的库区编码 | 由仓内受理时填写，货主不可填 |
| `binScope` | 库位范围 | String | 500 | 否 | 逗号拼接的 `binCode` | 抽盘与专项盘点用 |
| `planDate` | 计划盘点日期 | Date | — | 是 | 受理时确定 | 货主下发单在受理前为货主期望日期 |
| `planWindow` | 计划时段 | String | 20 | 否 | 如 `14:00-16:00` | 避开出入库高峰 |
| `countMode` | 盘点方式 | Enum | 20 | 是 | 明盘 / 盲盘 | 盲盘时盘点任务不展示账面数，实盘提交后才比对 |
| `acceptor` | 受理人 | String | 30 | 否 | 仓内账号 | 受理时写入 |
| `acceptTime` | 受理时间 | Datetime | — | 否 | 受理时刻 | 留痕 |
| `rejectReason` | 驳回原因 | String | 500 | 否 | 仓内填写 | 驳回后计划回待受理并通知发起方 |

## 3. 执行与派生

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `processCount` | 已生成盘点单 | Int | 10 | 是 | 由工序单汇总，初始 0 | 右对齐数字列 |
| `taskCount` | 盘点任务数 | Int | 10 | 是 | 由任务汇总，初始 0 | 右对齐数字列 |
| `diffLineCount` | 差异行数 | Int | 10 | 否 | 由盘点单差异行汇总 | 实时差异列，盲盘期间不展示 |
| `finishTime` | 完成时间 | Datetime | — | 否 | 最后一笔盘点单完成时刻 | 完成后计划置已完成 |
| `remark` | 备注 | String | 500 | 否 | 发起方填写 | 说明盘点缘由 |

派生列由页面内纯函数算出，不往数据文件加展示字段：计划进度取已生成盘点单与计划范围的比值，差异率取差异行数与盘点行数的比值。

## 4. 与其它主档的关系

- **仓库主档**：`warehouseCode` 外键，一单只落一座仓；货灵WMS即本仓，不提供仓库下拉。
- **货主主档**：`ownerCode` 外键，货主下发时必填，其余来源可空。货主只能对自己名下的商品发起盘点。
- **工序单**：计划生效后按范围拆盘点单（`processType` 为盘点），一张计划可生成多张盘点单，盘点单回指 `planNo`。
- **盘点任务**：盘点单再按库区或库位段拆任务，任务行记录账面数、实盘数、差异数与差异原因。
- **库存调整任务**：差异经仓内主管复核、货主确认后才生成调整任务冲台账；未确认的差异不落账。
- **委托单**：货主下发的盘点计划在货灵ERP 以委托类型「盘点」呈现，进度取本实体的计划状态。
- **差异异常单**：盘点差异作为协同记录回写差异异常单，货灵WMS不直接维护该台账。

## 5. 原型衔接建议

- 货灵WMS `warehouse/count-plan`（list）：页签取计划状态五值；筛选取来源类型、盘点类型、货主、计划盘点日期；工具栏「新建」「受理」「导出」。
- 列名取：盘点计划号、盘点类型、来源类型、计划状态、货主、计划盘点日期、盘点方式、已生成盘点单、差异行数、创建时间、操作。
- 行操作打开详情抽屉：抬头取计划号、来源类型、货主、计划盘点日期、计划状态；分段列范围、受理留痕、派生盘点单与任务；受理与驳回动作放在抽屉内。
- 货主下发的计划，在货灵WMS为「待受理」，受理时只能改 `planDate`、`planWindow`、`zoneScope`、`binScope` 与 `countMode`，不能改货主与商品范围；驳回必须填原因。
- 货灵ERP 不建独立页，下发入口在委托单据中心的「盘点」类型抽屉里，选目标仓库与商品清单；进度只读回显受理与执行状态。
- 日常盘点由周期规则自动生成，落「已受理」，创建人记「系统」，不占用人工受理动作。
