# 商品主档（数据字典）

> 实体：商品主档（SKU Master）｜对应原型页面：基础资料 / 商品档案（`base` 模块 `sku-list`）
> 定位：描述货主委托 3PL 保管与作业的商品，是效期与批次策略的唯一真值源；批次本身不在本主档内。
> 本文件是字段真值源；原型列名与取值须逐字取自本文件，并在 `glossary.md` 登记。
> 示例模拟数据：[商品主档-示例数据.md](samples/商品主档-示例数据.md)（SKU0001~0004，`ownerCode` 指向 OW001~003 闭环）
> 字段名（key）用小写驼峰；类型以 PostgreSQL 风格标注。

约定：
- 必填：是＝创建时不可为空；否＝可空。
- 枚举（Enum）：固定取值集合，原型中以 `select` 呈现，首项「全部」。
- 多值（multi）：可多选，存储为数组 / JSONB，原型用逗号拼接展示。
- 关联：指向其它主档的外键，原型列展示其名称。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `skuCode` | 商品编码 | String | 32 | 是 | 全局唯一，运营中台赋码后不可改 | 业务系统引用主键 |
| `skuName` | 商品名称 | String | 100 | 是 | 对外正式名称 | |
| `spec` | 规格 | String | 100 | 是 | 型号 / 容量 / 颜色等 | |
| `barcode` | 条码 | String | 40 | 是 | 同一货主内唯一，跨货主可重复；仅作扫描索引，不作商品身份 | 商品身份为「货主＋商品编码」；一商品多码另建条码映射 |
| `ownerCode` | 货主 | String | 32 | 是 | 关联货主主档 | 原型「货主」筛选与 `data-owner` 作用域 |
| `unit` | 单位 | Enum | — | 是 | 件 / 箱 / 托 / 千克 | 与 `glossary.md` 数量单位一致 |
| `skuStatus` | 商品状态 | Enum | — | 是 | 启用 / 停用 | 见下方状态枚举 |

条码口径：`barcode` 与 `ownerCode` 组成唯一约束 `(ownerCode, barcode)`，不建 `barcode` 全局唯一约束。跨货主撞码（代工贴牌、条码复用）允许并存，收货与拣货按单据货主限定匹配范围；同一货主内重复拒绝。一个商品存在多个包装条码时另建「商品条码映射」子表（`ownerCode`、`barcode`、`skuCode`、包装单位），扫描先查映射再定位商品编码。外包装无法区分时贴仓内码，改扫内部商品编码。

## 8. 与其它主档的关系

- **货主主档（owner）**：`ownerCode` 多对一；商品归货主所有，货灵ERP只能查看与申请自有商品。
- **仓库主档（warehouse）**：`visibleWarehouses` 多对多；决定货灵WMS可见的商品范围。
- **批次（batch）**：不是主档字段，收货验收时按 `batchCodeRule` 生成；库存粒度为货主＋商品＋批次＋库位。
- **库存中心（inventory）**：`batch-list` 与 `stock-list` 展示批次与库存，取值口径由本主档的效期与批次策略决定。
- **入库 / 出库（inbound / outbound）**：`receiving-scan` 采集生产日期，`picking-scan` 按 `allocationRule` 分配批次；两页扫码均按单据货主限定商品集合。
- **商品条码映射**：不是主档字段；处理一商品多包装条码，按 `(ownerCode, barcode)` 查到 `skuCode`，扫描结果只作为查找索引。

## 9. 原型衔接

- 模块 `base`：`sku-list` 商品档案展示效期与批次策略列，并以行抽屉维护策略；`sku-apply-list`、`sku-audit-list`、`sku-warehouse-list` 均已落地。商品新增只走货主申请与仓网审核，`sku-list` 不提供新建与导入商品。
- 模块 `inventory`：`batch-list` 批次效期含剩余天数与效期状态；`batch-owner-list`、`batch-network-report` 均已落地。
- 模块 `owner`：`sku-owner-list` 本货主商品查询只读展示已发布主档。
- 列表列：商品编码、商品名称、规格、条码、货主、单位、是否效期管理、是否批次管理、保质期天数、临期预警天数、商品状态、创建时间。
- 筛选：货主、是否效期管理、商品状态、商品编码；下拉首项「全部」。货灵ERP页面不提供货主筛选。
- 状态页签：全部 / 启用 / 停用（主档）；全部 / 草稿 / 待审核 / 已通过 / 已驳回 / 已撤回 / 已作废（申请单，见 [商品资料变更申请单.md](商品资料变更申请单.md)）；全部 / 正常 / 临期 / 禁售 / 过期（批次）。
- 申请单与本档的关系：审核通过时按 `changeType` 新增或更新本档行，写入 `skuCode`、`version` 与 `changeSource`＝货主申请；已产生单据或批次的发布不回写，按变更申请发新版本。
