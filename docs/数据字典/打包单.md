# 打包单（数据字典）

> 实体：打包单（Packing Order）｜对应原型页面：发货作业 / 打包单（`outbound` 模块 `packing-order`）
> 定位：复核后按箱打包，记录箱号、箱型、重量体积，为装车与交接提供件数。

## 1. 打包字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `packingNo` | 打包号 | String | 24 | 是 | `PK` + 日期 + 流水 | 全局唯一 |
| `obNo` | 出库订单 | String | 24 | 是 | 关联出库订单 | |
| `cartonNo` | 箱号 | String | 24 | 是 | 一箱一号 | |
| `boxType` | 箱型 | Enum | — | 是 | 小箱 / 中箱 / 大箱 / 托盘 | |
| `boxCount` | 箱数 | Int | — | 是 | | |
| `weight` | 重量 | Decimal(10,3) | — | 否 | 公斤 | |
| `volume` | 体积 | Decimal(10,3) | — | 否 | 立方米 | |
| `packer` | 打包人 | String | 50 | 否 | | |
| `packedAt` | 打包时间 | Datetime | — | 否 | | |
| `packingStatus` | 打包状态 | Enum | — | 是 | 待打包 / 打包中 / 已打包 | |

## 2. 状态与口径

- 一个出库订单可拆多箱，箱号全局唯一。
- 称重与体积用于装车与运费估算，不反写出库订单数量。
- 打包完成后才允许装车。

## 3. 与其它主档的关系

- 出库订单：`obNo` 为外键。
- 装车单：按打包件数与重量汇总。
- 物流运单：箱唛与面单按箱号关联。

## 4. 原型衔接建议

- 页面：`outbound/packing-order`，list 骨架，按状态页签。
- 表单抽屉：出库订单、箱号、箱型、箱数、重量、体积；动作「装箱」「称重」。
