# 工序单（数据字典）

> 实体：工序单｜对应原型页面：货灵WMS的收货单、上架单、拣货单、复核单、交接单（`inbound` / `outbound` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
工序单是单仓按单据工序编排生成的作业单据，**一道工序一张**。它是货在仓内流转的作业批，向下拆成任务派给人员或设备。生成时机由编排节点的前置依赖决定：前置节点全部完成后节点就绪，就绪后按该节点的生成方式自动落单或等人工确认。工序类型可扩，新增一道工序只加枚举、一个节点类型与一张页面，不改模型。

## 2. 来源与分组

工序单不是货主建的，是单仓按作业组织维度把多张计划单的货聚到一起生成的。分组依据决定它按什么聚。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `sourcePlans` | 来源计划单 | multi | — | 是 | 多张 `planNo`，逗号拼接 | 收货按到货批次合、上架按库区合、拣货按波次合 |
| `groupBasis` | 分组依据 | Enum | — | 是 | 到货批次 / 目标库区 / 作业时段 / 单据 / 承运商 / 盘点计划 / 库位段 | 说明这张单按什么把货聚到一起，取值由编排节点配置 |
| `waveNo` | 波次号 | String | 24 | 否 | 拣货专用，关联波次计划 | 波次排时段，拣货单在波次内执行 |
| `targetZone` | 目标库区 | String | 20 | 否 | 上架专用，一单只对一个库区 | 关联库区库位 |
| `rowCount` | 行数 | Int | — | 是 | 明细行数 | 由明细派生 |
| `planQty` | 计划数量 | Int | — | 是 | 明细计划量之和 | 列表列 |
| `doneQty` | 已完成数量 | Int | — | 是 | 由任务完成量汇总，初始 0 | 列表列 |

## 4. 与其它主档的关系

- 入库计划单与出库计划单：工序单的来源（L1），一对多；一张计划单可生成多张工序单（一张收货、一张或多张上架），一张工序单也可含多张计划单。
- 盘点计划：盘点单的来源，计划生效后按盘点范围拆单；一张计划可生成多张盘点单。
- 单据工序编排：决定这道工序是否生成、什么时候生成、按什么维度聚；节点就绪后按节点的生成方式落单，单据记录当时使用的编排版本号。
- 任务：一张工序单拆多任务，任务回指 `processNo`；任务完成量汇总回写 `doneQty`，任务行上的差异数汇总回写单据差异。
- 库区库位：`fromBin` / `toBin` 外键，上架与拣货的路线依据。
- 波次：拣货单挂在波次下，波次决定时段与余量，拣货单决定拣哪些行。
- 库存调整任务：盘点单的差异经仓内复核与货主确认后派生调整任务，未确认的差异不落账。
- 库存台账：工序单不写账；账在收货上架完成、拣货出库等节点按行写入，`processNo` 作为流水业务单据号留痕。

## 5. 工序清单与页面

| 工序类型 | 前缀 | 分组依据 | 货灵WMS页面 | 说明 |
| --- | --- | --- | --- | --- |
| 收货 | `RC` | 到货批次 | 收货单 | 一次到货含多张计划单的货时合并，采批次与实收、拒收 |
| 上架 | `PA` | 目标库区 | 上架单 | 多张计划单进同一库区的货合并，收货完成后生成 |
| 拣货 | `PK` | 作业时段 | 拣货单 | 挂在波次内，波次排时段、拣货单定行 |
| 复核 | `CK` | 单据 | 复核单 | 拣货后逐包裹或逐单复核 |
| 交接 | `HV` | 承运商 | 交接单 | 与承运商交接回单 |
| 盘点 | `CN` | 盘点计划 + 库位段 | 盘点单 | 计划生效后按盘点范围拆，任务行记账面数与实盘数；盲盘期间不展示账面数 |
| 移库 | `MV` | 目标库区 | 移库任务 | 策略触发或人工建，单据与任务合页 |
| 补货 | `RP` | 补货区 | 补货任务 | 从存储位移到拣货位，单据与任务合页 |

新增工序（质检、贴标、打托、拆零等）时只在此表加行、在 `processType` 加枚举、在编排里加一个节点类型、在货灵WMS开页，模型不变。

## 6. 原型衔接建议

- 收货单、上架单、拣货单、复核单、交接单各一页（list），页签统一用工序单状态 5 值。
- 通用列：工序单号、工序单状态、来源计划单、计划数量、已完成数量、作业进度；按工序加专属列（上架加目标库区、交接加承运商）。
- 扫码作业屏取任务上下文，不取整张工序单。
