# 盘点差异（数据字典）

> 实体：盘点差异（Count Difference）｜对应原型页面：盘点与异常 / 盘点差异审批（`inventory` 模块 `count-diff-audit`）
> 定位：盘点实盘与账面不一致的差异记录，审批通过后生成库存调整，是改账唯一出口。

## 1. 差异字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `diffNo` | 差异号 | String | 24 | 是 | `DF` + 日期 + 流水 | 全局唯一 |
| `countNo` | 盘点单 | String | 24 | 是 | 关联盘点单 | |
| `ownerCode` | 货主 | String | 20 | 是 | 关联货主主档 | |
| `skuCode` | 商品编码 | String | 24 | 是 | 关联商品主档 | |
| `batchNo` | 批次号 | String | 24 | 否 | | |
| `locationCode` | 库位 | String | 20 | 是 | | |
| `bookQty` | 账面数 | Decimal(14,3) | — | 是 | | |
| `actualQty` | 实盘数 | Decimal(14,3) | — | 是 | | |
| `diffQty` | 差异数 | Decimal(14,3) | — | 是 | 实盘减账面 | |
| `diffType` | 差异类型 | Enum | — | 是 | 盘盈 / 盘亏 / 串位 | |
| `approveStatus` | 审批状态 | Enum | — | 是 | 待审批 / 已通过 / 已驳回 | |
| `adjustNo` | 调整单 | String | 24 | 否 | 通过后生成 | |

## 2. 状态与口径

- 容差内自动通过；超容差进人工审批。
- 审批通过前不改账面；通过后生成一张调整单过账。
- 驳回必须填原因，差异回盘点单重盘。

## 3. 与其它主档的关系

- 盘点单：`countNo` 为外键。
- 库存调整任务：`adjustNo` 为外键。
- 库存台账：调整单过账写流水。

## 4. 原型衔接建议

- 页面：`inventory/count-diff-audit`，list 骨架，按审批状态页签。
- 抽屉：差异明细 + 调整单预览 + 审批意见；动作「通过」「驳回」。
