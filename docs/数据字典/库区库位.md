# 库区库位（数据字典）

> 实体：库区库位（Location / Zone / Rack / Bin）｜对应原型页面：仓储管理 / 库区库位（`warehouse` 模块 `location-list`）
> 示例模拟数据：[库区库位-示例数据.md](samples/库区库位-示例数据.md)（WH0004 1F 的库区/货架/库位三层与拣货坐标示例）
> 定位：描述仓库**内部的空间划分与存储单元**，是 `仓库主档` 的下层结构。仓库主档管"建筑壳"，本档管"壳里的格子"。
> 空间层级：**库区(zone) → 货架(rack) → 库位(bin)**。库位是带坐标的最小存储单元，坐标用于拣货路顺计算。
> 本文件是字段真值源；生成原型页面时列名与取值逐字取自本文件，并在 `glossary.md` 登记。
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯。

约定：
- 必填：是=创建时不可为空；否=可空。
- 枚举（Enum）：固定取值集合，原型中以 `select` 呈现，首项「全部」。
- 关联：指向其它主档的外键，原型列展示其「名称」。

---

## 1. 库区（Zone）

按楼层（`floorNo`）划分的功能区域，是货架的容器。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `zoneCode` | 库区编码 | String | 20 | 是 | 全局唯一 | 建议 `Z` + 仓库编码后缀 + 序号 |
| `zoneName` | 库区名称 | String | 50 | 是 | 如「A 区-常温存储」 | |
| `warehouseCode` | 所属仓库 | String | 20 | 是 | 关联 `仓库主档.warehouseCode` | 外键 |
| `floorNo` | 所在楼层 | Int | — | 否 | 关联 `仓库主档.floors[].floorNo` | 各层库区划分的归属层 |
| `zoneType` | 库区类型 | Enum | — | 否 | 见下方枚举 | 决定作业属性 |
| `zoneArea` | 库区面积 | Decimal(10,2) | — | 否 | 单位 ㎡ | 应 ≤ 所在楼层单层面积 |
| `tempZone` | 温区 | Enum | — | 否 | 常温 / 恒温 / 冷藏 / 冷冻 | 与仓库主档 `tempZones` 取值对齐 |
| `zoneStatus` | 库区状态 | Enum | — | 否 | 启用 / 停用 / 封存 | 见下方状态枚举 |

### 库区类型枚举
| 值 | 中文 | 说明 |
| --- | --- | --- |
| `storage` | 存储区 | 长期存放 |
| `picking` | 拣选区 | 按单拣货，多用流利架/隔板货位 |
| `buffer` | 暂存区 | 出入库缓冲 |
| `crossdock` | 越库区 | 不入库直转 |
| `defect` | 不良品区 | 残次 / 待处理 |
| `office` | 办公区 | 非存储 |
| `equip` | 设备区 | 设备 / 充电 |

### 状态枚举
| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `active` | 启用 | `enabled` |
| `disabled` | 停用 | `disabled` |
| `sealed` | 封存 | `disabled` |

## 2. 货架（Rack）

库区内的货架结构，是库位的容器。一个货架（尤其拣货区流利架）铺开成多个货位（`排 × 层 × 位`）。`rackType` 为枚举，是货架的主属性。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `rackCode` | 货架编码 | String | 20 | 是 | 全局唯一 | 建议 库区前缀 + `R` + 序号 |
| `rackName` | 货架名称 | String | 50 | 否 | | |
| `zoneCode` | 所属库区 | String | 20 | 是 | 关联 `库区.zoneCode` | 外键 |
| `rackType` | 货架类型 | Enum | — | 是 | 见下方枚举 | 决定承载与库位形态 |
| `aisleNo` | 巷道号 | String | 10 | 否 | 如 `A01` | 同巷道货架相邻；拣货路径分组依据，须与库位 `aisleNo` 一致 |
| `bayCount` | 排数 | Int | — | 否 | 沿巷道方向的分支数 | 几何 |
| `levelCount` | 层数 | Int | — | 否 | 垂直层数 | 几何 |
| `positionPerCell` | 每格位数 | Int | — | 否 | 每(排,层)的货位数 | 几何 |
| `totalBin` | 库位数 | Int | — | 否 | = `bayCount` × `levelCount` × `positionPerCell` | 派生，供校验 |
| `depth` | 深位 | Enum | — | 否 | 单深 / 双深 | 双深影响取货顺序与坐标 |
| `rackStatus` | 货架状态 | Enum | — | 否 | 启用 / 停用 / 封存 | |

### 货架类型枚举（rackType）
| 值 | 中文 | 说明 |
| --- | --- | --- |
| `beam` | 横梁货架 | 整托 / 重型 |
| `flow` | 流利架 | 拆零拣选，重力滑道 FIFO；拣货区主力 |
| `drivein` | 驶入式货架 | 高密度整托 |
| `asrs` | 自动化立库 | AS/RS，库位由系统坐标寻址 |
| `mezzanine` | 阁楼货架 | 利用层高隔出二层拣选 |
| `cantilever` | 悬臂货架 | 长件 / 管材 |
| `other` | 其他 | |

> 注：`仓库主档.rackType` 仅作"主类型概述"；逐货架类型以本档 `rackType` 为准。

## 3. 库位（Bin）

货架（或地堆/暂存区）上的最小存储单元，**必须带坐标地址**以便拣货路顺计算。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `binCode` | 库位编码 | String | 20 | 是 | 全局唯一 | 建议 库区 + 巷道 + 排 + 层 + 位 |
| `zoneCode` | 所属库区 | String | 20 | 是 | 关联 `库区.zoneCode` | 外键 |
| `rackCode` | 所属货架 | String | 20 | 否 | 关联 `货架.rackCode` | 外键；地堆 / 暂存可空 |
| `binType` | 库位类型 | Enum | — | 是 | 见下方枚举 | 决定可存放形态 |
| `aisleNo` | 巷道号 | String | 10 | 否 | 关联 `货架.aisleNo` | 拣货路径分组键 |
| `bayNo` | 排/列号 | Int | — | 否 | 沿巷道方向序号 | 拣货路径排序键 |
| `levelNo` | 层号 | Int | — | 否 | 垂直层序号（从下往上 1,2,3…） | 拣货路径排序键 |
| `posNo` | 位号 | Int | — | 否 | 该层该排内货位序号 | 拣货路径排序键 |
| `binAddress` | 库位地址 | String | 30 | 否 | 由 巷道-排-层-位 组合，如 `A01-03-02-05` | 人类可读坐标 |
| `capacity` | 容量 | Decimal(10,2) | — | 否 | 单位按 `capacityUnit` | |
| `capacityUnit` | 容量单位 | Enum | — | 否 | 托 / 件 / 箱 / 千克 | |
| `usedCapacity` | 已用容量 | Decimal(10,2) | — | 否 | 单位同 `capacityUnit` | 派生自库存，不冗余存储 |
| `binStatus` | 库位状态 | Enum | — | 否 | 空闲 / 占用 / 冻结 / 停用 | 见下方状态枚举 |

### 库位类型枚举（binType）
| 值 | 中文 | 适用 |
| --- | --- | --- |
| `pallet` | 托盘位 | 整托存储 |
| `shelf` | 隔板位 | 拆零 / 小件 |
| `flow` | 流利架位 | 先进先出拆零（货架 `rackType=flow`） |
| `ground` | 地堆位 | 大货 / 非标，无 `rackCode` |
| `drivein` | 驶入位 | 高密度整托 |
| `buffer` | 暂存位 | 待上架 / 待拣 |
| `crossdock` | 越库位 | 直转 |
| `defect` | 残次位 | 不良品 |

### 状态枚举
| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `empty` | 空闲 | `info` |
| `occupied` | 占用 | `enabled` |
| `frozen` | 冻结 | `pending` |
| `disabled` | 停用 | `disabled` |

### 拣货路顺所需的库位坐标
- 同一次拣货任务内的多个库位，先按 `aisleNo` 分组成巷道；
- 巷道内按 `(bayNo, levelNo, posNo)` 排序走 S 形 / 最短路径；
- `binAddress` 是上述坐标的可读表达，算法侧可用结构化字段或地址解析。
- 因此 `aisleNo / bayNo / levelNo / posNo` 为拣货计算的**必留字段**，原型与算法不得省略。

## 4. 与其它主档的关系

- **仓库主档**：`warehouseCode` + `floorNo` 定位到建筑与楼层；`zoneArea` 累计应 ≤ `floors[].floorArea`。
- **货架**：`zoneCode` 归属库区；货架几何（`bayCount`/`levelCount`/`positionPerCell`）派生 `totalBin`，应等于其下 `binCode` 实际数量。
- **库位**：`zoneCode` + `rackCode` + 坐标 定位；坐标与货架 `aisleNo` 对齐。
- **库存中心**：库位是库存的落点（`stock-list` 的 `库位编码`）；容量 / 状态由实际库存驱动。
- **入库 / 出库**：上架任务、拣货作业指向具体库位，库位类型约束可存放形态；拣货路径依赖库位坐标。
