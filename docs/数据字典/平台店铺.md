# 平台店铺（数据字典）

> 实体：平台店铺｜对应原型页面：货灵ERP「平台店铺」（`owner` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
平台店铺是货主在外部电商平台开设的店铺，与货源商城的「商城店铺」是两个实体。一个货主可以有多个平台、多个店铺；授权按店铺隔离，订单按店铺拉回。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `shopCode` | 店铺编码 | String | 30 | 是 | 全局唯一，业务引用主键 | 平台店铺编码，不可改 |
| `shopName` | 店铺名称 | String | 100 | 是 | 平台店铺展示名 | 列表列 |
| `platformCode` | 平台 | Enum | — | 是 | 速卖通 / Amazon / Temu / TikTok Shop / Shopee / Lazada / 美客多 / 其他 | 取 glossary 平台枚举 |
| `sellerId` | 卖家 ID | String | 60 | 是 | 平台侧卖家或店铺标识 | 同平台多店时区分 |
| `region` | 站点 | String | 30 | 否 | Temu 全球 / 美国 / 欧区；Lazada PH / ID / VN / MY / TH / SG；TikTok Shop 东南亚 / 英国 / 美国 / 欧盟；Amazon NA / EU / FE / 沙特 / 阿联酋 | 多站点平台按站点分别授权 |
| `shipFrom` | 发货地 | Enum | — | 是 | 中国 | 本期只支持中国地区发货，不建海外仓与本土店 |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 按登录货主限定 |
| `shopType` | 店铺类型 | Enum | — | 是 | 全托管 / 半托管 / POP / 跨境店 / 自发货 | 按平台可选，见店铺类型枚举 |
| `authMode` | 授权方式 | Enum | — | 是 | 产品库存 Token / 订单发货 Token / 站点市场服务 / OAuth / 区域授权 / supplier_id | 取平台授权要求，见授权方式枚举；页面不展示 Token 值 |
| `authStatus` | 授权状态 | Enum | — | 是 | 待授权 / 已授权 / 即将过期 / 已过期 / 已撤销 / 授权失败 | 见状态枚举 |
| `createTime` | 创建时间 | Datetime | — | 是 | 系统写入 | 列表列 |

### 店铺类型枚举

| 值 | 中文 | 可选平台 | 履约责任 |
| --- | --- | --- | --- |
| `fullManaged` | 全托管 | Temu、TikTok Shop、速卖通、Lazada | 供货到平台国内集货仓，跨境物流与售后由平台承担，不处理消费者订单 |
| `semiManaged` | 半托管 | Temu、Lazada | 商家自主发货，本期为中国直发，尾程用平台在线面单 |
| `pop` | POP | Lazada | 商家自运营、自发货，走跨境官方直邮或国内集货仓 |
| `crossBorder` | 跨境店 | TikTok Shop | 中国大陆 / 香港主体跨境店，从中国发货 |
| `selfFulfilled` | 自发货 | Amazon、Shopee、美客多 | 商家自发货（FBM），国内直邮 |

### 授权方式枚举

| 值 | 中文 | 适用平台与店铺类型 |
| --- | --- | --- |
| `productToken` | 产品库存 Token | Temu 全托管、Temu 半托管 |
| `orderToken` | 订单发货 Token | Temu 半托管（全托管不需要） |
| `complianceToken` | 合规 API Token | Temu 全托管（可选） |
| `siteService` | 站点市场服务 | Lazada POP、Lazada 半托管（每站点单独订购，半年有效） |
| `oauth` | OAuth | TikTok Shop 跨境店/全托管、Lazada 主账号 |
| `regionAuth` | 区域授权 | Amazon（同区域多站点算一店，跨区域分次授权） |
| `supplierId` | supplier_id | TikTok Shop 全托管（只授权主店铺） |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `pendingAuth` | 待授权 | `pending` |
| `authorized` | 已授权 | `enabled` |
| `expiring` | 即将过期 | `pending` |
| `expired` | 已过期 | `rejected` |
| `revoked` | 已撤销 | `disabled` |
| `authFailed` | 授权失败 | `rejected` |

## 2. 授权与同步

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `authNo` | 授权编号 | String | 24 | 否 | 当前有效授权记录 | 关联店铺授权 `authNo` |
| `authScope` | 授权范围 | String | 200 | 否 | 订单 / 售后 / 物流 / 商品 | 多项用逗号拼接 |
| `authTime` | 授权时间 | Datetime | — | 否 | 最近一次授权成功时刻 | |
| `expireTime` | 凭证到期 | Datetime | — | 否 | 平台凭证到期时刻 | 到期前 7 天转即将过期 |
| `lastSyncTime` | 最近同步时间 | Datetime | — | 否 | 最近一次拉单成功时刻 | 列表列 |
| `failReason` | 失败原因 | String | 300 | 否 | 授权或同步失败原因 | 留痕不可删 |
| `operator` | 操作人 | String | 30 | 否 | 取登录账号 | 授权与解除授权留痕 |

## 3. 适配要点（只读派生）

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `adapterCode` | 适配配置 | String | 30 | 是 | 关联平台适配器 `adapterCode` | 按 `platformCode` × `shopType` 命中，见平台适配器字典 |
| `rawOrder` | 原单有无 | Enum | 20 | 是 | 有原单 / 无原单（备货单） | 全托管与 FBA 按备货单接入，不产生终端消费者订单 |
| `labelSource` | 面单来源 | Enum | 20 | 是 | 平台面单 / 承运商面单 / 卖家自备 / 无面单 | 半托管与 POP 口径不同，见平台适配器能力矩阵 |
| `fulfillDuty` | 履约责任 | Enum | 10 | 是 | 平台 / 卖家 | 全托管由平台承担，其余由卖家承担 |

这四个字段由平台×模式派生，不在新增店铺表单里录入；授权抽屉只读展示，避免把不同平台压成同一套字段。

## 4. 与其它主档的关系

- 货主主档：`ownerName` 外键，平台店铺归属货主；货灵ERP按登录身份限定，不提供货主下拉。
- 店铺授权：一个平台店铺对应多条授权记录，`authNo` 取当前有效记录，历史授权不清除。
- 平台适配器：`platformCode` × `shopType` 命中一条适配器，`adapterCode` 回指；字段映射、状态映射与能力不复制进店铺。
- 平台订单：`shopCode` 外键，平台订单按店铺拉回，不跨店铺合并。
- 同步任务：`shopCode` 外键，每店一条队列，游标与任务按店铺隔离。
- 商城店铺：两个实体不合并。`店铺.md` 是货源商城店铺，平台店铺是外部平台店铺。

## 5. 原型衔接建议

- `owner/platform-shop-list`（货灵ERP，list）：平台、店铺、站点、店铺类型、发货地、授权方式、授权状态、凭证到期、最近同步时间、适配配置、操作。
- 状态页签：全部 / 待授权 / 已授权 / 即将过期 / 已过期 / 已撤销 / 授权失败；筛选：平台、店铺类型、发货地、授权方式。
- 工具条：新增店铺、导出；新增抽屉按平台选择店铺类型、站点、发货地与授权方式，平台与店铺类型联动可选值。
- 表单动作：保存店铺、授权、重新授权、解除授权、关闭；行详情展示授权范围、授权时间、失败原因与授权日志，并按当前行只读带出原单有无、面单来源、履约责任、适配配置。
- 列表按登录货主限定，不提供货主筛选；重新授权追加授权记录，不覆盖历史；页面不展示 Token 值与 App Secret。
- 本期只支持中国地区发货；Temu 全托管供货到平台国内集货仓，Temu 半托管走 Y2 中国直邮，Lazada 走跨境官方直邮或国内集货仓，TikTok Shop 跨境店从中国发货，Amazon 走 FBM 国内直邮。
