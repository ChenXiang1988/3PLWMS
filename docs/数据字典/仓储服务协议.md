# 仓储服务协议（数据字典）

> 实体：仓储服务协议｜对应原型页面：货灵ERP「仓储服务」、货灵运营中台管理端「服务协议」
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
仓储服务协议是货主与仓网之间的商务签约，决定能不能使用仓储服务、能用哪些仓。**先有本协议，后有时效协议**：本协议管商务关系与服务仓库范围，时效协议管作业承诺，两者按「仓 × 货主」对齐但不合并。未签约的货灵ERP 注册账号只能用软件功能，建不了入库与出库计划单。

## 1. 协议标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `agreementNo` | 协议编号 | String | 24 | 是 | 全局唯一，业务引用主键 | `SA` + 日期 + 4 位流水；不可改 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 一个货主一份协议，增补仓库不另开协议 |
| `ownerName` | 货主名称 | String | 100 | 是 | 取货主主档 | 展示用 |
| `agreementStatus` | 协议状态 | Enum | — | 是 | 草稿 / 待审核 / 已生效 / 已驳回 / 已终止 | 见状态枚举 |
| `submitTime` | 提交时间 | Datetime | — | 否 | 货主提交签约申请的时刻 | |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `draft` | 草稿 | `disabled` |
| `pendingReview` | 待审核 | `pending` |
| `approved` | 已生效 | `enabled` |
| `rejected` | 已驳回 | `rejected` |
| `terminated` | 已终止 | `disabled` |

## 2. 服务与期限

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `serviceItems` | 服务项目 | Enum | — | 是 | 仓储 / 库内加工 / 配送 | 可多选，决定开放哪些作业页 |
| `billingCycle` | 账期 | Enum | — | 是 | 月结 / 半月结 / 票结 | 与费用账单的出账口径一致 |
| `effectiveDate` | 生效日期 | Date | — | 是 | 审核通过后按此日期生效 | 早于审核日则按审核日计 |
| `expireDate` | 到期日期 | Date | — | 否 | 空表示长期有效 | 到期前提醒续签 |
| `signTime` | 签约时间 | Datetime | — | 否 | 审核通过时写入 | |
| `reviewer` | 审核人 | String | 30 | 否 | 运营中台账号 | |
| `reviewTime` | 审核时间 | Datetime | — | 否 | 运营中台审核时刻 | |
| `terminateReason` | 终止原因 | String | 500 | 否 | 终止时必填 | 留痕不可删 |

## 3. 按仓签约

一张协议可覆盖多个仓，仓库范围按行登记，一仓一行，支持不同仓分批生效。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `warehouseCode` | 仓库编码 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 一仓一行 |
| `warehouseStatus` | 仓库签约状态 | Enum | — | 是 | 已生效 / 暂停 / 已终止 | 暂停期间不能建该仓单据 |
| `startDate` | 生效日期 | Date | — | 是 | 该仓开始服务日期 | 不早于协议生效日期 |
| `endDate` | 终止日期 | Date | — | 否 | 空表示长期 | |

## 4. 与其它主档的关系

- 货主主档：`ownerCode` 外键，一个货主一份协议；`货主主档` 不再承载签约状态，只在关系节引用本协议。
- 仓库主档：`warehouseCode` 外键，只对已生效的仓开放入库与出库单据。
- 时效协议：本协议生效后才能按「仓 × 货主 × 业务类型」签时效协议；时效协议只约束作业时效，不替代商务签约。
- 入库计划单与出库计划单：提交时校验目标仓在本协议范围内且仓库签约状态为已生效，不满足则不允许提交，提示先签约。
- 费用账单：账期取本协议 `billingCycle`，仓储费按签约仓归集。

## 5. 原型衔接建议

- 货灵ERP `owner/service-agreement`（list）：协议编号、服务仓库、服务项目、账期、协议状态、生效日期、到期日期。
- 货灵运营中台管理端 `network/agreement-audit`（list）：协议编号、货主、服务仓库、服务项目、账期、协议状态、提交时间；工具条：审核通过、驳回留原因、终止。
- 货灵ERP未签约时，入库计划单与出库计划单入口置灰并展示「先签仓储服务协议」，点击跳本页。
- 状态页签：全部 / 草稿 / 待审核 / 已生效 / 已驳回 / 已终止；列表按登录货主限定，不提供货主筛选。
