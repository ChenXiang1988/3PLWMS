# 理货单（数据字典）

> 实体：理货单（Tally Order）｜对应原型页面：入库管理 / 理货任务（`inbound` 模块 `tally-task`）
> 定位：收货与上架之间的理货环节，按商品、批次与托盘归集，差异转异常。

## 1. 理货字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `tallyNo` | 理货号 | String | 24 | 是 | `TL` + 日期 + 流水 | 全局唯一 |
| `receivingNo` | 收货单 | String | 24 | 是 | 关联收货单 | |
| `ownerCode` | 货主 | String | 20 | 是 | 关联货主主档 | |
| `skuCode` | 商品编码 | String | 24 | 是 | 关联商品主档 | |
| `batchNo` | 批次号 | String | 24 | 否 | | |
| `stageLocationCode` | 暂存库位 | String | 20 | 是 | 理货暂存区 | |
| `palletNo` | 托盘 | String | 20 | 否 | | |
| `tallyQty` | 理货数量 | Decimal(14,3) | — | 是 | | |
| `tallyStatus` | 理货状态 | Enum | — | 是 | 待理货 / 理货中 / 已完成 / 有差异 | |
| `operator` | 操作人 | String | 50 | 否 | | |
| `actedAt` | 操作时间 | Datetime | — | 否 | | |

## 2. 状态与口径

- 理货数量与收货数量不一致时置「有差异」，生成差异异常单。
- 一个收货单可按库区或托盘拆多条理货任务。
- 理货完成后才允许生成上架单。

## 3. 与其它主档的关系

- 收货单：`receivingNo` 为外键。
- 上架单：按理货结果生成。
- 差异异常单：差异数量回写来源域。

## 4. 原型衔接建议

- 页面：`inbound/tally-task`，list 骨架，按状态页签。
- 表单抽屉：收货单、暂存库位、托盘、理货数量、差异说明；动作「开始理货」「完成理货」。
