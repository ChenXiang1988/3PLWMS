# 店铺授权（数据字典）

> 实体：店铺授权｜对应原型页面：货灵ERP「平台店铺」授权抽屉
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
店铺授权记录一个平台店铺的授权生命周期。重新授权追加新记录，不覆盖历史；凭证与 App Secret 不在原型展示。

## 1. 授权标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `authNo` | 授权编号 | String | 24 | 是 | 全局唯一，业务引用主键 | `AU` + 日期 + 4 位流水；不可改 |
| `shopCode` | 店铺编码 | String | 30 | 是 | 关联平台店铺 `shopCode` | 一个店铺多条授权记录 |
| `platformCode` | 平台 | Enum | — | 是 | 取平台店铺同名字段 | 冗余展示，不另建平台主档 |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 按登录货主限定 |
| `authStatus` | 授权状态 | Enum | — | 是 | 已授权 / 即将过期 / 已过期 / 已撤销 / 授权失败 | 当前记录状态 |
| `authScope` | 授权范围 | String | 200 | 否 | 订单 / 售后 / 物流 / 商品 | 多项用逗号拼接 |
| `authTime` | 授权时间 | Datetime | — | 否 | 授权成功时刻 | 授权失败为空 |
| `expireTime` | 凭证到期 | Datetime | — | 否 | 平台凭证到期时刻 | 到期前 7 天转即将过期 |
| `revokeTime` | 解除时间 | Datetime | — | 否 | 解除授权时刻 | 已撤销时填写 |
| `failReason` | 失败原因 | String | 300 | 否 | 授权失败原因 | 留痕不可删 |

## 2. 授权日志

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `operator` | 操作人 | String | 30 | 是 | 取登录账号 | 授权、重新授权、解除授权 |
| `action` | 操作动作 | Enum | — | 是 | 授权 / 重新授权 / 解除授权 / 刷新凭证 | 只追加不删除 |
| `actionTime` | 操作时间 | Datetime | — | 是 | 系统写入 | 时间轴 |
| `actionDetail` | 操作内容 | String | 500 | 否 | 变更前后值或失败原因 | 留痕不可删 |

## 3. 与其它主档的关系

- 平台店铺：`shopCode` 外键，一个店铺对应多条授权记录，当前有效记录回写平台店铺 `authNo`。
- 货主主档：`ownerName` 外键，授权归属货主；子账号只能看授权范围内的店铺。
- 同步任务：授权失效导致拉单停止，任务失败原因回指授权状态，不改写已拉订单。
- 平台应用凭证：由部署侧配置，不属于本实体，原型只展示凭证到期与失败原因。

## 4. 原型衔接建议

- `owner/platform-shop-list` 行详情抽屉：展示授权编号、授权状态、授权范围、授权时间、凭证到期、解除时间、失败原因与授权日志时间轴。
- 工具条动作：新增店铺、保存店铺、授权、重新授权、解除授权；解除授权需二次确认，已拉订单与进行中履约不受影响。
- 页面不在列表展示 App Secret 与 Token 值；凭证只显示脱敏值与到期时间。
- 各平台授权前置不同：Temu 全托管取产品库存 Token（合规 API Token 可选），Temu 半托管另取订单发货 Token；Lazada 每站点单独订购市场服务（半年有效）；TikTok Shop 跨境店走 OAuth，全托管走 supplier_id；Amazon 按区域授权，同区域多站点算一店。页面只登记授权方式，不承载凭证。
- Temu 店铺类型授权成功后不可修改，需删除店铺重新授权；Lazada 跨境店需用主账号授权并选择跨境卖家。
