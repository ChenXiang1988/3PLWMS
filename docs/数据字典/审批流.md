# 审批流（数据字典）

> 实体：审批流（Approval Flow）｜对应原型页面：账号与权限 / 审批流配置（`system` 模块 `approval-flow`）
> 定位：按单据类型配置审批节点、审批角色与超时升级。

## 1. 流程字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `flowCode` | 流程编码 | String | 20 | 是 | 全局唯一 | |
| `docType` | 单据类型 | Enum | — | 是 | 入库计划单 / 出库计划单 / 盘点差异 / 冻结解冻 / 费用账单 | |
| `nodeSeq` | 节点序号 | Int | — | 是 | 从 1 开始 | |
| `nodeName` | 节点名称 | String | 40 | 是 | | |
| `approverRole` | 审批角色 | String | 40 | 是 | 关联角色 | |
| `timeoutHours` | 超时小时 | Int | — | 否 | | |
| `escalateTo` | 升级对象 | String | 40 | 否 | 超时转交角色 | |
| `flowStatus` | 状态 | Enum | — | 是 | 草稿 / 已发布 / 已停用 | |
| `version` | 版本 | String | 10 | 是 | 发布递增 | |

## 2. 状态与口径

- 一流程多节点，节点按序号串行。
- 已发布版本不可改，改配置发新版本。
- 停用后新单据走默认审批。

## 3. 与其它主档的关系

- 角色：`approverRole` 为外键。
- 差异异常单、盘点差异、冻结单：按 `docType` 命中流程。
- 操作日志：审批动作写审计。

## 4. 原型衔接建议

- 页面：`system/approval-flow`，list 骨架，一流程一行展开节点。
- 编排抽屉：节点序号、节点名称、审批角色、超时小时、升级对象。
