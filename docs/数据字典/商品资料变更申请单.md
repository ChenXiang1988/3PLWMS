# 商品资料变更申请单（数据字典）

> 实体：商品资料变更申请单｜对应原型页面：货灵ERP「商品资料变更申请」、货灵运营中台管理端「商品主档审核」｜字段真值源

约定：货灵ERP提交商品资料新增、变更、停用与运营中台审核发布的唯一载体。审核通过后才写入商品主档并赋商品编码；新增类型在提交前不带商品编码。申请单、审核留痕与商品主档版本三方关联，已产生单据或批次的发布不可回写。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `applyNo` | 申请单号 | String | 20 | 是 | 系统生成，全局唯一 | 列表主键，两端共用 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 货灵ERP按登录身份限定，不提供货主下拉 |
| `ownerName` | 货主 | String | 50 | 是 | 取货主主档名称 | 列表展示 |
| `changeType` | 变更类型 | Enum | 10 | 是 | 新增 / 变更 / 停用 | 新增时 `skuCode` 为空 |
| `skuCode` | 商品编码 | String | 20 | 否 | 运营中台审核通过后赋码 | 新增前为空，变更与停用必填 |
| `skuName` | 商品名称 | String | 100 | 是 | 货主填写 | 列表展示 |
| `spec` | 规格 | String | 50 | 否 | 货主填写 | 基础标识 |
| `barcode` | 条码 | String | 30 | 否 | 同一货主内唯一 | 按「货主＋条码」校验撞码 |
| `unit` | 单位 | String | 10 | 否 | 件 / 箱 / 托 / 千克 | 基础标识 |
| `applyStatus` | 审核状态 | Enum | 20 | 是 | 见状态枚举 | 页签与状态流转依据 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `draft` | 草稿 | `disabled` |
| `pendingReview` | 待审核 | `pending` |
| `approved` | 已通过 | `enabled` |
| `rejectedReview` | 已驳回 | `rejected` |
| `withdrawn` | 已撤回 | `disabled` |
| `voided` | 已作废 | `disabled` |

## 3. 与其它主档的关系

- **货主主档**：`ownerCode` 多对一；货灵ERP只能提交与查看本货主的申请单。
- **商品主档**：审核通过后按 `changeType` 新增或更新主档行，并写入 `skuCode` 与 `releasedVersion`；主档 `changeSource` 取「货主申请」。
- **仓库主档**：发布后按商品主档 `visibleWarehouses` 下发，已产生单据或批次时只发新版本，不回写已发布主档。
- **委托单**：申请单未发布前，相关商品不可用于建委托单。

## 4. 原型衔接建议

- 货灵ERP `base/sku-apply-list`：页签取状态枚举中文名；工具条新增、提交审核、撤回、退回修改重提；表单抽屉承载第 1、2 节字段，草稿保存不改状态。
- 货灵运营中台管理端 `base/sku-audit-list`：审核详情抽屉展示申请内容、变更前后值与操作轨迹；审核意见与驳回原因可录入，通过时触发赋码与发布。
- 两端申请单取同一份共享主档，页签计数与列表状态随操作重算；审核留痕字段在操作轨迹里可见。
- 逆向边界：草稿可撤回、待审核可撤回、已通过未下发可作废（`skuCode` 不复用）、无单据批次时可反审核回待审核；已产生单据或批次不可逆，按变更申请发新版本。
