# 委托单（数据字典）

> 实体：委托单｜对应原型页面：货灵ERP「委托单据中心」、货灵ERP「入库计划单」「出库计划单」｜字段真值源

约定：委托单据中心是各类委托的统一查询视图，不另建第二份业务真相。委托单按业务类型指向计划单、调拨申请单、退货申请单、商品资料变更申请单或盘点计划，只做状态跟踪与追溯。

## 1. 委托标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |

| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 按登录身份限定 |

| `sourcePage` | 来源页面 | String | 50 | 是 | 页面名 | 追溯跳转依据 |
| `sourceKey` | 来源页 key | String | 50 | 是 | 注册表页 key | 侧栏定位 |

## 3. 与其它主档的关系

- **入库计划单 / 出库计划单**：委托类型入库、出库时取计划单号与五态状态机映射。
- **调拨申请单 / 退货申请单**：委托类型调拨、退货时取各自申请单状态映射。
- **商品资料变更申请单**：委托类型商品资料变更时取申请单审核状态映射。
- **盘点计划**：委托类型盘点时取盘点计划号与计划状态映射；货主下发后由货灵WMS受理排期，受理前的状态为待受理。
- **货主主档**：按登录身份限定数据范围，不提供货主筛选；已下发作业单据进展在来源页面查看。

## 4. 原型衔接建议

- 货灵ERP `owner/delegation-list` 页签取委托状态五值；工具条「导出」「变更取消」，变更取消抽屉录入原因并留痕。
- 列表展示委托单号、委托类型、目标仓库、品类数、计划数量、委托状态、提交时间、申请人。
- 统一视图只读来源单据状态，不提供来源单据的编辑入口；确认结果展示运营中台结论。
- 委托单与来源单据不合并成同一实体，避免两套状态机互相覆盖。
- 盘点类型在下发抽屉里选目标仓库与商品清单，库区与库位不由货主填写；下发后进度回显货灵WMS的受理与执行状态。
