# 装车单（数据字典）

> 实体：装车单（Loading Order）｜对应原型页面：发货作业 / 装车发运（`outbound` 模块 `loading-list`）
> 定位：月台装车与发运记录，承接打包件数、交接单与承运商。

## 1. 装车字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `loadingNo` | 装车号 | String | 24 | 是 | `LD` + 日期 + 流水 | 全局唯一 |
| `carrierCode` | 承运商 | String | 20 | 是 | 关联承运商主档 | |
| `plateNo` | 车牌 | String | 16 | 否 | | |
| `dockCode` | 月台 | String | 20 | 否 | | |
| `handoverNo` | 交接单 | String | 24 | 否 | 关联交接单 | |
| `packageCount` | 件数 | Int | — | 是 | 来自打包单 | |
| `weight` | 重量 | Decimal(12,3) | — | 否 | 公斤 | |
| `loadedAt` | 装车时间 | Datetime | — | 否 | | |
| `loadingStatus` | 装车状态 | Enum | — | 是 | 待装车 / 装车中 / 已发运 | |

## 2. 状态与口径

- 装车完成即发运，发运后不可回退。
- 件数与重量按同一车次汇总，不按单票重复计。
- 发运必须已有交接单与承运商。

## 3. 与其它主档的关系

- 交接单：`handoverNo` 为外键。
- 承运商主档：`carrierCode` 为外键。
- 物流运单：装车后回写运单发运节点。

## 4. 原型衔接建议

- 页面：`outbound/loading-list`，list 骨架，按发运状态页签。
- 表单抽屉：承运商、车牌、月台、交接单、件数、重量；动作「装车完成」。
