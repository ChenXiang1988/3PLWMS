# 任务池任务（数据字典）

> 实体：任务池任务（Task Pool Item）｜对应原型页面：任务中心 / 任务池与派工（`task` 模块 `task-pool`）
> 定位：跨模块任务的统一派工视图，任务态、设备态与单据态分列。

## 1. 任务字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `taskNo` | 任务号 | String | 24 | 是 | `TK` + 日期 + 流水 | 全局唯一 |
| `taskType` | 任务类型 | Enum | — | 是 | 收货 / 上架 / 拣货 / 复核 / 盘点 / 移库 / 补货 / 加工 / 打包 / 分播 | |
| `docNo` | 单据号 | String | 24 | 是 | 来源单据 | |
| `taskStatus` | 任务状态 | Enum | — | 是 | 待派 / 已派 / 执行中 / 已完成 / 已取消 | |
| `deviceStatus` | 设备状态 | Enum | — | 否 | 待执行 / 执行中 / 已完成 / 失败 | 人工任务为空 |
| `assignee` | 执行人 | String | 50 | 否 | 账号或设备编码 | |
| `priority` | 优先级 | Enum | — | 是 | 高 / 中 / 低 | |
| `retryCount` | 重试次数 | Int | — | 是 | 默认 0 | |
| `plannedAt` | 计划时间 | Datetime | — | 否 | | |
| `startedAt` | 开始时间 | Datetime | — | 否 | | |
| `finishedAt` | 完成时间 | Datetime | — | 否 | | |

## 2. 状态与口径

- 任务态与设备态分离；设备失败不自动回退任务态，需人工重派。
- 取消只允许待派与已派；执行中需先中断。
- 重派保留原任务号，追加派工记录。

## 3. 与其它主档的关系

- 工序单：任务按工序单拆分。
- 执行单元、设备档案：`assignee` 指向人或设备。
- 操作日志：派工与重派写审计。

## 4. 原型衔接建议

- 页面：`task/task-pool`，list 骨架，任务态/设备态/单据态三列。
- 工具条：批量派工、重派；筛选按任务类型与状态。
