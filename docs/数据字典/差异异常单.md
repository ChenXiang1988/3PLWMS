# 差异异常单（数据字典）

> 实体：差异异常单｜对应原型页面：货灵ERP「异常队列」、货灵ERP「本货主费用账单」申诉入口｜字段真值源

约定：差异异常单是收货、盘点、破损丢失、跨货主串货、费用对账等异常的协同载体，由作业任务行上的差异派生，不单独建档。差异源头在任务：任务行记录商品、批次、账面数、实盘数、差异数与差异原因，向上汇总到工序单与计划单；本实体承载货主确认、申诉与处理结果，处理进度全程留痕。异常确认引发的库存调整走台账冲正，不物理删除原记录。

## 3. 与其它主档的关系

- **货主主档**：`ownerCode` 决定可见范围，货灵ERP只看本货主异常单。
- **费用账单**：费用对账类异常回写账单申诉状态，不改写已出账明细。
- **库存台账**：差异确认产生的调整写台账冲正流水，原流水保留。
- **商品档案创建流程**：跨货主串货由扫码拦截登记，退回货灵ERP修改申请资料。

## 4. 原型衔接建议

- 货灵ERP `owner/exception-list` 页签取处理状态四值；工具条「确认」「异议申诉」，表单抽屉录入货主确认意见。
- 列表展示异常单号、异常类型、来源单据、差异数量、处理状态、发生时间、处理人。
- 已处理与已驳回状态只读，处理结果与冲正流水号在详情抽屉可见。
- 异常单不做删除操作，所有状态推进留痕。
- 货灵WMS不建独立页面：差异在收货单、盘点单、拣货单的作业行上登记，向上汇总；货灵WMS的处理动作是复核与确认，入口在对应工序单行抽屉里。
- 货主下发的盘点所生成的差异，货主在委托单据中心看到结论并确认，申诉入口仍在货灵ERP 差异与异常协同。
