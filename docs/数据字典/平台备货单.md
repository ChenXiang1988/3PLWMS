# 平台备货单（数据字典）

> 实体：平台备货单｜对应原型页面：货灵ERP「平台备货单」（`owner` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
平台备货单承接全托管、FBA 等平台仓履约：货主把货发到平台仓或集货仓，需要箱唛、装箱单与入仓预约。它不是消费者发货单，不产生终端运单。

## 4. 与其它主档的关系

- 平台店铺：`shopCode` 外键，一单一店；平台仓与预约规则由平台订单类型配置带出。
- 商品主档：明细 `skuCode` 外键，只允许本货主商品。
- 出库计划单：3PL 仓发货时生成，`bizType=平台备货出库`，`sourceDocType=平台备货单`、`sourceDocNo=replenishNo`；收货方为平台仓。
- 履约单：本单完成发货后形成一条履约单，来源为平台订单或平台备货单，履约方式为平台备货。
- 物流运单：平台备货不产生消费者运单；箱唛、装箱单、预约号替代运单作为交接凭证。

## 5. 原型衔接建议

- `owner/platform-replenish-list`（货灵ERP，list）：备货单号、平台、店铺、平台仓、备货单状态、箱数、品类数、备货数量、预约号、计划入仓日期。
- 状态页签：全部 / 待备货 / 待预约 / 已预约 / 已发货 / 平台收货 / 已完成 / 已取消；筛选：平台、店铺、平台仓、计划入仓日期。
- 工具条：新建、生成箱唛、打印箱唛、生成装箱单、打印装箱单、预约入仓、发货、导出；行详情展示箱唛号、装箱单号、附件名、预约号、预约时间与操作轨迹。
- 自助动作：打印箱唛、打印装箱单只写附件名与操作轨迹，不改变备货单状态，原型不调用打印机。
- 列表按登录货主限定，不提供货主筛选；箱唛与装箱单只展示附件名，不做真实文件上传。
