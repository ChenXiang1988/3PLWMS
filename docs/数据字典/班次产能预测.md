# 班次产能预测（数据字典）

> 实体：班次产能预测（Shift Capacity Forecast）｜对应原型页面：仓网管理 / 仓容与产能规划（`network` 模块 `capacity-plan`）
> 定位：以当前可用人员、设备与已占用产能计算班次余量的派生视图，不代表真实预测模型。

## 1. 指标字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `shift` | 班次 | String | 20 | 是 | 白班 / 中班 / 夜班 | 关联排班档案 |
| `warehouse` | 仓库 | String | 100 | 是 | 关联仓库主档 | |
| `availableStaff` | 可用人员 | Int | — | 是 | 班次内可出勤人员数 | |
| `availableDevices` | 可用设备 | Int | — | 是 | 班次内可用设备数 | 设备档案派生 |
| `theoreticalCapacity` | 理论产能 | Int | — | 是 | 当前人员与设备可完成任务量 | 派生 |
| `occupiedCapacity` | 已占用产能 | Int | — | 是 | 已分配任务折算产能 | 派生 |
| `remainingCapacity` | 预计余量 | Int | — | 是 | 理论产能减已占用产能 | 可为负数 |
| `forecastFinish` | 预计完成 | Datetime / String | — | 否 | 按当前余量估算的完成时间 | 展示层派生 |

## 2. 口径

- 仅根据当前排班、设备可用量和已分配任务计算，未接入实时控制系统。
- `remainingCapacity` 小于 0 时表示班次存在产能缺口，需要调整人员、设备或任务安排。
- `forecastFinish` 是排程参考，不作为对外时效承诺。

## 3. 与其它实体的关系

- 仓库主档：`warehouse` 为外键。
- 排班、人员档案：提供 `shift` 与 `availableStaff`。
- 设备档案：提供 `availableDevices`。

## 4. 原型衔接建议

- 页面：`network/capacity-plan`，分仓容与产能明细、班次产能预测、容量风险三个区块。
- 运营中台可查看跨仓汇总；货灵 WMS 继续使用本仓设备、人员和任务字段，不引入跨仓管理动作。
