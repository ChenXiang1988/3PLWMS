# 设备告警（数据字典）

> 实体：设备告警（Device Alarm）｜对应原型页面：设备与容器 / 告警与故障工单（`resource` 模块 `device-alarm`）
> 定位：设备运行告警与停机记录，可转故障工单。

## 1. 告警字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `alarmNo` | 告警号 | String | 24 | 是 | `DA` + 日期 + 流水 | 全局唯一 |
| `deviceCode` | 设备编码 | String | 20 | 是 | 关联设备档案 | |
| `alarmLevel` | 级别 | Enum | — | 是 | 提示 / 警告 / 严重 | |
| `alarmCode` | 告警码 | String | 20 | 是 | 设备协议返回码 | |
| `raisedAt` | 触发时间 | Datetime | — | 是 | | |
| `handleStatus` | 处理状态 | Enum | — | 是 | 待处理 / 处理中 / 已处理 | |
| `downMinutes` | 停机分钟 | Int | — | 否 | 恢复时计算 | |
| `reviewer` | 复核人 | String | 50 | 否 | | |
| `reviewAt` | 复核时间 | Datetime | — | 否 | | |
| `reasonCategory` | 原因分类 | Enum | — | 否 | 通信中断 / 队列拥堵 / 设备恢复 / 能源不足 / 其他 | 异常原因聚类维度 |
| `repeatRate` | 重复故障率 | Decimal(5,2) | — | 否 | 同类原因重复告警数除以告警数 | 聚类派生 |
| `ruleHit` | 规则命中 | Boolean | — | 否 | 是 / 否 | 自动处置规则命中结果 |

## 2. 状态与口径

- 恢复时写入停机分钟，按触发到恢复计算。
- 转工单后状态置处理中，工单号写故障工单。
- 同一设备同一告警码 30 分钟内合并。

## 3. 与其它主档的关系

- 设备档案：`deviceCode` 为外键。
- 故障工单：从告警转入。
- 设备监控：告警数按本实体计数。

## 4. 原型衔接建议

- 页面：`resource/device-alarm`，list 骨架，按处理状态页签。
- 动作：转工单、恢复；恢复后展示停机分钟。
