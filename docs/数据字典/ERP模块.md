# ERP模块（数据字典）

> 实体：ERP模块｜对应原型页面：货灵运营中台管理端「ERP 运营 / 模块与版本」｜字段真值源

约定：模块是货灵ERP的软件功能单元，版本是软件版本；一个模块可适用一个或多个端。

## 1. 模块标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `moduleCode` | 模块编码 | String | 30 | 是 | 本部署内唯一 | 列表主键 |
| `moduleName` | 模块名称 | String | 40 | 是 | 订单 / 履约 / 售后 / 仓储委托 / 库存 / 商品 / 平台接入 / 账单与服务 / 报表与设置 | 页面展示 |
| `currentVersion` | 当前版本 | String | 20 | 是 | 如 `2026.11` | 软件版本 |
| `applicableApp` | 适用端 | Enum | 30 | 是 | 货灵ERP / 货灵运营中台管理端 / 货灵WMS / 货灵商城 | 页面动作按端显隐 |
| `ownerCount` | 已开通货主数 | Integer | — | 是 | 派生值 | 停用影响面 |
| `moduleStatus` | 状态 | Enum | 20 | 是 | 启用 / 停用 | 页签依据 |
| `updateTime` | 更新时间 | Datetime | — | 是 | 系统写入 | 列表展示 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `active` | 启用 | `enabled` |
| `disabled` | 停用 | `disabled` |

## 2. 关系与规则

- **货主开通**：`modules` 引用 `moduleCode`；停用模块只影响新开通，不影响已有数据。
- **操作日志**：启用、停用、更新版本写全局审计。
- **版本**：更新版本只改版本号与更新时间，不自动改货主配置。
- **不写商业化字段**：不建价格、周期、商业化分层字段。

## 3. 原型衔接建议

- `erp-ops/erp-module-list`（货灵运营中台管理端，list）：列取上表，状态页签两值。
- 动作：启用/停用、查看开通明细、更新版本；只做 toast 与状态流转。
