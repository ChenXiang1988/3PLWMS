# 执行单元档案（数据字典）

> 实体：执行单元档案｜对应原型页面：作业资源 / 执行单元（`resource` 模块，单仓端）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。
执行单元是「某座仓里能承接一类作业的物理区域」，不是组织部门，也不等同于库区。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `unitCode` | 执行单元编码 | String | 20 | 是 | 仓内唯一，业务引用主键 | 建议 `EU` + 4 位序号；不可改 |
| `unitName` | 执行单元名称 | String | 100 | 是 | 现场称呼 | 如「1 号收货月台」 |
| `unitType` | 单元类型 | Enum | — | 是 | 收货区 / 上架暂存区 / 拣货区 / 复核区 / 发货区 / 存储区 | 决定可承接的任务类型 |
| `unitStatus` | 单元状态 | Enum | — | 是 | 启用 / 停用 / 维保 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `active` | 启用 | `enabled` |
| `inactive` | 停用 | `disabled` |
| `maintaining` | 维保 | `pending` |

## 2. 归属与能力

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `warehouseCode` | 所属仓库 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 执行单元必属某一座实体仓 |
| `zoneCode` | 关联库区 | String | 20 | 否 | 关联库区库位 `zoneCode` | 一个单元可跨多个库区 |
| `taskTypes` | 承接任务类型 | Enum(multi) | — | 是 | 收货 / 上架 / 移库 / 拣货 / 复核 / 盘点 / 发货 | 多值逗号拼接展示 |
| `capacity` | 处理能力 | Int | — | 否 | 单位件/小时 | 作业量预测分配依据 |
| `teamCode` | 默认班组 | String | 20 | 否 | 关联班组档案 `teamCode` | 派工时默认候选 |

## 3. 运营与系统字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `businessHours` | 开放时段 | String | 50 | 否 | 如 `08:00-20:00` | 与排班档案呼应 |
| `manager` | 负责人 | String | 50 | 否 | 关联人员档案 `staffCode` | |

| `createTime` | 创建时间 | Datetime | — | 是 | 系统写入 | 列表列 |
| `updateTime` | 更新时间 | Datetime | — | 是 | 系统写入 | |
| `createBy` | 创建人 | String | 50 | 否 | 账号 | 关联 `system` 模块账号 |

## 4. 与其它主档的关系

- 仓库主档：`warehouseCode` 外键，执行单元按仓维护，仓网端不下发执行单元定义。
- 库区库位：`zoneCode` 指向库区；执行单元是作业组织口径，库区是存储位置口径，两者不互相替代。
- 班组档案与人员档案：`teamCode` 给派工默认班组，实际出勤由排班档案按日期决定。
- 设备档案：单元内可用设备靠 `zoneCode` 与设备位置间接关联，不建双向外键。

## 5. 原型衔接建议

- `resource/exec-unit-list`（单仓端，list）：执行单元编码、执行单元名称、单元类型、承接任务类型、所属仓库、处理能力、默认班组、单元状态、创建时间。
- 筛选：单元类型、单元状态、所属仓库；状态页签 全部 / 启用 / 停用 / 维保。
- 行按 `warehouseCode` 归属本仓，不带货主维度。
