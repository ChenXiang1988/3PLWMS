# 人效指标（数据字典）

> 实体：人效指标（Labor Performance）｜对应原型页面：人员与班次 / 人效与准确率（`task` 模块 `staff-performance`）
> 定位：按人员、班组、班次统计任务量、耗时与准确率，只做派生视图。

## 1. 指标字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `staffNo` | 人员编号 | String | 20 | 是 | 关联人员档案 | |
| `teamCode` | 班组 | String | 20 | 是 | 关联班组档案 | |
| `shiftCode` | 班次 | String | 20 | 是 | 关联排班档案 | |
| `statDate` | 统计日期 | Date | — | 是 | | |
| `taskCount` | 任务数 | Int | — | 是 | 已完成任务数 | |
| `avgMinutes` | 平均分钟 | Decimal(8,2) | — | 是 | 总耗时除以任务数 | |
| `errorCount` | 错误数 | Int | — | 是 | 差异与返工计数 | |
| `accuracyRate` | 准确率 | Decimal(5,2) | — | 是 | 1 减错误数除以任务数 | |

## 2. 口径

- 任务数只算已完成；取消不计。
- 准确率按差异与返工口径统计，不按扫描次数。
- 人效按出勤工时折算，缺勤不参与。

## 3. 与其它主档的关系

- 人员档案、班组档案、排班档案：三个外键。
- 任务池任务：按 `assignee` 与完成时间汇总。
- 货主报表指标：人效口径与运营日报共用。

## 4. 原型衔接建议

- 页面：`task/staff-performance`，report 骨架，5 个指标卡 + 按班组分节。
- 口径说明走 `tipKey`，不写常显提示。
