# 结算单（数据字典）

> 实体：结算单（Settlement）｜对应原型页面：计费结算 / 结算单（`billing` 模块 `settlement-list`）
> 定位：把同一货主、同一账期的多张费用账单汇总成一张结算单，承接开票与收款。

## 1. 标识与金额

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `settlementNo` | 结算单号 | String | 24 | 是 | `ST` + 日期 + 流水 | 全局唯一 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 列表显示货主名称 |
| `billType` | 账单类型 | Enum | — | 是 | 仓租 / 作业费 / 增值服务 / 混合 | |
| `billPeriod` | 账期 | String | 20 | 是 | `YYYY-MM` | |
| `billCount` | 账单数 | Int | — | 是 | 关联费用账单计数 | 派生 |
| `sourceNo` | 来源编号 | String | 120 | 否 | 多张账单号逗号分隔 | 抽屉明细可反查 |
| `currency` | 币种 | Enum | — | 是 | CNY / USD / EUR | 默认 CNY |
| `taxRate` | 税率 | Decimal(5,2) | — | 是 | 百分比 | |
| `amountBeforeTax` | 不含税金额 | Decimal(14,2) | — | 是 | 账单合计除以税率换算 | |
| `amountWithTax` | 含税金额 | Decimal(14,2) | — | 是 | 不含税金额加税额 | |
| `invoiceStatus` | 开票状态 | Enum | — | 是 | 未开票 / 已开票 | |
| `settlementStatus` | 结算状态 | Enum | — | 是 | 待审核 / 已发送 / 已确认 / 已完成 / 已驳回 | |
| `approver` | 审批人 | String | 50 | 否 | 账号姓名 | |
| `createdAt` | 创建时间 | Datetime | — | 是 | 系统写入 | |

## 2. 状态与口径

- 状态链：生成 → 审核 → 发送 → 确认 → 完成；驳回退回待审核并留原因。
- 开票状态与结算状态正交：结算完成不要求已开票，已开票也不等于已收款。
- 金额以含税金额入账，不含税金额只作展示与对账。

## 3. 与其它主档的关系

- 费用账单：一张结算单汇总多张同货主同账期账单。
- 发票与收款：一张结算单可对应多张发票与多次收款。
- 货主主档：`ownerCode` 为外键。

## 4. 原型衔接建议

- 页面：`billing/settlement-list`，list 骨架，未开票/已开票双页签带计数。
- 抽屉：抬头 + 账单明细子表 + 审批轨迹；动作走 `data-form-action`。
