# 结算单（数据字典）

> 实体：结算单（Settlement）｜对应原型页面：计费结算 / 结算单（`billing` 模块 `settlement-list`）
> 定位：把同一货主、同一账期的多张费用账单汇总成一张结算单，承接开票与收款。

## 1. 标识与金额

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `settlementNo` | 结算单号 | String | 24 | 是 | `ST` + 日期 + 流水 | 全局唯一 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 列表显示货主名称 |
| `billType` | 账单类型 | Enum | — | 是 | 仓租 / 作业费 / 增值服务 / 混合 | 取纳入账单的类型 |
| `billPeriod` | 账期 | String | 20 | 是 | `YYYY-MM` | |
| `periodStart` | 账期开始 | Date | — | 是 | 账期首日 | 同货主账期不重叠 |
| `periodEnd` | 账期结束 | Date | — | 是 | 账期末日 | 与账期边界口径一致 |
| `billCount` | 账单数 | Int | — | 是 | 关联费用账单计数 | 派生 |
| `sourceNo` | 来源编号 | String | 120 | 否 | 多张账单号逗号分隔 | 抽屉明细可反查 |
| `currency` | 币种 | Enum | — | 是 | CNY / USD / EUR | 默认 CNY |
| `taxRate` | 税率 | Decimal(5,2) | — | 是 | 百分比 | 取纳入账单的加权税率，多税率保留两位 |
| `amountBeforeTax` | 不含税金额 | Decimal(14,2) | — | 是 | `amountWithTax / (1 + 税率)` | 不是除以税率 |
| `amount` | 应收金额 | Decimal(14,2) | — | 是 | 明细含税金额合计 | 两位小数 |
| `amountWithTax` | 含税金额 | Decimal(14,2) | — | 是 | 不含税金额加税额 | 与 `amount` 同口径 |
| `invoiceStatus` | 开票状态 | Enum | — | 是 | 未开票 / 已开票 | 由发票派生 |
| `settlementStatus` | 结算状态 | Enum | — | 是 | 待审核 / 已发送 / 已确认 / 已完成 / 已驳回 | 页签与动作依据 |
| `approver` | 审批人 | String | 50 | 否 | 账号姓名 | 取审批流节点 |
| `createdAt` | 创建时间 | Datetime | — | 是 | 系统写入 | |

## 2. 状态与口径

- 状态链：生成 → 审核 → 发送 → 确认 → 完成；驳回退回待审核并留原因。
- 开票状态与结算状态正交：结算完成不要求已开票，已开票也不等于已收款。
- 金额以含税金额入账，不含税金额只作展示与对账；不含税金额按 `含税 / (1 + 税率)` 换算，不按 `含税 / 税率`。
- 多税率账单（如仓储 6% + 运输 9%）的 `taxRate` 为加权税率，`amountBeforeTax` 以账单明细不含税金额汇总为准。
- 一张结算单只汇总同一货主、同一账期、已确认的账单；存在待确认或已申诉账单时不得生成结算单。
- 账单的 `invoiceStatus` 由结算单派生，账单页不单独维护开票状态。

## 3. 与其它主档的关系

- 费用账单：一张结算单汇总多张同货主同账期账单；`sourceNo` 逐张回指。
- 发票与收款：一张结算单可对应多张发票与多次收款；收款状态只在发票维护。
- 货主主档：`ownerCode` 为外键。
- 服务目录与报价：税率与单价通过费用账单明细快照带入，不在结算单改写。

## 4. 原型衔接

- 页面：`billing/settlement-list`，list 骨架；页签取开票状态「未开票 / 已开票」带计数，结算状态降为列。
- 工具条「生成结算单」；抽屉抬头 + 账单明细子表 + 审批轨迹；动作审核、发送、确认、完成、账单调整。
- 抽屉内账单明细列：账单编号、账期、费用合计、开票状态、账单状态。
- 金额列统一「￥」加两位小数，右对齐。
