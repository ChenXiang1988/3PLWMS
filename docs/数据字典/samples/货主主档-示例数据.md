## 三、如何扩展 / 新增模拟货主

1. 先定 `ownerType` → 决定 `supportedBizModel` / `qualifications` / `defaultTempZone` 的取值区间。
2. 填 `serviceWarehouses`（引用已存在的 `仓库主档.warehouseCode`）；务必同步在对应仓库的 `serviceOwners` 里加回本编码，保持互指闭环。
3. 补联系人、资质、合同与计费（`billingBasis` / `settlementCycle` / `creditLimit`）。
4. 收尾系统字段；并在 `../log.md` 记录变更（遵循字典管理纪律）。

> 注：本文件为 `samples/` 子目录内容，`check.mjs` 仅校验实体文档与索引/日志，不扫描子目录；其字段仍应人工对齐 `../货主主档.md`。
