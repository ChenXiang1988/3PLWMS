## 三、如何扩展 / 新增模拟仓

1. 先定 `warehouseType` → 决定 `buildingStructure` / `floorCount` / `floors` / `tempZones` / `supportedBiz` / `supportedBizModel` 的取值区间。
2. 多层 / 立体库须拆 `floors[]`（每层 `floorArea`，且 Σ `floorArea` = `totalArea`），单层仅一条。
3. 据类型填地理与容量（用真实量级，不要写 `test` / `demo` / `示例数据` 等过程词）。
4. 补运营、设施、计费、管理字段；`serviceOwners` 引用已存在的货主编码。
5. 库区与库位（含库区类型、库位类型）不在此填，归 `../库区库位.md`。
6. 收尾状态与系统字段（`createTime` / `updateTime` / `createBy`）；并在 `../log.md` 记录变更（遵循字典管理纪律）。

> 注：本文件为 `samples/` 子目录内容，`check.mjs` 仅校验实体文档与索引/日志，不扫描子目录，因此模拟数据不受字典结构校验约束；但其字段仍应人工对齐 `../仓库主档.md` 与 `../库区库位.md`。
