## 4. 库位与拣货坐标

1F 共 **64** 个库位（`flow` ×48 + `pallet` ×16），坐标按 `巷道-排-层-位` 连续生成，完整清单见 [`库区库位-示例数据.md`](库区库位-示例数据.md) 第三节。

**拣货路顺示例**：一单跨 3 个巷道，按 `aisleNo` 分组、组内按 `(bayNo, levelNo, posNo)` 升序后的行走顺序：

```text
A01-01-01-02 (flow) → A01-02-03-04 (flow) → A02-01-01-01 (flow) → A02-02-02-03 (flow) → B01-03-02-02 (pallet)
```

> 算法直接消费库位坐标字段，无需解析 `binCode`；同巷道内可进一步做 S 形优化。
