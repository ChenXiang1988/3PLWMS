## 三、如何扩展 / 新增模拟承运商

1. 先定 `carrierType` → 决定 `supportedTempZone` / `vehicleTypes` / `serviceBiz` 取值区间（冷链必含 冷藏/冷冻）。
2. 填 `serviceRegions` 与 `serviceWarehouses`（引用已存在的 `仓库主档.warehouseCode`）。
3. 定对接方式：`apiSupported=是` 时 `interfaceType` 必填且给 `trackingUrl`；`否` 时一般走手动。
4. 补合同与计费（`billingMode` / `settlementCycle` / `accountPeriod`）与 SLA（时效 / 准点率 / 破损率）。
5. 收尾系统字段，并在 `../log.md` 记录变更。

> 注：本文件为 `samples/` 子目录内容，`check.mjs` 仅校验实体文档与索引/日志，不扫描子目录；其字段仍应人工对齐 `../承运商主档.md`。
