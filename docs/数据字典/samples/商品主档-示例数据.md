## 三、如何扩展 / 新增模拟商品

1. 先定 `ownerCode`（必须属于已有货主），据此定 `tempZone`、`unit` 与 `allocationRule` 的取值区间（与货主 `defaultTempZone`、仓库温区对齐）。
2. 决定是否 `shelfLifeManaged` / `batchManaged`：效期商品 `allocationRule=FEFO` 且 `productionDateRequired=是`；非效期一般 `FIFO`。
3. 填包装与计量（`packSpec`/`qtyPerPack`/`grossWeight`/`volume`…）与 `visibleWarehouses`（引用已存在仓库，且与货主 `serviceWarehouses` 取交集）。
4. 收尾 `version`/`effectiveTime`/系统字段，并在 `../log.md` 记录变更。

> 注：本文件为 `samples/` 子目录内容，`check.mjs` 仅校验实体文档与索引/日志，不扫描子目录；其字段仍应人工对齐 `../商品主档.md`。
