# 服务目录与报价（数据字典）

> 实体：服务目录与报价（Service Catalog and Quote）｜对应原型页面：服务关系 / 服务目录与报价（`network` 模块 `service-catalog`）
> 定位：仓网对外提供的服务项目与按合同、货主、仓库维度的报价，是费用规则的唯一价格来源。

## 1. 服务与报价

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `itemCode` | 项目编码 | String | 20 | 是 | 全局唯一 | 费用规则以 `itemCode` 引用 |
| `itemName` | 项目名称 | String | 60 | 是 | 如「仓租」「入库上架费」 | 费用账单 `feeItem` 取值来源 |
| `contractNo` | 合同号 | String | 24 | 否 | 关联仓储服务协议 | |
| `category` | 服务类别 | Enum | — | 是 | 仓储 / 搬运 / 包装 / 质检 / 加工 / 运输 | |
| `unit` | 计费单位 | Enum | — | 是 | 件 / 托 / 公斤 / 立方米 / 平方米 / 单 | 只表达计量单位，不写「按件」 |
| `currency` | 币种 | Enum | — | 是 | CNY / USD / EUR | |
| `price` | 标准价 | Decimal(12,4) | — | 是 | 单价 | 价格唯一来源 |

## 2. 状态与口径

- 报价按「合同 + 货主 + 仓库 + 有效期」命中，最具体优先。
- 改价不改旧版本，新增版本并停用旧版本；历史账单保留出账时的单价与税率快照。
- 最低/最高收费只对按量计费项目生效；0 表示不设下限或不设上限，列表分别显示「—」与「不限」。
- 计费单位与计费周期分开：单位回答「按什么量」，周期回答「按什么时间粒度结算」。
- 服务目录是价格的唯一来源；费用规则只引用 `itemCode`，不另存单价、最低收费、最高收费。

## 3. 与其它主档的关系

- 仓储服务协议：`contractNo` 为外键。
- 货主主档、仓库主档：`owner`、`warehouse` 为外键。
- 费用规则：规则引用 `itemCode`，并把 `itemName`、参考单价、最低/最高收费带到规则页只读展示。
- 费用账单：明细的 `feeItem` 取 `itemName`，`unitPrice` 与 `taxRate` 取出账时报价版本快照。

## 4. 原型衔接

- 页面：`network/service-catalog`，list 骨架，按服务类别筛选。
- 列：项目编码、项目名称、合同号、服务类别、计费单位、币种、标准价、最低收费、最高收费、计费周期、税率、适用货主、适用仓库、版本、生效起、有效期至、状态。
- 行内「改价」打开报价表单抽屉；动作确认改价后生成新版本。
- 费用规则页只读展示「参考单价」，改价入口不在计费结算段。
