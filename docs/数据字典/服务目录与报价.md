# 服务目录与报价（数据字典）

> 实体：服务目录与报价（Service Catalog and Quote）｜对应原型页面：服务关系 / 服务目录与报价（`network` 模块 `service-catalog`）
> 定位：仓网对外提供的服务项目与按合同、货主、仓库维度的报价。

## 1. 服务与报价

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `itemCode` | 项目编码 | String | 20 | 是 | 全局唯一 | |
| `itemName` | 项目名称 | String | 60 | 是 | 如「入库卸货费」 | |
| `contractNo` | 合同号 | String | 24 | 否 | 关联仓储服务协议 | |
| `category` | 服务类别 | Enum | — | 是 | 仓储 / 搬运 / 包装 / 质检 / 加工 / 运输 | |
| `unit` | 计费单位 | Enum | — | 是 | 件 / 托 / 公斤 / 立方米 / 天 / 单 | |
| `currency` | 币种 | Enum | — | 是 | CNY / USD / EUR | |
| `basePrice` | 标准价 | Decimal(12,4) | — | 是 | 单价 | |
| `minCharge` | 最低收费 | Decimal(12,2) | — | 否 | 不足最低收费按最低收 | |
| `maxCharge` | 最高收费 | Decimal(12,2) | — | 否 | 超过按最高收 | |
| `billingCycle` | 计费周期 | Enum | — | 是 | 按单 / 按件 / 按重量 / 按体积 / 按天 / 按月 | |
| `ownerCode` | 适用货主 | String | 20 | 否 | 空表示全部货主 | |
| `warehouseCode` | 适用仓库 | String | 20 | 否 | 空表示全部仓库 | |
| `version` | 版本 | String | 10 | 是 | 改价递增 | |
| `effectiveFrom` | 生效开始 | Date | — | 是 | | |
| `effectiveTo` | 生效结束 | Date | — | 否 | 空表示长期 | |

## 2. 状态与口径

- 报价按「合同 + 货主 + 仓库 + 有效期」命中，最具体优先。
- 改价不改旧版本，新增版本并停用旧版本。
- 最低/最高收费只对按量计费项目生效。

## 3. 与其它主档的关系

- 仓储服务协议：`contractNo` 为外键。
- 货主主档、仓库主档：`ownerCode`、`warehouseCode` 为外键。
- 费用规则：报价是规则的价格来源，规则引用 `itemCode`。

## 4. 原型衔接建议

- 页面：`network/service-catalog`，list 骨架，按服务类别筛选。
- 表单抽屉：合同、单位、标准价、最低最高、周期、适用范围、有效期；动作「改价」。
