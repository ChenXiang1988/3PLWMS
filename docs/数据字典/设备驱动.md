# 设备驱动（数据字典）

> 实体：设备驱动（Device Driver）｜对应原型页面：设备与容器 / 驱动与协议（`resource` 模块 `device-driver`）
> 定位：设备接入的驱动与协议配置，按设备族维护连接与心跳。

## 1. 驱动字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `driverCode` | 驱动编码 | String | 20 | 是 | 全局唯一 | |
| `deviceType` | 设备类型 | Enum | — | 是 | 叉车 / AGV / 输送线 / 扫码枪 / 打印机 / 其他 | |
| `protocol` | 协议 | Enum | — | 是 | TCP / HTTP / MQTT / Modbus | |
| `endpoint` | 端点 | String | 120 | 是 | 地址或队列名 | |
| `heartbeatSeconds` | 心跳秒数 | Int | — | 是 | 默认 30 | |
| `connectStatus` | 连接状态 | Enum | — | 是 | 已连接 / 未连接 / 连接失败 | |
| `lastTestAt` | 最近测试时间 | Datetime | — | 否 | | |

## 2. 状态与口径

- 测试连接只更新连接状态与时间，不改协议。
- 心跳超时两倍判未连接。
- 一个设备类型可以有多套驱动，按设备档案引用。

## 3. 与其它主档的关系

- 设备档案：按 `deviceType` 与驱动匹配。
- 设备监控：心跳与连接状态由此派生。
- 设备告警：连接失败可触发告警。

## 4. 原型衔接建议

- 页面：`resource/device-driver`，list 骨架，按连接状态页签。
- 动作：测试连接；表单抽屉只改端点与心跳。
