# 发票与收款（数据字典）

> 实体：发票与收款（Invoice and Receipt）｜对应原型页面：计费结算 / 发票与收款（`billing` 模块 `invoice-list`）
> 定位：登记结算单开出的发票与收到的款项，跟踪未收、部分收与逾期。

## 1. 标识与金额

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `invoiceNo` | 发票号 | String | 24 | 是 | 发票代码 + 号码 | 全局唯一 |
| `settlementNo` | 结算单号 | String | 24 | 是 | 关联结算单 | |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | |
| `invoiceType` | 发票类型 | Enum | — | 是 | 增值税专用发票 / 增值税普通发票 / 电子发票 | |
| `currency` | 币种 | Enum | — | 是 | CNY / USD / EUR | |
| `taxRate` | 税率 | Decimal(5,2) | — | 是 | 百分比 | |
| `amount` | 开票金额 | Decimal(14,2) | — | 是 | 含税金额 | |
| `attachmentName` | 附件 | String | 120 | 否 | 发票文件名 | 不存二进制 |
| `invoicedAt` | 开票时间 | Datetime | — | 是 | | |
| `receivedAmount` | 已收金额 | Decimal(14,2) | — | 是 | 多次收款累计 | |
| `receiveStatus` | 收款状态 | Enum | — | 是 | 待收款 / 部分收款 / 已收款 / 逾期 | |
| `dueDate` | 到期日 | Date | — | 是 | 按合同账期计算 | |

## 2. 状态与口径

- 收款状态由已收金额与开票金额、到期日派生，不手工改。
- 逾期 = 到期日早于当前日期且未收足。
- 一张发票可对应多次收款，收款记录在抽屉内追加。

## 3. 与其它主档的关系

- 结算单：`settlementNo` 为外键。
- 货主主档：`ownerCode` 为外键。
- 费用账单：通过结算单间接关联。

## 4. 原型衔接建议

- 页面：`billing/invoice-list`，list 骨架，按收款状态页签。
- 抽屉：发票信息 + 收款记录 + 附件名；动作「登记收款」。
