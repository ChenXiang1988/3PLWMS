# 发票与收款（数据字典）

> 实体：发票与收款（Invoice and Receipt）｜对应原型页面：计费结算 / 发票与收款（`billing` 模块 `invoice-list`）
> 定位：登记结算单开出的发票与收到的款项，跟踪未收、部分收与逾期。

## 1. 发票

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `invoiceNo` | 发票号 | String | 24 | 是 | 发票代码 + 号码 | 全局唯一 |
| `settlementNo` | 结算单号 | String | 24 | 是 | 关联结算单 | 结算单须为已开票或待开票 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | |
| `invoiceType` | 发票类型 | Enum | — | 是 | 增值税专用发票 / 增值税普通发票 / 电子发票 | |
| `currency` | 币种 | Enum | — | 是 | CNY / USD / EUR | 与结算单一致 |
| `taxRate` | 税率 | Decimal(5,2) | — | 是 | 百分比 | 与结算单一致；多税率取加权 |
| `amount` | 开票金额 | Decimal(14,2) | — | 是 | 含税金额 | 不超过结算单含税金额 |
| `attachmentName` | 附件 | String | 120 | 否 | 发票文件名 | 不存二进制 |
| `invoicedAt` | 开票时间 | Date | — | 是 | | |
| `receivedAmount` | 已收金额 | Decimal(14,2) | — | 是 | 多次收款累计 | 由收款记录汇总 |
| `receiveStatus` | 收款状态 | Enum | — | 是 | 待收款 / 部分收款 / 已收款 / 逾期 | 由金额与到期日派生 |
| `dueDate` | 到期日 | Date | — | 是 | 按合同账期计算 | |

## 2. 收款记录

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `receiveNo` | 收款号 | String | 24 | 是 | 系统生成 | 收款记录主键 |
| `invoiceNo` | 发票号 | String | 24 | 是 | 关联发票 | |
| `receiveDate` | 收款时间 | Date | — | 是 | | |
| `receiveAmount` | 收款金额 | Decimal(14,2) | — | 是 | 累加到发票已收金额 | |
| `receiveMethod` | 收款方式 | Enum | — | 是 | 银行转账 / 银行承兑 / 现金 / 其他 | |
| `voucherNo` | 收款凭证 | String | 40 | 否 | 银行流水号或凭证号 | |
| `operator` | 登记人 | String | 30 | 是 | 取登录账号 | |

## 3. 状态与口径

- 收款状态由已收金额与开票金额、到期日派生，不手工改：未收足且未到期为待收款；未收足且已到期为逾期；部分收为部分收款；收足为已收款。
- 逾期 = 到期日早于当前日期且未收足。
- 一张发票可对应多次收款，收款记录只追加，不退改；冲正另记负数记录。
- 发票金额不得超过结算单含税金额；结算单未开票时不得登记发票。
- 一张结算单可对应多张发票与多次收款。

## 4. 与其它主档的关系

- 结算单：`settlementNo` 为外键；发票的币种与税率与结算单一致。
- 货主主档：`ownerCode` 为外键。
- 费用账单：通过结算单间接关联。
- 收款记录：挂在发票下，`receivedAmount` 由收款记录汇总，不单独改写。

## 5. 原型衔接

- 页面：`billing/invoice-list`，list 骨架，按收款状态页签。
- 列：发票号、结算单号、货主、发票类型、币种、税率、开票金额、附件、开票时间、已收金额、收款状态、到期日。
- 抽屉：发票信息 + 收款记录子表 + 附件名；动作「登记收款」打开收款表单。
- 演示数据中每张发票的 `settlementNo` 必须指向已开票或待开票的结算单，收款金额累计不得超过开票金额。
