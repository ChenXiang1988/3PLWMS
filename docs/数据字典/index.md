# 数据字典索引（货灵供应链运营平台）

本文件夹是货灵供应链运营平台的**数据字典真值源**。每个业务实体一个文档，本索引统一管理，变更记入 `log.md`。

## 使用规则

1. **新增实体**：在文件夹内新建 `<实体名>.md`，按 `仓库主档.md` 的字段表结构登记，并在本索引追加一行、在 `log.md` 追加一条。
2. **修改字段**：改对应实体文档，并在 `log.md` 追加变更记录；**只改文档不记日志视为未完成**。
3. **原型取数**：生成原型页面时，列名与取值逐字读对应实体文档，禁止凭印象新增或重命名；需在 `glossary.md` 登记后方可画页面。
4. **提交前自检**：改完文档跑 `node check.mjs`（位于本文件夹），必须零错误再提交；脚本校验链接闭环、状态合法、字段表规范与禁用词。
5. **禁语边界**：禁语表（租户、订阅、套餐等）只在实体字段与界面文案生效，防的是把 SaaS 概念写进字典；方案文档描述货灵ERP 对多个卖家的隔离时可用「租户模型」，但须注明它不是 SaaS 租户——本项目单实例单主体，多卖家是业务维度，不做多租户架构。
