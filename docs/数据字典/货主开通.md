# 货主开通（数据字典）

> 实体：货主开通｜对应原型页面：货灵运营中台管理端「ERP 运营 / 货主开通」｜字段真值源

约定：货主开通是货主与货灵ERP的软件开通关系，不是货主主档本身；一个货主当前一条开通记录。产品文案统一写「货主开通」，不使用商业化账号分层用语。

## 1. 开通标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 列表主键 |
| `ownerName` | 货主名称 | String | 60 | 是 | 取货主主档 | 列表展示 |
| `signStatus` | 签约状态 | Enum | 20 | 是 | 已签约 / 待签约 | 未签约不允许开通 |
| `erpStatus` | ERP 状态 | Enum | 20 | 是 | 见状态枚举 | 页签依据 |
| `moduleCount` | 模块数 | Integer | — | 是 | 已开通模块数 | 列表展示 |
| `version` | 版本 | String | 20 | 是 | 如 `2026.11` | 软件版本，不是商业化分层 |
| `expireDate` | 有效期 | Date | — | 是 | 到期日 | 到期不自动停用，由运营中台提醒 |
| `shopCount` | 店铺数 | Integer | — | 是 | 平台店铺数 | 只读汇总 |
| `accountCount` | 账号数 | Integer | — | 是 | 货灵ERP货主账号数 | 只读汇总，不管理账号 |
| `lastActive` | 最近活跃 | Datetime | — | 否 | 最近登录或业务操作时间 | 列表展示 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `pending` | 待开通 | `pending` |
| `active` | 已开通 | `enabled` |
| `disabled` | 已停用 | `disabled` |

## 2. 模块与操作

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `modules` | 已开通模块 | multi | — | 否 | 订单 / 履约 / 售后 / 仓储委托 / 库存 / 商品 / 商城店铺 / 平台接入 / 账单与服务 / 报表与设置 | 只决定可见模块，不写业务数据 |
| `openTime` | 开通时间 | Datetime | — | 否 | 系统写入 | 首次开通 |
| `disableTime` | 停用时间 | Datetime | — | 否 | 系统写入 | 停用不删除数据 |
| `remark` | 备注 | String | 300 | 否 | 自由文本 | 不进列表列 |

## 3. 与其它主档的关系

- **货主主档**：`ownerCode` 决定归属；货主主档管主体，本档管 ERP 开通。
- **平台店铺**：`shopCount` 只读汇总，不复制店铺字段。
- **子账号**：`accountCount` 只读汇总；货主账号由货灵ERP管理，本档不提供账号增删改。
- **操作日志**：开通、停用、调整有效期、代维进入写全局审计。

## 4. 原型衔接建议

- `erp-ops/erp-tenant-list`（货灵运营中台管理端，list）：列取上表，状态页签取三值。
- 行操作：开通/停用、调整有效期、模块配置、代维进入、查看审计；代维只读并 toast。
- 本页不出现货主账号列表、角色配置与登录凭证。
