# ERP服务费账单（数据字典）

> 实体：ERP服务费账单｜对应原型页面：货灵ERP「服务费账单」、货灵运营中台管理端「软件服务费」
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
ERP服务费账单收的是货灵ERP 的软件服务费，**与仓储费用账单两套账分开**，不合并、不互相冲抵。收费对象是注册账号，未签约也能出账；仓储费用账单的收费对象是签约货主，两者口径不同。账单与计费项目统一按服务费口径命名，不引入按周期预收的说法。

## 1. 账单标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `billNo` | 账单编号 | String | 24 | 是 | 全局唯一，业务引用主键 | `EB` + 年月 + 4 位流水；不可改 |
| `accountCode` | 账号编码 | String | 20 | 是 | 货灵ERP 注册账号 | 与货主编码分开，未签约账号也有账单 |
| `ownerCode` | 货主编码 | String | 20 | 否 | 已签约时回填 | 关联货主主档 |
| `billMonth` | 账单月份 | String | 7 | 是 | `YYYY-MM` | 列表列 |
| `billStatus` | 账单状态 | Enum | — | 是 | 待确认 / 已确认 / 已开票 / 已付款 / 已取消 | 见状态枚举 |
| `billAmount` | 账单金额 | Decimal(12,2) | — | 是 | 明细金额之和 | 列表列 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `pending` | 待确认 | `pending` |
| `confirmed` | 已确认 | `enabled` |
| `invoiced` | 已开票 | `info` |
| `paid` | 已付款 | `disabled` |
| `cancelled` | 已取消 | `disabled` |

## 2. 计费明细

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `chargeItem` | 计费项目 | Enum | — | 是 | 账号数 / 订单量 / 功能模块 | 按当期实际用量结算 |
| `chargeQty` | 计费数量 | Int | — | 是 | 按计费项目口径取数 | 账号数取月末在用数 |
| `unitPrice` | 单价 | Decimal(12,2) | — | 是 | 取当期报价 | |
| `amount` | 金额 | Decimal(12,2) | — | 是 | 计费数量乘单价 | |
| `chargeDesc` | 计费说明 | String | 200 | 否 | 阶梯口径或调整原因 | 调整必须留痕 |

## 3. 与仓储费用账单的分工

| 维度 | ERP服务费账单 | 费用账单 |
| --- | --- | --- |
| 收费对象 | 货灵ERP 注册账号 | 签约货主 |
| 费用性质 | 软件服务费 | 仓租、入库操作费、出库操作费、增值服务费 |
| 出账主体 | 软件服务方 | 仓网运营方 |
| 是否需签约 | 否 | 是，需仓储服务协议 |
| 账期依据 | 计费周期 | 仓储服务协议的账期 |

两套账的账单编号、状态机、开票流程各自独立；货灵ERP账单页分两个入口，不做合并汇总，避免一张账单混两类费用。

## 4. 与其它主档的关系

- 货主主档：`ownerCode` 外键，已签约时回填；未签约账号只记 `accountCode`。
- 仓储服务协议：是否签约影响计费项目，不影响出账能力；签约后可增加仓储相关功能模块的用量。
- 费用账单：两者平行，不互相引用金额，不合并出账。
- 子账号：`chargeItem=账号数` 时，计费数量取该账号下在用子账号与主账号之和。

## 5. 原型衔接建议

- 货灵ERP `owner/service-bill-list`（list）：账单编号、账单月份、计费项目、账单金额、账单状态、开票时间。
- 货灵运营中台管理端 `network/erp-bill-list`（list）：账单编号、账号编码、货主、账单月份、账单金额、账单状态；工具条：确认、开票、导出。
- 状态页签：全部 / 待确认 / 已确认 / 已开票 / 已付款 / 已取消；筛选：账单月份、计费项目。
- 行详情抽屉：抬头取账单编号、账号编码、货主、账单月份、账单金额；明细取计费项目、计费数量、单价、金额、计费说明；附开票与付款记录。
- 货灵ERP只读，不提供账单编辑与合并入口；与仓储费用账单并列两个菜单。
