# 分播任务（数据字典）

> 实体：分播任务（Sortation Task）｜对应原型页面：发货作业 / 分播播种（`outbound` 模块 `sort-task`）
> 定位：波次拣货后的分播播种，承接两级容器与播种墙格口。

## 1. 分播字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `sortNo` | 分播号 | String | 24 | 是 | `ST` + 日期 + 流水 | 全局唯一 |
| `waveNo` | 波次 | String | 24 | 是 | 关联波次计划 | |
| `stationCode` | 工作站 | String | 20 | 是 | 关联执行单元 | |
| `firstContainerNo` | 一次下架容器 | String | 24 | 是 | 拣货容器 | |
| `secondContainerNo` | 分拣容器 | String | 24 | 否 | 播种容器 | |
| `gridCode` | 格口 | String | 20 | 是 | 播种墙格口 | |
| `barcode` | 条码 | String | 40 | 否 | 商品条码 | |
| `orderCount` | 订单数 | Int | — | 是 | 本格口覆盖订单数 | |
| `pickedQty` | 已拣数 | Decimal(14,3) | — | 是 | | |
| `sortStatus` | 分播状态 | Enum | — | 是 | 待分播 / 分播中 / 已结格 | |

## 2. 状态与口径

- 格口三色：蓝色待绑定、白色可拣、绿色 SKU 有效。
- 结格后不放新订单；未拣完的差异转异常。
- 两级容器必须绑定后才能开始分播。

## 3. 与其它主档的关系

- 波次计划：`waveNo` 为外键。
- 容器档案：两级容器编码为外键。
- 拣货单：按波次与格口汇总已拣数。

## 4. 原型衔接建议

- 页面：`outbound/sort-task`，list 骨架，按状态页签。
- 抽屉：波次、工作站、两级容器、格口、条码、订单数、已拣数；动作「结格」。
