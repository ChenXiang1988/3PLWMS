# 变体（数据字典）

> 实体：变体（Variant）｜对应原型页面：商品 / SPU 列表行抽屉（`owner` 模块 `spu-list`）
> 定位：SPU 下的规格层，一个 SPU 可有多个变体，对应不同颜色、尺码或包装。

## 1. 变体字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `variantCode` | 变体编码 | String | 24 | 是 | `VR` + 流水 | 全局唯一 |
| `spuCode` | SPU 编码 | String | 24 | 是 | 关联 SPU | |
| `variantName` | 变体名称 | String | 80 | 是 | | |
| `spec` | 规格 | String | 80 | 否 | 颜色、尺码、包装 | |
| `barcode` | 条码 | String | 40 | 否 | 同货主内唯一 | |
| `price` | 参考价 | Decimal(12,2) | — | 否 | | |
| `variantStatus` | 状态 | Enum | — | 是 | 启用 / 停用 | |

## 2. 状态与口径

- 同一 SPU 下变体名称不重复。
- 条码按货主唯一；跨货主可重复。
- 停用变体不影响已建 Listing。

## 3. 与其它主档的关系

- SPU：`spuCode` 为外键。
- 商品主档：仓储 SKU 可关联一个变体。
- 平台 Listing：按变体粒度推送。

## 4. 原型衔接建议

- 页面：并入 `owner/spu-list` 行抽屉「商品详情」页签，不单开页。
- 抽屉字段：变体编码、变体名称、规格、条码、参考价、状态。
