# 平台售后单（数据字典）

> 实体：平台售后单｜对应原型页面：货灵ERP「平台售后单」（`owner` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
平台售后单承接平台侧的退款、退货退款、换货、平台介入与索赔。售后处理不改写原订单终态；仓发货退货生成售后入库计划单，自发货退货在 ERP 内闭环，平台备货与全托管只读。

## 4. 与其它主档的关系

- 平台订单：`orderNo` 外键，售后不改写原订单状态；原订单停留在已发货、已签收或已完成。
- 平台店铺：`shopCode` 外键，售后按店铺与货主隔离；同一平台售后号只落一条记录。
- 入库计划单：仓发货退货生成售后入库计划单，`bizType=售后入库`，`sourceDocType=平台售后单`、`sourceDocNo=afterSaleNo`；固定原发货仓，不得超退。
- 出库订单：换货补发新建履约单与出库计划单，回指本售后单；原履约单不删。
- 物流运单：退货物流不回写原发货运单；原运单只读留痕。

## 5. 原型衔接建议

- `owner/platform-aftersale-list`（货灵ERP，list）：售后单号、平台售后号、原订单、售后类型、退款金额、售后状态、退货物流、处理时限。
- 状态页签：全部 / 待处理 / 待买家退货 / 待收货 / 退款中 / 已完成 / 已关闭 / 平台介入；筛选：平台、店铺、售后类型、售后状态。
- 工具条：同意、拒绝、确认收货、退款、生成售后入库计划单、导出；行详情展示原因、退货物流、处理记录与回传状态。
- 列表按登录货主限定，不提供货主筛选；仓发货才显示「生成售后入库计划单」，自发货与平台备货不显示。
