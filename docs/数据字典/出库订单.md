# 出库订单（数据字典）

> 实体：出库订单｜对应原型页面：出库管理 / 出库订单、拣货作业、发货交接（`outbound` 模块，单仓端）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。
出库订单是货主委托出库的 L1 单据，也是商城订单履约的落点。波次、拣货、复核、交接由它派生，单据状态由工序聚合，取消请求未闭环时停在「进行中」并展示返仓中。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `soNo` | 出库单号 | String | 24 | 是 | 仓内唯一，业务引用主键 | `SO` + 日期 + 4 位流水；不可改 |
| `outType` | 出库类型 | Enum | — | 是 | 销售出库 / 调拨出库 / 退货出库 / 加工出库 | 决定默认工序编排 |
| `docStatus` | 单据状态 | Enum | — | 是 | 待处理 / 进行中 / 异常待处理 / 已完成 / 已取消 | 见状态枚举，由工序聚合 |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 库存分配按货主隔离 |
| `warehouseCode` | 仓库 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 一张订单只落一座实体仓 |
| `carrierName` | 承运商 | String | 100 | 否 | 关联承运商主档 `carrierName` | 交接按承运商分组 |
| `sourceDocType` | 来源单据类型 | Enum | — | 否 | 商城订单 / 委托单 / 调拨单 / 退货单 | 商城订单履约时必填 |
| `sourceDocNo` | 来源单号 | String | 40 | 否 | 上游单据号 | 与 `sourceDocType` 成对出现 |
| `waveNo` | 波次号 | String | 24 | 否 | 关联波次计划 `waveNo` | 未分配波次时为空 |

## 3. 明细行

一张订单至少一行；批次按商品主档的出库分配规则（FEFO / FIFO）确定。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |

| `skuCode` | 商品编码 | String | 20 | 是 | 关联商品主档 `skuCode` | 只允许本单货主商品 |
| `skuName` | 商品名称 | String | 200 | 是 | 取商品主档 | 展示用 |
| `batchNo` | 批次号 | String | 40 | 否 | 按分配规则选批次 | 效期或批次管理商品必填 |
| `planQty` | 计划数量 | Int | — | 是 | 行级计划数量 | |

## 5. 与其它主档的关系

- 货主主档：`ownerName` 外键；库存分配与拣货只在「本单货主」范围内取批次与库位，禁止跨货主串货。
- 商品主档：`skuCode` 外键，出库分配规则、禁售与临期拦截取商品主档策略。
- 仓库主档与库区库位：`warehouseCode` 确定落仓，`pickBin` 指向拣货库位。
- 承运商主档：`carrierName` 外键，交接回单与运单归集按承运商。
- 入库通知单与库存台账：退货退仓生成逆向入库通知单；出库记账后 `soNo` 作为流水业务单据号留痕，取消与返仓不删原行。

## 6. 原型衔接建议

- `outbound/so-list`（单仓端，list）：出库单号、单据状态、出库类型、货主、仓库、承运商、品类数、计划数量、已拣数量、已发数量、计划出库时间、创建时间。
- 状态页签：全部 / 待处理 / 进行中 / 异常待处理 / 已完成 / 已取消；筛选：出库单号、出库类型、货主、承运商、来源单号、计划出库时间。
- `outbound/picking-scan`（单仓端，scan）：任务上下文取出库单号、波次号、货主、操作员、设备；对象摘要取行号、商品编码、批次号、拣货库位；数量区取应拣数量、已拣数量。
- `outbound/handover-list`（单仓端，list）：交接单号、交接状态、货主、承运商、包裹数、交接时间、操作人；行上带 `waybillNo` 与 `handoverNo` 关联。
- 行按 `warehouseCode` 归属本仓，行上带货主维度供顶栏货主下拉过滤。
