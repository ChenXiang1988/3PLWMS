# 出库订单（数据字典）

> **单仓执行层**：本文描述 L0 出库计划单确认生效、分发到目标仓后形成的执行单。货灵WMS沿用计划单号 `planNo`，不再另开 `SO` 号；L0 委托层字段见 [出库计划单.md](出库计划单.md)，拣货、复核、交接等作业单据见 [工序单.md](工序单.md)。

> 实体：出库订单｜对应原型页面：出库管理 / 出库计划单及其行详情抽屉（`outbound` 模块，货灵WMS）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。
出库计划单分发到仓后形成执行单，也是商城订单履约的落点。波次、拣货、复核、交接由它派生，单据状态由工序聚合，取消请求未闭环时停在「进行中」并展示返仓中。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `planNo` | 计划单号 | String | 24 | 是 | 沿用 L0 计划单号，业务引用主键 | `OP` + 日期 + 4 位流水；不可改 |
| `outType` | 出库类型 | Enum | — | 是 | 销售出库 / 调拨出库 / 退货出库 / 加工出库 | 决定默认工序编排 |
| `docStatus` | 单据状态 | Enum | — | 是 | 待处理 / 进行中 / 异常待处理 / 已完成 / 已取消 | 见状态枚举，由工序聚合 |
| `planStatus` | 计划单状态 | Enum | — | 是 | 草稿 / 待确认 / 已生效 / 已分发 / 已关闭 | 沿用 L0 计划单状态，枚举见 [出库计划单.md](出库计划单.md) |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 库存分配按货主隔离 |
| `warehouseCode` | 仓库 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 一票计划单只落一座实体仓 |
| `carrierName` | 承运商 | String | 100 | 否 | 关联承运商主档 `carrierName` | 交接按承运商分组 |
| `sourceDocType` | 来源单据类型 | Enum | — | 否 | 平台订单 / 平台备货单 / 商城订单 / 委托单 / 调拨单 / 退货单 / 售后申请单 | 平台与商城履约、售后退货换货补发时必填 |
| `sourceDocNo` | 来源单号 | String | 40 | 否 | 上游单据号 | 与 `sourceDocType` 成对出现 |
| `waveNo` | 波次号 | String | 24 | 否 | 关联波次计划 `waveNo` | 未分配波次时为空 |

## 3. 明细行

一张计划单至少一行；批次按商品主档的出库分配规则（FEFO / FIFO）确定。

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `lineNo` | 行号 | Int | — | 是 | 单内唯一，从 1 开始 | 与任务分配行 `lineNo` 对应 |
| `skuCode` | 商品编码 | String | 20 | 是 | 关联商品主档 `skuCode` | 只允许本单货主商品 |
| `skuName` | 商品名称 | String | 200 | 是 | 取商品主档 | 展示用 |
| `batchNo` | 批次号 | String | 40 | 否 | 按分配规则选批次 | 效期或批次管理商品必填 |
| `planQty` | 计划数量 | Int | — | 是 | 行级计划数量 | |
| `pickBin` | 拣货库位 | String | 20 | 否 | 关联库区库位 `binCode` | 分配后写入 |
| `pickedQty` | 已拣数量 | Int | — | 是 | 行级实拣数量，初始 0 | 拣货扫码写入 |

## 5. 与其它主档的关系

- 货主主档：`ownerName` 外键；库存分配与拣货只在「本单货主」范围内取批次与库位，禁止跨货主串货。
- 商品主档：`skuCode` 外键，出库分配规则、禁售与临期拦截取商品主档策略。
- 仓库主档与库区库位：`warehouseCode` 确定落仓，`pickBin` 指向拣货库位。
- 承运商主档：`carrierName` 外键，交接回单与运单归集按承运商。
- 平台订单：`sourceDocType=平台订单` 时 `sourceDocNo` 取平台订单编号；收货信息从平台订单带入，一个平台订单可对应多张本单。
- 平台备货单：`sourceDocType=平台备货单` 时 `sourceDocNo` 取备货单号，`outType=平台备货出库`，`receiverName` 为平台仓，`appointmentNo`、`cartonMarkNo`、`packingListNo` 从备货单带入。
- 入库计划单与库存台账：退货退仓生成逆向入库计划单；出库记账后 `planNo` 作为流水业务单据号留痕，取消与返仓不删原行。
- 商城订单：`sourceDocType` 为商城订单时，`sourceDocNo` 取商城订单 `orderNo`，收货方、联系电话、收货地址自动带入，且只带外部收货地址；商城订单支付成功才生成本单，单据进入「待处理」，`planNo` 回写商城订单的主履约单号。

## 6. 商城订单履约的状态映射与逆向

| 出库计划单执行状态 | 对应商城订单状态 | 触发与回写 |
| --- | --- | --- |
| 待处理 → 进行中 | 待发货 | 支付成功自动生成执行单；回写 `obNo` |
| 异常待处理 | 待发货（挂起并提示） | 库存不足、禁售过期批次、拣货复核差异或扫码故障；处置完回「进行中」，商城订单不自行跳态 |
| 已完成 | 已发货 | 交接完成后回写 `shipTime`、`carrierName`、`waybillNo` |
| 已取消 | 已取消 | 买家在待发货阶段取消，且本单尚未交接 |

取消与返仓按已完成程度分档：未拣货可直接取消；已拣货未交接要返仓回上架、释放锁库，原任务行与扫码原值留痕；已交接的不能取消，只能由买家拒收或退货，生成逆向入库单，原出库计划单不删。商城订单「已完成」与「已取消」是终态，只能新建逆向单据。映射规则见 `../产品需求/商城订单状态流转.md`。

## 7. 原型衔接建议

- `outbound/out-plan-list`（货灵WMS，list）：计划单号、计划单状态、货主、目标仓库、计划出库日期、品类数、计划数量、锁库状态、创建时间、操作。
- 状态页签：全部 / 待确认 / 已生效 / 已分发 / 已关闭；筛选：货主、目标仓库、计划单号、计划出库日期。
- `outbound/out-plan-list` 行详情抽屉：抬头取计划单号、货主、目标仓库、计划出库日期、计划单状态、锁库状态、品类数、计划数量；明细行取商品编码、商品名称、批次号、计划数量；附操作轨迹。
- `outbound/picking-scan`（货灵WMS，scan）：任务上下文取计划单号、波次号、货主、操作员、设备；对象摘要取行号、商品编码、批次号、拣货库位；数量区取应拣数量、已拣数量。
- `outbound/handover-list`（货灵WMS，list）：交接单号、交接状态、货主、承运商、包裹数、交接时间、操作人；行上带 `waybillNo` 与 `handoverNo` 关联。
- 行按 `warehouseCode` 归属本仓，行上带货主维度供列表「货主」筛选。
