# 商城商品（数据字典）

> 实体：商城商品｜对应原型页面：仓网管理 / 商城管理（`mall-admin` 模块，仓网管理端）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
商城商品是把货主在仓现货挂到店铺前台的可售记录，商品身份仍以货主主档的商品为准，不另建一份商品真相。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `skuCode` | 商品编码 | String | 20 | 是 | 关联商品主档 `skuCode` | 与 `shopCode` 共同定位一条上架记录 |
| `skuName` | 商品名称 | String | 200 | 是 | 取商品主档 | 展示用 |
| `shopCode` | 店铺编码 | String | 20 | 是 | 关联店铺 `shopCode` | 一个商品可挂多家店铺 |
| `ownerName` | 货主 | String | 100 | 是 | 关联商品主档 `owner` | 与店铺货主一致 |
| `category` | 商品类目 | Enum | — | 是 | 全部商品 / 食品饮料 / 日化清洁 / 家居百货 / 数码配件 | 取商品类目枚举 |
| `saleStatus` | 在售状态 | Enum | — | 是 | 在售 / 已下架 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `onSale` | 在售 | `enabled` |
| `offSale` | 已下架 | `disabled` |

## 2. 价格与可见性

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `price` | 单价 | Decimal(10,2) | — | 是 | 单位元，两位小数 | 列表列 |
| `ladderPrice` | 阶梯价 | String | 100 | 否 | 如「满 10 箱 ￥28.00」 | 前台详情展示 |
| `guestVisible` | 访客可见 | Enum | — | 是 | 是 / 否 | 否时访客看到「登录可见价格」 |
| `memberVisible` | 登录可见 | Enum | — | 是 | 是 / 否 | 与访客可见配合 |

## 3. 库存与系统字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `stockQty` | 在仓现货 | Int | — | 是 | 由库存查询派生可用数量 | 不手工维护 |
| `listTime` | 上架时间 | Datetime | — | 否 | 首次上架时间 | |
| `createTime` | 创建时间 | Datetime | — | 是 | 系统写入 | |
| `updateTime` | 更新时间 | Datetime | — | 是 | 系统写入 | |

## 4. 与其它主档的关系

- 商品主档：`skuCode` 外键，名称、规格、条码、效期策略取主档，不重复存储。
- 店铺：`shopCode` 外键，一家店铺只挂本货主的商品。
- 库存查询：`stockQty` 由可用数量派生，库存为 0 时前台不可下单。

## 5. 原型衔接建议

- `mall-admin/mall-sku-list`（仓网管理端，list）：商品编码、商品名称、货主、商品类目、在售状态、在仓现货、上架时间。
- 筛选：货主、商品类目、在售状态；状态页签 全部 / 在售 / 已下架。
- `mall-admin/mall-price-list`（仓网管理端，list）：商品编码、商品名称、货主、单价、阶梯价、访客可见、登录可见。
