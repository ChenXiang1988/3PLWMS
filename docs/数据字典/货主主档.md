# 货主主档（数据字典）

> 实体：货主主档（Owner / Consignor）｜对应原型页面：基础资料 / 货主档案（`base` 模块 `owner-list`）
> 定位：描述**使用仓储服务的客户（货主）**，是仓库主档里 `serviceOwners` 的指向方，也是商品、库存、出入库单据的归属方。
> 本文件是字段真值源；生成原型页面时列名与取值逐字取自本文件，并在 `glossary.md` 登记。
> 示例模拟数据：[货主主档-示例数据.md](samples/货主主档-示例数据.md)（OW001~003，与仓库主档 `serviceOwners` 互指闭环）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。

约定：
- 必填：是=创建时不可为空；否=可空。
- 枚举（Enum）：固定取值集合，原型中以 `select` 呈现，首项「全部」。
- 关联：指向其它主档的外键，原型列展示其「名称」。
- 多对多：`serviceWarehouses` 与 `仓库主档.serviceOwners` 互指，任一侧改动需另一侧同步。

## 6. 与其它主档的关系

- **仓库主档**：`serviceWarehouses` 多对多指向 `仓库主档.warehouseCode`，与 `仓库主档.serviceOwners` 互指；原型两侧需同步展示。
- **商品主档**：货主是商品的归属方（商品 `ownerCode`）；同一 SKU 在不同货主下视作不同商品。
- **库存中心**：库存按货主隔离（`stock-list` 含 `ownerCode`），拣货 / 盘点均按货主维度。
- **入库 / 出库**：ASN、SO 单据归属货主；费率与资质约束来自本档。
- **商城角色**：同一货主可同时是店主与买家。店主角色由该货主是否已开通店铺派生，买家角色在登录后默认具备；两个角色都不落成货主主档字段，避免随店铺启停反复改主档。登录账号与货主一对一绑定，账号与角色归 `system` 模块管理。
- **商城订单**：`buyerOwnerName` 是买家货主外键，`ownerName` 是店铺归属的卖家货主，两者不得相同。口径见 `../产品需求/商城双身份设计方案.md`。

## 7. 原型衔接建议（待实现）

- 模块：`base` 基础资料，页面 `owner-list` 货主档案（list 骨架）。
- 列表建议列：货主编码、货主名称、货主类型、服务仓库数、支持业态、状态。
- 筛选：货主类型、状态、服务仓库、支持业态、资质。
- 层级：列表 → 详情（基础信息 + 服务仓库标签 + 资质 + 合同计费 + 商品/SKU 概览）。
- 关联跳转：点「服务仓库」跳 `仓库主档` 列表并预筛；点「SKU 数」跳 `商品主档` 按 `ownerCode` 过滤。
