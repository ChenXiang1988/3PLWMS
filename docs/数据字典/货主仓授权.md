# 货主仓授权（数据字典）

> 实体：货主仓授权（Owner Warehouse Authorization）｜对应原型页面：服务关系 / 货主仓授权（`network` 模块 `owner-warehouse-auth`）
> 定位：货主与仓库之间的服务范围授权，决定计划单可分发到哪些仓。

## 1. 授权字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `authNo` | 授权号 | String | 24 | 是 | `AW` + 日期 + 流水 | 全局唯一 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | |
| `warehouseCode` | 仓库编码 | String | 20 | 是 | 关联仓库主档 | |
| `serviceScope` | 服务范围 | Enum(multi) | — | 是 | 入库 / 出库 / 库内 / 加工 / 退货 / 越库 | |
| `agreementNo` | 关联协议 | String | 24 | 否 | 关联仓储服务协议 | |
| `effectiveFrom` | 生效开始 | Date | — | 是 | | |
| `effectiveTo` | 生效结束 | Date | — | 否 | 空表示长期 | |
| `authStatus` | 授权状态 | Enum | — | 是 | 待生效 / 已生效 / 已停用 / 已过期 | |

## 2. 状态与口径

- 生效开始日晚于当前日期为待生效；到期未续为已过期。
- 停用后不影响已分发单据，只阻止新计划单选择该仓。
- 一个货主在一个仓只有一条有效授权。

## 3. 与其它主档的关系

- 货主主档、仓库主档：两个外键共同构成唯一约束。
- 仓储服务协议：`agreementNo` 为外键。
- 计划单：分发时校验本授权与服务范围。

## 4. 原型衔接建议

- 页面：`network/owner-warehouse-auth`，list 骨架，按授权状态页签。
- 抽屉：授权信息 + 服务范围勾选 + 关联协议；动作「停用授权」。
