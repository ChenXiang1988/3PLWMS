# 店铺（数据字典）

> 实体：店铺｜对应原型页面：仓网管理 / 商城管理（`mall-admin` 模块，仓网管理端）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
店铺是一家货主在本部署商城的前台展示单元，卖的是该货主在仓的现货，不是独立经营主体。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `shopCode` | 店铺编码 | String | 20 | 是 | 全局唯一，业务引用主键 | `SH` + 4 位序号；不可改 |
| `shopName` | 店铺名称 | String | 100 | 是 | 前台展示名 | |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 一家店铺对应一家货主 |
| `mainCategory` | 主营类目 | Enum | — | 否 | 全部商品 / 食品饮料 / 日化清洁 / 家居百货 / 数码配件 | 取商品类目枚举 |
| `shopScore` | 店铺评分 | Decimal(2,1) | — | 否 | 0.0–5.0，一位小数 | 列表列 |
| `shopStatus` | 店铺状态 | Enum | — | 是 | 营业中 / 已停用 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `active` | 营业中 | `enabled` |
| `inactive` | 已停用 | `disabled` |

## 2. 经营与展示

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `onSaleCount` | 在售商品数 | Int | — | 是 | 由商城商品派生 | 不手工维护 |
| `floorRefs` | 所在楼层 | Enum(multi) | — | 否 | 热销货源 / 新品上架 / 临期特惠 / 店铺推荐 | 多值逗号拼接 |
| `applyNo` | 入驻申请单号 | String | 24 | 否 | 关联入驻申请 | 开店来源 |

## 3. 系统字段

| 字段 key | 中文名 | 类型 | 必填 | 取值 / 口径 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `createTime` | 创建时间 | Datetime | 是 | 系统写入 | 列表列 |
| `updateTime` | 更新时间 | Datetime | 是 | 系统写入 | |

## 4. 与其它主档的关系

- 货主主档：`ownerName` 外键，一家店铺对应一家货主；货主停用则店铺同步停用。
- 商城商品：`onSaleCount` 由商城商品按 `shopCode` 派生，不在本档手工维护。
- 货源楼层：`floorRefs` 决定店铺出现在哪些楼层。

## 5. 原型衔接建议

- `mall-admin/shop-list`（仓网管理端，list）：店铺编码、店铺名称、货主、在售商品数、店铺评分、状态、创建时间。
- 筛选：货主、主营类目、店铺状态；状态页签 全部 / 营业中 / 已停用。
