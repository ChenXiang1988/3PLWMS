# 店铺（数据字典）

> 实体：店铺｜对应原型页面：仓网管理 / 商城管理（`mall-admin` 模块，货灵运营中台管理端）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
店铺是一家货主在本部署商城的前台展示单元，卖的是该货主在仓的现货，不是独立经营主体。一个货主当前只能开一个店铺，`ownerName` 有唯一约束；开店前需完成企业资质认证，见 `企业资质认证.md`。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `shopCode` | 店铺编码 | String | 20 | 是 | 全局唯一，业务引用主键 | `SH` + 4 位序号；不可改 |
| `shopName` | 店铺名称 | String | 100 | 是 | 前台展示名 | |
| `ownerName` | 货主 | String | 100 | 是 | 关联货主主档 `ownerName` | 唯一约束：一个货主当前只能开一个店铺 |
| `mainCategory` | 主营类目 | Enum | — | 否 | 全部商品 / 食品饮料 / 日化清洁 / 家居百货 / 数码配件 | 取商品类目枚举 |
| `shopScore` | 店铺评分 | Decimal(2,1) | — | 否 | 0.0–5.0，一位小数 | 列表列 |
| `shopStatus` | 店铺状态 | Enum | — | 是 | 营业中 / 已停用 | 见状态枚举 |

### 状态枚举

## 4. 与其它主档的关系

- 货主主档：`ownerName` 外键且唯一，一个货主当前只能开一个店铺；货主停用则店铺同步停用。
- 企业资质认证：认证状态「已通过」才允许开店；认证结论归货主，不落本档字段。
- 商城角色：店主角色由该货主是否已开通店铺派生，不落成货主主档字段；未开通店铺的货主仍可作为买家下单。买家货主不得购买本货主店铺的商品。
- 商城商品：`onSaleCount` 由商城商品按 `shopCode` 派生，不在本档手工维护。
- 货源楼层：`floorRefs` 决定店铺出现在哪些楼层。
- 商城订单：一张订单只对应一家店铺，店铺货主即订单的卖家货主。

## 5. 原型衔接建议

- `mall-admin/shop-list`（货灵运营中台管理端，list）：店铺编码、店铺名称、货主、在售商品数、店铺评分、状态、创建时间；运营方负责审核与启停。
- 货灵ERP店主侧（拟名待确认）：本货主的店铺信息与自助维护，按登录身份限定数据；页面名登记前不得写进页面。
- 筛选：货主、主营类目、店铺状态；状态页签 全部 / 营业中 / 已停用。
- 分工口径见 `../产品需求/商城双身份设计方案.md` 第 3 节：自助维护归货灵ERP，入驻审核与全局视图归货灵运营中台管理端，同一动作不在两端各做一遍。
