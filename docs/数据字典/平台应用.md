# 平台应用（数据字典）

> 实体：平台应用｜对应原型页面：货灵运营中台管理端「ERP 运营 / 平台应用」｜字段真值源

约定：平台应用是部署级应用，不是货主级店铺授权；App Secret 不落页面、不进演示数据，列表只展示脱敏 App Key。

## 1. 应用标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `appCode` | 应用编码 | String | 30 | 是 | 本部署内唯一 | 列表主键 |
| `platformName` | 平台 | String | 40 | 是 | Amazon / Temu / TikTok Shop / Lazada / 速卖通 / Shopee / 美客多 | 平台主档 |
| `appType` | 应用类型 | Enum | 30 | 是 | 自建应用 / 合作伙伴应用 | 平台准入矩阵 |
| `appKeyMasked` | App Key | String | 60 | 是 | 脱敏值，如 `amzn-****-7F2C` | 不展示 Secret |
| `authMode` | 授权方式 | Enum | 20 | 是 | OAuth / API Key / 店铺授权 | 按平台声明 |
| `callbackUrl` | 回调地址 | String | 200 | 否 | 客户侧网关公网地址 | 仅 OAuth 需要 |
| `capabilities` | 能力范围 | multi | — | 是 | 订单 / 履约 / 售后 / 物流 / 面单 / 商品 | 页面动作按能力显隐 |
| `rateLimit` | 限流 | String | 40 | 否 | 如 `100 次/分钟` | 按平台声明 |
| `auditStatus` | 审核状态 | Enum | 20 | 是 | 见状态枚举 | 页签依据 |
| `appVersion` | 应用版本 | String | 20 | 是 | 如 `2026.10` | 随软件发布更新 |
| `updateTime` | 更新时间 | Datetime | — | 是 | 系统写入 | 列表展示 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `pending` | 待提交 | `pending` |
| `reviewing` | 审核中 | `pending` |
| `approved` | 已通过 | `enabled` |
| `rejected` | 已驳回 | `rejected` |
| `disabled` | 已停用 | `disabled` |

## 2. 与其它主档的关系

- **平台店铺**：一个平台应用可服务多个店铺；店铺授权按店铺隔离，不复制应用凭证。
- **同步任务**：应用能力与限流决定同步任务可用动作；应用停用后该平台停止拉单。
- **操作日志**：应用新增、审核、更新版本、测试连接、停用写全局审计。
- **网关**：回调地址指向客户侧网关，不存订单主数据。

## 3. 原型衔接建议

- `erp-ops/erp-app-list`（货灵运营中台管理端，list）：列取上表，审核状态页签取五值。
- 动作：查看凭证、测试连接、更新版本、停用；只做 toast 与状态流转，不调真实平台 API。
- 不展示 App Secret、证书、token；不出现运营后台类 SaaS 术语。
