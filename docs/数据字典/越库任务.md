# 越库任务（数据字典）

> 实体：越库任务（Cross-dock Task）｜对应原型页面：入库管理 / 越库直发（`inbound` 模块 `crossdock-task`）
> 定位：到货不落库、直接配对出库订单发运的越库作业。

## 1. 越库字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `crossdockNo` | 越库号 | String | 24 | 是 | `CD` + 日期 + 流水 | 全局唯一 |
| `inPlanNo` | 入库通知单 | String | 24 | 是 | 关联入库通知单 | |
| `outPlanNo` | 出库订单 | String | 24 | 否 | 配对后写入 | |
| `ownerCode` | 货主 | String | 20 | 是 | 关联货主主档 | |
| `skuCode` | 商品编码 | String | 24 | 是 | 关联商品主档 | |
| `qty` | 数量 | Decimal(14,3) | — | 是 | | |
| `dockCode` | 月台 | String | 20 | 否 | 直发月台 | |
| `crossdockStatus` | 越库状态 | Enum | — | 是 | 待配对 / 已配对 / 已直发 | |

## 2. 状态与口径

- 配对后不生成入库库存，直接生成出库任务。
- 配对数量不能大于到货数量；差额转差异异常单。
- 直发确认后同时完成入库与出库过账。

## 3. 与其它主档的关系

- 入库通知单、出库订单：两个来源外键。
- 月台预约：`dockCode` 与预约共用月台。
- 差异异常单：数量差异回写。

## 4. 原型衔接建议

- 页面：`inbound/crossdock-task`，list 骨架，按配对状态页签。
- 表单抽屉：入库通知单、出库订单、数量、月台；动作「配对出库单」。
