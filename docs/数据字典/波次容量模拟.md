# 波次容量模拟（数据字典）

> 实体：波次容量模拟（Wave Capacity Simulation）｜对应原型页面：出库管理 / 波次计划（`outbound` 模块 `wave-list`）
> 定位：基于当前波次任务量、资源负荷与容量规则的派生模拟，不代表真实预测模型。

## 1. 指标字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `waveNo` | 波次号 | String | 30 | 是 | 关联波次计划 | |
| `orderCount` | 当前任务量 | Int | — | 是 | 波次内订单数 | |
| `estimatedFinish` | 预计完成 | Datetime / String | — | 否 | 按当前资源负荷估算 | 展示层派生 |
| `resourceLoad` | 资源负荷 | Decimal(5,2) | — | 否 | 当前任务量除以容量上限 | 展示为百分比 |
| `gap` | 缺口 | String | 100 | 否 | 无 / 需替代资源 | |
| `alternativeResource` | 替代资源方案 | String | 100 | 否 | 可替代的人员、设备或工位 | |

## 2. 口径

- 模拟只使用当前页面演示数据，不调用后端算法或实时设备数据。
- 波次存在设备故障、容量不足或资源负荷达到阈值时，标记缺口并给出替代资源方案。
- `estimatedFinish` 是运营排程参考，不作为承诺时效。

## 3. 与其它实体的关系

- 波次计划：`waveNo` 为外键。
- 任务池任务：`orderCount` 与任务量来自当前波次关联任务。
- 设备告警：故障影响会改变资源负荷与替代资源方案。

## 4. 原型衔接建议

- 页面：`outbound/wave-list`，保留波次列表及详情抽屉，在页面报告区展示容量模拟结果。
- 交互：支持释放、拆分、重排；阻塞波次先处理设备影响，不自动释放。
