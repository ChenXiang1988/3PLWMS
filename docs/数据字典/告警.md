# 告警（数据字典）

> 实体：告警（Alert）｜对应原型页面：总览 / 告警中心（`network` 模块 `alert-center`）
> 定位：库存、时效、设备与 SLA 的统一告警台账，可转工单或豁免。

## 1. 告警字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `alertNo` | 告警号 | String | 24 | 是 | `AL` + 日期 + 流水 | 全局唯一 |
| `alertType` | 告警类型 | Enum | — | 是 | 库存 / 时效 / 设备 / SLA | |
| `level` | 级别 | Enum | — | 是 | 提示 / 警告 / 严重 | |
| `warehouseCode` | 仓库 | String | 20 | 是 | 关联仓库主档 | |
| `objectRef` | 对象 | String | 120 | 是 | 单据号、库位或设备编码 | |
| `raisedAt` | 触发时间 | Datetime | — | 是 | | |
| `handleStatus` | 处理状态 | Enum | — | 是 | 待处理 / 处理中 / 已处理 / 已豁免 | |
| `workOrderNo` | 工单号 | String | 24 | 否 | 转工单后写入 | |

## 2. 状态与口径

- 转工单把状态置处理中并写工单号；恢复或处理完成置已处理。
- 豁免必须填原因，状态置已豁免，不再升级。
- 同一对象同类型告警 24 小时内合并计数，不重复建行。

## 3. 与其它主档的关系

- 仓库主档：`warehouseCode` 为外键。
- 差异异常单、设备告警：按 `objectRef` 回指来源。
- 故障工单：`workOrderNo` 为外键。

## 4. 原型衔接建议

- 页面：`network/alert-center`，list 骨架，按级别页签。
- 抽屉：告警详情 + 对象快照 + 处置记录；动作「转工单」「豁免」。
