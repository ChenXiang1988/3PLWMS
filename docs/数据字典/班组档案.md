# 班组档案（数据字典）

> 实体：班组档案｜对应原型页面：作业资源 / 班组（`resource` 模块，单仓端）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `teamCode` | 班组编码 | String | 20 | 是 | 仓内唯一，业务引用主键 | 建议 `TM` + 3 位序号；不可改 |
| `teamName` | 班组名称 | String | 100 | 是 | 现场称呼 | 如「收货一组」 |
| `teamType` | 班组类型 | Enum | — | 是 | 收货 / 上架 / 拣货 / 复核 / 盘点 / 发货 / 综合 | 决定派工候选范围 |
| `shiftType` | 班次 | Enum | — | 是 | 早班 / 中班 / 晚班 / 常白班 | 排班档案按此展开 |
| `teamStatus` | 班组状态 | Enum | — | 是 | 启用 / 停用 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `active` | 启用 | `enabled` |
| `inactive` | 停用 | `disabled` |

## 2. 归属与人员

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `warehouseCode` | 所属仓库 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 班组必属某一座实体仓 |
| `leaderCode` | 班组长 | String | 20 | 否 | 关联人员档案 `staffCode` | |
| `memberCount` | 班组人数 | Int | — | 是 | 由人员档案按 `teamCode` 派生计数 | 不手工维护 |
| `defaultUnitCode` | 默认执行单元 | String | 20 | 否 | 关联执行单元档案 `unitCode` | 派工时优先候选 |

## 3. 能力与系统字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `taskTypes` | 可承接任务类型 | Enum(multi) | — | 是 | 收货 / 上架 / 移库 / 拣货 / 复核 / 盘点 / 发货 | 多值逗号拼接展示 |

## 4. 与其它主档的关系

- 仓库主档：`warehouseCode` 外键，班组按仓维护，不支持跨仓共用一个班组。
- 人员档案：一名人员只属一个班组，`memberCount` 从人员档案派生，避免两处维护漂移。
- 排班档案：班组定义班次类型，排班档案给出具体日期与出勤人数。
- 执行单元档案：`defaultUnitCode` 是派工默认区域，不是人员归属。

## 5. 原型衔接建议

- `resource/team-list`（单仓端，list）：班组编码、班组名称、班组类型、班次、所属仓库、班组长、班组人数、班组状态、创建时间。
- 筛选：班组类型、班次、班组状态；状态页签 全部 / 启用 / 停用。
- 行按 `warehouseCode` 归属本仓，不带货主维度。
