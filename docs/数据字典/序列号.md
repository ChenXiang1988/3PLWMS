# 序列号（数据字典）

> 实体：序列号（Serial Number）｜对应原型页面：库存中心 / 序列号追踪（`inventory` 模块 `serial-list`）
> 定位：单件级序列号的在库与流转轨迹，支持入库、移位与出库追溯。

## 1. 序列号字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `sn` | 序列号 | String | 64 | 是 | 全局唯一 | 主键 |
| `skuCode` | 商品编码 | String | 24 | 是 | 关联商品主档 | |
| `ownerCode` | 货主 | String | 20 | 是 | 关联货主主档 | |
| `batchNo` | 批次号 | String | 24 | 否 | | |
| `locationCode` | 库位 | String | 20 | 否 | 当前库位 | |
| `serialStatus` | 状态 | Enum | — | 是 | 在库 / 已出库 / 已冻结 | |
| `inDocNo` | 入库单 | String | 24 | 否 | 来源入库通知单 | |
| `outDocNo` | 出库单 | String | 24 | 否 | 去向出库订单 | |
| `lastMoveAt` | 最近移动时间 | Datetime | — | 否 | | |

## 2. 状态与口径

- 在库序列号必须绑定库位；出库后库位置空。
- 冻结序列号不参与拣货分配。
- 序列号不可重复入库；重复扫描拦截。

## 3. 与其它主档的关系

- 商品主档、批次效期、库区库位：三个外键。
- 入库通知单、出库订单：来源与去向。
- 库存台账：按序列号写单件流水。

## 4. 原型衔接建议

- 页面：`inventory/serial-list`，list 骨架，按状态页签。
- 抽屉：入库、移位、出库三段轨迹；动作「查看轨迹」。
