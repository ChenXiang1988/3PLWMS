# 月台预约（数据字典）

> 实体：月台预约（Dock Appointment）｜对应原型页面：仓网调度 / 月台预约计划（`network` 模块 `dock-schedule`）、入库管理 / 到货预约（`inbound` 模块 `appointment-list`）
> 定位：到车与月台占用的统一预约记录，中台看全仓，WMS 只看本仓。

## 1. 预约字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `appointmentNo` | 预约号 | String | 24 | 是 | `DA` + 日期 + 流水 | 全局唯一 |
| `warehouseCode` | 仓库 | String | 20 | 是 | 关联仓库主档 | |
| `dockCode` | 月台 | String | 20 | 是 | 关联仓库月台 | |
| `docNo` | 单据号 | String | 24 | 是 | 入库通知单或出库订单 | |
| `direction` | 方向 | Enum | — | 是 | 入库 / 出库 | |
| `plateNo` | 车牌 | String | 16 | 否 | | |
| `plannedAt` | 计划到车 | Datetime | — | 是 | | |
| `arrivedAt` | 实际到车 | Datetime | — | 否 | | |
| `palletCount` | 托盘数 | Int | — | 否 | | |
| `appointmentStatus` | 预约状态 | Enum | — | 是 | 待确认 / 已确认 / 已到车 / 已取消 | |

## 2. 状态与口径

- 确认后占用月台时段；取消释放时段。
- 实际到车时间由 WMS 确认到车写入，中台只读。
- 同一月台同一时段只允许一条已确认预约。

## 3. 与其它主档的关系

- 入库通知单、出库订单：`docNo` 回指来源单据。
- 仓库主档：`warehouseCode` 为外键。
- 车辆与承运商：车牌在运单中复用。

## 4. 原型衔接建议

- 中台页面：`network/dock-schedule`，按预约状态页签，动作「确认到车」「取消预约」。
- WMS 页面：`inbound/appointment-list`，只看本仓，动作「确认到车」。
