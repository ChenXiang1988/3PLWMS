# 质检单（数据字典）

> 实体：质检单（QC Order）｜对应原型页面：入库管理 / 质检单（`inbound` 模块 `qc-order`）
> 定位：收货后、上架前的验收与抽检记录，结论决定入库数量与批次可用性。

## 1. 质检字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `qcNo` | 质检号 | String | 24 | 是 | `QC` + 日期 + 流水 | 全局唯一 |
| `receivingNo` | 收货单 | String | 24 | 是 | 关联收货单 | |
| `ownerCode` | 货主 | String | 20 | 是 | 关联货主主档 | |
| `skuCode` | 商品编码 | String | 24 | 是 | 关联商品主档 | |
| `batchNo` | 批次号 | String | 24 | 否 | 关联批次效期 | |
| `receivedQty` | 收货数量 | Decimal(14,3) | — | 是 | | |
| `acceptedQty` | 验收数量 | Decimal(14,3) | — | 是 | 必填，不能大于收货数量 | |
| `sampleQty` | 抽样数 | Decimal(14,3) | — | 否 | | |
| `qualifiedQty` | 合格数 | Decimal(14,3) | — | 是 | | |
| `defectiveQty` | 不合格数 | Decimal(14,3) | — | 是 | | |
| `producedAt` | 生产日期 | Date | — | 否 | 效期商品必填 | |
| `plannedLocationCode` | 计划库位 | String | 20 | 否 | | |
| `palletNo` | 托盘 | String | 20 | 否 | | |
| `defectType` | 缺陷类型 | Enum | — | 否 | 破损 / 短少 / 错发 / 包装不良 / 效期不足 / 其他 | |
| `conclusion` | 结论 | Enum | — | 是 | 合格 / 部分合格 / 不合格 | |
| `inspector` | 质检人 | String | 50 | 否 | | |
| `inspectedAt` | 质检时间 | Datetime | — | 否 | | |

## 2. 状态与口径

- 验收数量必填；合格数加不合格数等于验收数量。
- 不合格数量转差异异常单，不直接改库存。
- 效期商品未填生产日期不允许提交。

## 3. 与其它主档的关系

- 收货单：`receivingNo` 为外键。
- 商品主档、批次效期：`skuCode`、`batchNo` 为外键。
- 上架单：按验收数量生成上架需求。

## 4. 原型衔接建议

- 页面：`inbound/qc-order`，list 骨架，按结论页签。
- 表单抽屉：验收数量、抽样数、合格数、不合格数、生产日期、批次、计划库位、托盘、缺陷类型、结论。
