# 平台订单（数据字典）

> 实体：平台订单｜对应原型页面：货灵ERP「平台订单」（`erp` 模块）
> 字段名（key）用小写驼峰；中文显示名按 货灵供应链运营平台习惯。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」。
平台订单是外部电商平台订单在货灵ERP 订单中心的落点，只服务订单管理与多平台对账，**不进仓储单据链**。仓储侧从履约单与出库计划单开始，计划单只回指平台单号，不复制平台状态、退款与同步字段。
一个平台订单可以拆多张履约单：部分发货、补发、多包裹各自形成履约单，`planNo` 只存首张主履约单号，全部履约单见履约单视图，不把多张单号塞进一个字段。

## 1. 基础标识

## 5. 与其它主档的关系

- 货主主档：`ownerCode` 外键，店铺归属的卖家货主；一个货主可接多个平台、多个店铺。
- 平台店铺与店铺授权：`shopCode` 外键、`shopAuthNo` 关联当前授权；授权过期后只读，不再拉新单。
- 商品主档：明细 `skuCode` 匹配本货主商品，按 `platformSku` 与本地商品编码的映射维护；未匹配不阻断拉单，进映射异常待人工处理。
- 履约单：一个平台订单对应多张履约单，履约单记录履约方式、执行单号、包裹与运单；`fulfillmentCount` 由履约单派生，`planNo` 只存首张主履约单号。
- 出库计划单：仓发货时由下发动作生成，`sourceDocType=平台订单`、`sourceDocNo=platformOrderNo`；平台订单不直接写仓储单据。
- 代发采购单：无货卖家走代发时 `dropshipNo` 回指采购单，再由货源方生成履约单。
- 商城订单：两者并列、不合并。商城订单来自货源商城，平台订单来自外部平台，只在下游都汇到履约单与执行单。
- 平台售后单：`orderNo` 外键，售后不改写本单状态；本单在售后期间保持原履约状态，聚合状态可显示售后中。
- 库存台账：平台订单不写账，账在仓储侧收货上架与交接后产生；自发货与平台备货按各自执行单口径处理。

## 6. 原型衔接建议

- 货灵ERP `owner/platform-order-list`（list，原单处理流水线）：订单编号、平台、店铺、平台订单号、平台原始状态、订单类型、履约方式、处理状态、履约单数、同步状态、下单时间。
- 状态页签取 `processStatus`：全部 / 待审单 / 已审单 / 已拆单 / 待下发 / 同步异常 / 已下发；筛选：平台、店铺、订单类型、履约方式、异常标签、同步状态。
- 工具条：导出；行抽屉动作：审单通过、拆单生成履约单、下发 3PL、自发货、备货到平台仓、补拉漏单、标记重复单、重新同步、关闭。动作只写演示行与操作轨迹，不调平台接口、不生成真实履约单。
- 行详情抽屉：抬头取平台原始状态、订单类型、履约方式、幂等键、商品明细、同步状态；审单分节取异常标签（多选）、命中规则、审单结论、拆分履约单数、处理备注。
- 原单按 `idempotencyKey` 去重；平台改地址与退款由重新同步覆盖；漏单经补拉动作回到待审单。字段映射与状态映射不落在订单行，见平台适配器字典。
- 订单中心 `owner/order-center` 的订单 360 抽屉按 `orderNo` 关联，补展示平台原始状态、幂等键、命中规则、异常标签与拉单/映射/审单/拆单/回传轨迹。
- 列表按登录货主限定，不提供货主筛选。
