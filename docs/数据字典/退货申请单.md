# 退货申请单（数据字典）

> 实体：退货申请单｜对应原型页面：货灵ERP「退货申请」、货灵WMS「退货退仓逆向单据」｜字段真值源

约定：货主发起退货退仓申请，运营中台确认后生成逆向单据由货灵WMS执行。已出库交接后的退货不可逆，不回写已发布商品主档；原出库单据与台账留痕保留。

## 1. 申请标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `returnNo` | 退货单号 | String | 24 | 是 | 系统生成，全局唯一 | 列表主键 |
| `ownerCode` | 货主编码 | String | 20 | 是 | 关联货主主档 | 按登录身份限定 |
| `sourcePlanNo` | 原出库单号 | String | 24 | 是 | 关联出库订单 | 已交接单据 |
| `skuCode` | 商品编码 | String | 20 | 是 | 关联商品主档 | |
| `batchNo` | 批次号 | String | 24 | 否 | 关联批次效期 | |
| `returnQty` | 退货数量 | Int | 12 | 是 | 不得超过原出库数量 | 右对齐数字列 |
| `returnStatus` | 退货状态 | Enum | 20 | 是 | 见状态枚举 | 页签依据 |
| `submitTime` | 提交时间 | Datetime | — | 是 | 提交时刻 | |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `draft` | 草稿 | `disabled` |
| `pendingConfirm` | 待确认 | `pending` |
| `confirmed` | 已生效 | `enabled` |
| `receiving` | 退仓验收中 | `pending` |
| `finished` | 已完成 | `disabled` |
| `cancelled` | 已取消 | `disabled` |

## 2. 逆向与留痕

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `returnReason` | 退货原因 | String | 500 | 是 | 货主填写 | 表单抽屉多行输入 |
| `reverseDocNo` | 逆向单据号 | String | 24 | 否 | 确认后由系统生成 | 货灵WMS执行 |
| `receivedQty` | 已收数量 | Int | 12 | 否 | 退仓验收写入 | |
| `warehouseCode` | 退仓仓库 | String | 20 | 否 | 关联仓库主档 | |
| `reviewer` | 确认人 | String | 30 | 否 | 运营中台账号 | |
| `reviewTime` | 确认时间 | Datetime | — | 否 | 运营中台确认时刻 | |
| `ledgerNo` | 冲正流水号 | String | 24 | 否 | 关联库存台账 | 入账冲正留痕 |
| `trace` | 操作轨迹 | String | 1000 | 否 | 提交、确认、验收、完成、取消 | 留痕不可删 |

## 3. 与其它主档的关系

- **出库订单**：`sourcePlanNo` 关联原出库单据，退货数量按原单行校验。
- **商品主档**：只读取已发布主档，不因退货改写主档字段或版本。
- **库存台账**：退仓验收写冲正流水，原出库流水不删除。
- **调拨申请单**：调拨在途取消走取消流程，不复用退货申请单。

## 4. 原型衔接建议

- 货灵ERP `owner/return-apply-list` 页签取退货状态枚举；工具条「新增」「提交」「撤回」，表单抽屉录入原出库单号、商品、数量与原因。
- 已确认后不再出现撤回入口；退仓验收中只展示进度，不提供编辑。
- 逆向单据与冲正流水号在详情抽屉可见，已交接后标「不可逆」。
- 列表货主维度由登录身份限定，不提供货主筛选。
