# 人员档案（数据字典）

> 实体：人员档案｜对应原型页面：作业资源 / 人员（`resource` 模块，单仓端）
> 字段名（key）用小写驼峰；中文显示名按 3PL 云仓习惯；类型以 PostgreSQL 风格标注。
> 本文件是字段真值源；原型列名与取值逐字取自本文件，并在 `glossary.md` 登记。

约定：必填 是＝创建时不可为空；枚举在原型以下拉呈现，首项「全部」；关联字段列展示名称。
本档只管仓内作业人员，登录账号与角色权限归 `system` 模块。

## 1. 基础标识

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `staffCode` | 人员编码 | String | 20 | 是 | 仓内唯一，业务引用主键 | 建议 `ST` + 4 位序号；不可改 |
| `staffName` | 姓名 | String | 50 | 是 | 真实姓名 | |
| `position` | 岗位 | Enum | — | 是 | 收货员 / 上架员 / 拣货员 / 复核员 / 叉车司机 / 仓管员 | 决定可做哪类任务 |
| `staffStatus` | 人员状态 | Enum | — | 是 | 在职 / 休假 / 离职 | 见状态枚举 |

### 状态枚举

| 值 | 中文 | 建议色型 tone |
| --- | --- | --- |
| `active` | 在职 | `enabled` |
| `leave` | 休假 | `pending` |
| `resigned` | 离职 | `disabled` |

## 2. 归属与资质

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `warehouseCode` | 所属仓库 | String | 20 | 是 | 关联仓库主档 `warehouseCode` | 跨仓支援按排班临时登记，不改归属 |
| `teamCode` | 所属班组 | String | 20 | 否 | 关联班组档案 `teamCode` | 一名人员只属一个班组 |
| `qualification` | 作业资质 | Enum(multi) | — | 否 | 叉车证 / 冷链作业 / 危品作业 / 高位作业 | 无资质不下发对应任务 |
| `entryDate` | 入职日期 | Date | — | 否 | 人事口径 | |

## 3. 作业与系统字段

| 字段 key | 中文名 | 类型 | 长度 | 必填 | 取值 / 口径 | 说明 / 关联 |
| --- | --- | --- | --- | --- | --- | --- |
| `account` | 关联账号 | String | 50 | 否 | 关联 `system` 模块账号 | 无账号的人员只作台账 |
| `contactPhone` | 联系电话 | String | 20 | 否 | 现场联络 | |
| `remark` | 备注 | String | 300 | 否 | 自由文本 | 不进列表列 |
| `createTime` | 创建时间 | Datetime | — | 是 | 系统写入 | 列表列 |
| `updateTime` | 更新时间 | Datetime | — | 是 | 系统写入 | |
| `createBy` | 创建人 | String | 50 | 否 | 账号 | 关联 `system` 模块账号 |

## 4. 与其它主档的关系

- 仓库主档与班组档案：`warehouseCode` 定仓，`teamCode` 定班组，班组人数由本档派生。
- 排班档案：按 `staffCode` 与日期给出班次，人员档案不重复存排班明细。
- 设备档案：叉车司机靠 `qualification` 与设备类型匹配，不在人员上挂设备清单。
- 系统设置：账号、角色、数据范围在 `system` 模块，本档只留 `account` 关联。

## 5. 原型衔接建议

- `resource/staff-list`（单仓端，list）：人员编码、姓名、岗位、所属仓库、所属班组、作业资质、人员状态、入职日期、创建时间。
- 筛选：岗位、所属班组、人员状态；状态页签 全部 / 在职 / 休假 / 离职。
- 行按 `warehouseCode` 归属本仓，不带货主维度。
