# 图表选型判据

图不是装饰。每张图必须回答一个具体问题：谁比谁多、哪一步是瓶颈、哪个状态无法回退。答不出这个问题的图，删掉换成一句数字。

## 1. 选型阶梯

按这张表选图形，从上往下取第一个合适的（依据：Cleveland & McGill 的编码阶梯，位置与长度最准，面积与角度最差）。

| 级 | 编码 | 用于 | 本报告里的落点 |
| --- | --- | --- | --- |
| 1 | 同一刻度上的位置 | 趋势、多对象比较 | 横向条形、对比矩阵 |
| 2 | 长度 | 单维数量对比 | 条形、占比条 |
| 3 | 颜色强度（单色相由浅到深） | 只用于矩阵 | 能力矩阵的三档底色 |
| 4 | 面积、角度 | 几乎不用；饼图仅在有一个压倒性占比时 | 本报告不用 |
| — | 色相 | 只表分类，不表大小 | 不用于数值 |

离梯的东西一律不用：径向仪表盘、treemap、3D、双 Y 轴、渐变填充。

## 2. 内容类型 → 图形

| 内容 | 用什么 | 不用什么 | 依据 |
| --- | --- | --- | --- |
| 多个对象的同一指标 | 横向条形，按值降序 | 单条条形、饼图 | 长度可精确比较 |
| 三段以内的构成 | 堆叠占比条，段内标百分比 | 饼图、环形图 | 角度难读 |
| 线性流程与步骤 | 步骤链，分支另起一行 | 纯文字罗列 | 位置表达顺序 |
| 状态与逆向流转 | 状态带，终态加重，逆向虚线回指 | 只写状态名 | 位置表达先后 |
| 层级结构（菜单、模块树） | 缩进树，层级用竖线 | 项目符号列表 | 缩进表达从属 |
| 跨参与者交互 | 参与者泳道（内联 SVG） | 长段落描述 | 时间轴 + 列位 |
| 多对象多维度 | 表格 + 单元格色块 | 拆成多张单维表 | 网格容纳二维 |
| 单一数值 | 一句话 + 数字，不画图 | 单条条形、仪表盘 | 单值无比较 |

## 3. 每类图的规则

**横向条形**

- 条从 0 起，长度与数值严格成比例；只画有可比对象的指标。
- 条高 10px、圆角 2px，主对象用强调色，其余用浅一档；数值右对齐贴条端，单位紧随。
- 超过 8 条只留前 8 条，其余归「其他」，并在图注写清。

**堆叠占比条**

- 单条高 14px，段间 2px 白缝，段内标百分比，总和不等于 100% 要在图注说明口径。
- 超过 5 段合并尾部为「其他」。

**步骤链**

- 主路径实线、异常分支虚线，分支从最近的主路径节点引出，不横穿。
- 每步一个短标签，超过 6 步拆分或折叠。

**状态带**

- 按推进顺序横排，终态加粗下边线；不可逆的终态在图注里点明。
- 逆向用虚线回指并标动作名（撤销 / 驳回 / 反审核）。

**缩进树**

- 层级用 1px 竖线 + 12px 缩进，节点文字不换行；超过三层折叠为「等 N 项」。
- 只画到三级，更深的用一句「其余 N 项同类」代替。

**参与者泳道（SVG）**

- 固定 `viewBox`，参与者列头用正文色，消息线用次级色，返回线虚线。
- 消息标签写动作与对象，不写「调用」「处理」这类无信息动词。

**能力矩阵**

- 格内写 有 / 无 / 未验证，用三档底色区分；文字保留在格内，不靠颜色单独表意。
- 未验证不涂成「无」，两者在图上必须可区分。

## 4. 颜色

- 只用报告已有的令牌：`--accent`（强调）、`--accent-soft`（次级）、`--line`（分隔）、`--muted`（次要文字）、`--ink`（正文）。
- 一个强调色。红绿只在有正负方向且基数足够时使用，且必须同时有文字标注，不靠颜色单独承载含义。
- 颜色强度只用于矩阵，由浅到深表示程度；不用于条形。

## 5. 基线与数字

- 每个标题数字要能回答「和什么比」：上一轮、目标、或另一个对象。没有基线就不画对比。
- 条形一律从 0 起；折线可从非 0 起，但轴要标明。
- 数字用等宽数字、右对齐；单位紧随数字；无数据写 `—`，不写 0。

## 6. 图注与无障碍

- 每图必须有 `<figcaption>`：`图 N ｜ 一句结论`。结论写「A 比 B 多 12 页」或「复核是瓶颈」，不复述标题。
- 图形容器加 `role="img"` 与 `aria-label`，内容与图注一致。
- 打印时图不跨页：`break-inside: avoid`。

## 7. 什么时候不画图

- 只有一个数值、没有比较对象。
- 数据只有 1~2 条，一句话说得清。
- 内容本身就是表格（术语对照、缺项清单），表格比图准。
- 图的结论要靠读者自己算——说明这张图没选对。

## 8. 八节的建议配图

| 节 | 建议图形 | 什么时候不画 |
| --- | --- | --- |
| 1 口径与证据 | 对象 × 证据级矩阵 | 单对象时用一行 KPI 数字 |
| 2 覆盖清单 | 菜单缩进树；覆盖页数条形 | 只覆盖 1~2 页时用文字 |
| 3 逐页记录 | 状态带；页面分区步骤链 | 单页且无状态流转时省略 |
| 4 术语对照 | 不用图 | 恒定用表格 |
| 5 横向对比 | 能力矩阵；关键维度条形 | 单对象时写「无横向对比」 |
| 6 结论与落点 | 落点按端或模块计数条形 | 结论少于 3 条时用表格 |
| 7 缺项 | 不用图 | 恒定用表格 |
| 8 截图索引 | 缩略图网格 | 无截图时只写缺图原因 |

## 9. 工具边界

- 图表一律内联：CSS 画条形、步骤链、状态带、缩进树、矩阵；结构关系与时序用内联 SVG。**不引外部图表库、不引 CDN、不引 Mermaid**——报告要能双击打开。
- `archify` 在本工作区只有规范（`schemas/` 五类图定义、`assets/template.html` 的 SVG 组织方式），**其 CLI `bin/archify.mjs` 不存在，不能执行 validate 与 deliver**。需要画结构关系或时序图时，读它的 schema 定字段，自己写 SVG，不要声称由它生成。
- 图表选型依据来自 `dashboard-design` 的编码阶梯与颜色规则，落成本项目时改用报告自己的令牌，不用它示例里的色值。
- 代码片段见 `chart-snippets.md`，逐类可直接复制。
