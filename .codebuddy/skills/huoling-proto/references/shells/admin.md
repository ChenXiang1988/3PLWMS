# 后台外壳视觉法（admin）

适用于 `shell = "admin"` 的三端：货灵ERP、货灵运营中台管理端、货灵WMS。三端同壳同法，差异只在侧栏条目、页头页签内容、登录身份与货灵ERP的两套演示数据。

## 1. 设计意图

工具型界面。使用者是每天开八小时的仓内作业与货主运营人员，判据是「一屏能读多少行、误操作有多少」，不是「第一眼多惊艳」。由此定四条取向：

- **密度优先**：留白服务于分组，不服务于呼吸感。
- **弱装饰**：边框与底色承担分区；阴影只给表格容器与浮层；不用渐变、插画、装饰图形、彩色大色块。
- **状态靠色型**：状态一律由 `StatusTag` / `Tag` 的 tone 表达，不靠图标、描边、字号加粗另造一套。
- **强调有预算**：一屏只允许一处主色强调（主按钮或当前导航），其余分层靠中性灰阶。
- **导航分两栏**：首栏回答「在哪条业务动线」，面板回答「这条动线里做哪件事」。域是动线归并，不是分类树，不按单据类型或模块名切。

## 2. 基准

| 项 | 取值 |
| --- | --- |
| PC 设计基准 | 1440 × 900 |
| 内容区最小宽度 | 1080px；列放不下时横向滚动，不压缩列宽 |
| 首栏 / 导航面板 | 76px / 256px（面板可收起为 0） |
| 最小触控目标 | 44px（`--wx-touch`） |
| 字体 | 系统字体栈，不引外部字体文件 |

## 3. 骨架

双栏导航：窄的首栏放业务域，宽的面板放当前域的段与页，正文在右侧自适应。没有顶栏，也没有页头页签。

```
.wx-app（height:100vh，overflow:hidden）
└ .wx-shell（height:100%，横向 flex）
    ├ .wx-rail（flex:0 0 76px）：品牌字标 / 业务域条目 / 底部帮助、通知、当前用户
    ├ .wx-panel（flex:0 0 256px，收起为 0）：表头（端名 + 产品名 + 本域搜索 + 货灵ERP「前往商城」）→ 当前域的分段与页 → 收起按钮
    └ .wx-main（flex:1，min-width:0）
        └ .wx-page-body（唯一滚动容器）：一屏一个 .page
.wx-toast / 抽屉与弹层挂 body 末尾
```

- 首栏只放产品字标、本端业务域、帮助、通知与当前用户。不放部署形态、运营主体说明、主体切换器、套餐与配额；参考图里的「Enterprise Tier」与容量配额卡是 SaaS 形态，不落。
- 业务域在注册表 `apps[].rail` 声明：`name` 是域名，`mark` 是首栏方块里的单字字标，`navs` 引用 `apps[].nav[].id`。域顺序即首栏顺序，每个段恰好归属一个域，构建期校验覆盖。
- 首栏条目为 40px 圆角方块（单字字标）+ 11px 域名标签，当前域浅主色底 + 主色文字；面板条目 36px 行高，当前页浅主色底 + 主色文字并在右侧带 4px 圆点。
- 点首栏切域：显示该域面板并激活该域第一页；点面板条目切页，同时按页的 `data-nav-group` 反查所属域并同步首栏。
- 面板按段分组，段名用 11px 灰字小标签，段内页面全部展开，不做手风琴。只有一段的域不重复显示段标签，直接列页。
- 面板可收起：`.wx-app.is-collapsed` 时面板宽度归 0，只剩首栏，正文加宽；收起按钮在面板底部，收起后首栏底部出现展开按钮。状态写 `sessionStorage` 的 `wx-nav-collapsed`，切页不丢。视口宽 ≥1280 首次进入默认展开，<1280 默认收起；用户手动切换后按用户选择。
- 面板表头放端名、产品名与本域搜索，不放部署形态、套餐、运营主体说明。货灵ERP在表头右上角多一个「前往商城」链接按钮，是全库唯一跨端入口：相对路径指向同目录的货灵商城产物，带 `owner` 参数传当前登录货主，`target="_blank"` 新开页面，文案逐字取 `glossary.md`；货灵运营中台管理端与货灵WMS不出现该入口。货灵ERP另单建「商城店铺」段，五个店主侧页面挂在它下面，段内页序不改。
- 页头页签已取消：换页只由面板承接，不再有第二处同源入口，也不再生成 `.wx-head-tabs`。页面名由面板当前条目表达，正文不加大标题。
- 页面归属只由注册表的 `pages[].app` 决定，导航只改 `apps[].rail` 与 `apps[].nav`，不在页面名里加端前缀。
- 货主维度只用列表筛选：需要按货主收窄的页，在筛选区给一个「货主」下拉，取值域来自注册表 `owners`，首项「全部」。端不设货主下拉。货灵ERP按登录身份限定数据范围，不摆货主筛选。
- 正文滚动靠布局层级：`.wx-app` 固定高度、`.wx-page-body` 是唯一滚动容器，不用 `position:sticky`。
- `.page` 默认 `display:none`，靠 `.page:not([hidden])` 显示。**任何写了 `display` 的组件都要补 `[hidden]{display:none}`**，否则 `display:flex` 会压过浏览器默认隐藏规则；面板与分段容器同理。
- 会话面板挂 `.wx-app` 之后，是弹层，不属于任何 `.page`，由共享外壳统一生成，贴视口右上角，不再叠加顶栏高度。登录层在这里是 `gate` 模式：登录前全屏覆盖，令牌到期或退出回到登录层。货灵ERP登录层多一个「演示身份」选择，进入后锁定。

## 4. 页面类型

本外壳使用 `list` / `report` 两类；`detail` 与表单都只作列表行抽屉的内容骨架（`DrawerDetail` 内部复用 `DetailPage`，`FormDrawer` 内部复用 `FormField`），**不注册独立页面，也不新增第六类骨架**。**不出现** `scan`（归 PDA）与 `shop`（归商城）。类型由注册表 `pages[].type` 声明，判据是「这页属于哪一类」，不是「组件能不能用」。

| 类型 | 组件 | 结构 | 硬约束 |
| --- | --- | --- | --- |
| `list` | `ListPage` | 状态页签 → 筛选条 → 工具条 → 表格 → 分页 | 一页一张表；**不加** `StatRow`、`ReportHero`、页内大标题、自绘筛选栏 |
| `detail`（仅抽屉内容） | `DrawerDetail` → `DetailPage` | 抬头字段网格 → 明细表 → 操作轨迹 → 底部操作条 | 抬头字段只读；明细用 `BaseTable`；不套状态页签与分页；不注册独立页面，只由列表行按钮打开 |
| `form`（仅抽屉内容） | `FormDrawer` → `FormField` | 抬头 → 分组字段 → 底部动作条 | 字段成组、一屏一主体；必填标记随字段声明；不套状态页签与分页；不注册独立页面 |
| `report` | `ReportHero` + `StatRow` + `Block` | 页头 → 指标卡 → 分节卡片 | 唯一允许摆 KPI 的类型；指标值由数据算，不写死数字 |

报表页用了 `ReportHero` 或 `Block` 即豁免列表页禁令；列表页用了 `ListPage` 就不得出现 `StatRow` / `PageHeader`。

编排类抽屉用 `DagDrawer`：抬头字段 + `DagGraph` 拓扑 + 节点属性块，宽度 920。它是抽屉内容的一种形态，不算第六类骨架；拓扑只读，增删节点与改依赖走列表与表单抽屉，图上不承接编辑动作。节点与属性块之间用 `:target` 联动，不写脚本。

### 4.2 打印

仓内与货主侧都有打印单据的需求（拣货单、复核单、装箱单、交接单、库位标签）。工具条与抽屉底部用 `data-print="<单据名>"` 声明打印入口，点击只打印当前可见页的当前表格：外壳、首栏、面板、筛选条、工具条、分页条在打印媒体里一律隐藏，表头补一行单据名与打印时间。

打印只改呈现，不改数据；不做导出 PDF、不做批量套打、不做打印模板编辑。列宽在打印媒体里按内容自适应，不保留屏幕上的固定像素宽。

### 4.1 列表页细则

- `statusTabs` 第一项是「全部」，不带 `field`；其余每项**必须**带 `field` + `value`，点了要真筛数据。行数据放在 `<tr data-row="转义后的行 JSON">` 里，脚本按 `row[field] === value` 比。
- 计数写 `statusTabs[].count` 或 `scopeNote`，不另做统计卡片。
- `filters` 由 `filters` 数组传，`type` 仅 `text` / `select` / `date` / `daterange`；`select` 的选项从行数据 `uniq()` 派生，不手抄枚举；`extra: true` 的收进「展开全部条件」。
- 数字列加 `align:'right'`，自动带 `tabular-nums`；列头口径说明用 `tipKey` 写进 `title`。**列头不塞按钮与图标**：排序用 `columns[].sortable` 声明，勾选与箭头由实现层画在 `<th data-sort-key>` 上，点整格切换升序 / 降序 / 不排序，三态循环。
- 需要批量处置的列表声明 `selectable` 与 `bulk`：表头出全选框，每行首列出勾选格；`bulk` 项给 `{ label, status }`，选中行数大于 0 时启用，点击把选中行的状态字段改成 `status` 并重算页签计数。没有 `bulk` 声明的列表不出现批量按钮，**不写点了不生效的批量文案**。
- 全量 `<tr>` 都写进产物并带 `data-row-idx`，分页只做显隐，`unit` 随页面取（条 / 单 / 行 / 个 / 件）。
- 派生列写成纯函数，不往 `data/*.json` 里加展示字段，避免产生第二份真相。

## 5. 层级与节奏

- **三级层级**：页级（页签、工具条）→ 块级（表格容器、分区卡片标题）→ 行级（单元格、字段值）。每级只能靠「字号 + 字重 + 留白」三者中的一种拉开，混用两种以上会显脏。
- **表格**：`<th>` 只用中性灰底与弱化字色，不加重、不加彩色；主键列加粗；长文本列截断，横向溢出交给容器滚动。
- **留白**：只用 4 / 8 / 12 / 16 / 24 / 32 六档；同页同层级间距必须同档，不许 10、14、18 这类插值。
- **空态**：一页一处，标题说状态，一句说原因；空态里不放统计、不放引导流程、不放插画。
- **一屏一主体**：列表页的主体是表；报表页的主体是指标卡；详情页的主体是抬头 + 明细。主体之外不并列第二个视觉重心。
- **信息自解释**：分区、字段、状态靠布局与标签说清楚，不在标题下挂副标题、不在区块顶部写引导句、不在字段旁写常显提示。确需补充的口径走 info 图标 + hover 提示（当前落到 `tipKey` / `title`，列头已是此机制），不做常显。
- **例外不删**：表单标签与可访问名称、危险 / 不可逆动作的后果提示（删除、提交永久性变更写清影响与能否撤销）、空态的状态与原因，都不按辅助文案删。`note` 只放数据与后果，不放教学段；`ReportHero` 的 `sub` 留空或只放时间范围、数据口径，不放页面概述。

## 6. 强调色纪律

- 主色（`--wx-primary-*`）只给：主按钮、当前页签、当前业务域、面板当前页、进度条、链接、品牌标记。
- 首栏当前域与面板当前页同属一次导航强调，按一处计；其余位置不得再出现第二处主色强调。
- 状态色（success / warn / error / info）只出现在 `StatusTag` / `Tag` / `StatRow` 的 tone 上，不做背景块、不做描边、不做图标着色。
- 中性灰阶承担其余全部分层；一屏出现两种以上强调色即视为超预算。

## 7. 禁区

| 错误做法 | 正确做法 |
| --- | --- |
| 列表页顶部铺一排 KPI 卡、加大标题 | 计数进页签，标题交给面板当前条目 |
| 自绘筛选栏、把筛选塞进面板表头 | 用 `ListPage` 的 `filters`，收不住的进「展开全部条件」 |
| 给表格加斑马纹、彩色表头、行悬浮变色成主色 | 中性灰底 + 边框分区；hover 只做底色微调 |
| 用渐变、插画、装饰性图标填补空白 | 空白靠留白与分组解决 |
| 首栏或面板表头放部署形态、主体切换器、套餐与配额卡 | 单实例单主体，首栏只放品牌字标、业务域、帮助、通知、用户；面板表头只放端名、产品名、搜索、跨端入口 |
| 只在字号上做层级，字重与留白齐平 | 三件套至少用两种，见第 5 节 |
| 键盘 Tab 看不到焦点 | 见 `references/implementation.md` 的焦点规则（当前待补齐） |
| 页顶写一句 slogan、每个区块下挂一行说明、字段旁写常显提示、按钮后补一句解释 | 结构自己说话；必要补充进 `tipKey` / `title`，不做常显文案。表单标签、可访问名称、危险动作的后果提示不在此列 |
| 为了让界面清爽，删掉表单标签、纯图标按钮的 `aria-label`，或删掉删除 / 提交永久变更的后果说明 | 标签、可访问名称、后果提示必留；先删冗余说明，再调布局与按钮文案 |
