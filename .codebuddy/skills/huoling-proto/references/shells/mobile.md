# 独立站 APP 外壳视觉法（mobile）

适用于 `shell = "mobile"` 的独立站 APP（`site-mobile-app`，5 页，全部 `shop` 型）。页面源在 `site-front` 模块。本外壳是消费端手机壳，**不是作业终端**：没有物理按键区、没有扫码语义、没有「作业 / 扫码 / 终端」分组。

## 1. 设计意图

单手浏览的品牌站。使用者站着或坐着看品牌与产品，判据是「一屏能不能看懂一张卡、下一步点哪里」。与作业 APP 的根本差异：这里的任务是**看**，不是扫；输入只有点击。

四条取向：

- **一屏一段**：首屏只回答三件事——这是哪个品牌、有什么产品、门店在哪。
- **卡片流**：商品与门店都用卡片，不用表格；一屏 2 张商品卡。
- **大目标**：可点元素 ≥ 44px；底部四个 tab 常驻。
- **无悬停**：所有反馈靠按下态与页面切换，不靠 hover 提示。

## 2. 基准

| 项 | 取值 |
| --- | --- |
| 设备基准 | 375 × 812（竖屏单手） |
| 当前外壳渲染 | 机身 405px 宽，屏 375 × 720，圆角 30 / 8px，深色机身 |
| 屏内可用高度 | 720 − 状态条 28 − 导航 44 − 底部 tab 44，其余给内容 |
| 最小触控目标 | 44px |
| 字号 | 只用 12 / 13 / 14 / 16 / 20 / 24 |
| 适配 | flex / grid / 百分比 / media query，不用 `rpx` |

## 3. 骨架

```
.wx-mobile-app（居中容器，浅灰底）
└ .wx-mobile-device（深色机身）
    ├ .wx-mobile-screen（375 × 720）
    │   ├ .wx-mobile-status（左：站点名 右：端名）
    │   ├ .wx-mobile-nav（返回 / 当前页名）
    │   ├ .wx-mobile-body（唯一滚动容器，一屏一个 .page）
    │   └ .wx-mobile-tabs（底部四个分组 tab）
```

- 机身为演示载体，只做一次，页面模块不画机身、不画状态条。
- 「返回」只在页面栈有上一屏时可用；从 tab 进入的首屏不显示返回。
- 窄屏（≤480px）铺满，不显示机身。

## 4. 页面类型

五页全部 `shop` 型，用 `ShopPage` 组合共享组件，**不套** `ListPage` / `ReportHero` / `ScanPage`。

| 页 | 主体 | 组合 |
| --- | --- | --- |
| 站点首页 | 纵向品牌首屏 + 两列商品 + 门店入口 | `ShopHero` + `ShopFloor` + `ProductCard` |
| 站点商品 | 两列商品卡 | `ShopFloor` + `ProductCard` |
| 站点商品详情 | 大图 + 规格 + 公开价 + 到店咨询 | `ShopDetailHero` + `ShopActions` |
| 品牌故事 | 纵向年份沿革 + 资质 | 分段结构 |
| 门店网点 | 单列门店卡 | 自定义门店卡 |

商品卡整块可点，进入商品详情；不出现加购按钮。价格走公开零售价（`publicPrice: true`）。

## 5. 层级与节奏

- **三级层次**：品牌名与当前页名 → 商品卡 / 门店卡 → 辅助信息（规格、营业时间）。位置固定，换页不换顺序。
- **网格**：商品两列，间距 12；门店单列，地址不截断，允许两行。
- **按钮**：主操作在卡片内或页尾常驻，次操作在左、主操作在右；危险动作不占主操作位。
- **留白**：只用 4 / 8 / 12 / 16 / 24；屏宽有限，不用 32。

## 6. 强调色纪律

- 主色只给主操作、当前 tab 与关键数字。
- 不使用商城橙 `--wx-mall-*`；首屏深色用 `--wx-gray-900`。
- 状态胶囊在屏内不超过两个，且不并排；用文字 + 色型，不靠图标。

## 7. 禁区

| 错误做法 | 正确做法 |
| --- | --- |
| 复用作业 APP 的 `pda` 外壳与六键按键区 | `shell = "mobile"` 走 `wx-mobile-app`，没有按键区 |
| 屏内出现后台侧栏、页头页签、货主下拉 | 本端只有状态条 + 导航 + 内容 + 底部 tab |
| 在 375 宽塞四列商品或密集表格 | 两列卡片；门店单列，表格最多三列 |
| 依赖 hover / tooltip 传递关键信息 | 信息直接摆在屏上，反馈用按下态与页面切换 |
| 横向滚动、双指缩放、长表单 | 单列纵向；不铺表单 |
| 写操作说明、字段旁提示、区块引导句 | 一屏一段靠结构表达；无 hover，删减或并入主标签 |

## 8. 与其它外壳的边界

- 不复用 `pda`：作业 APP 面向仓内作业，有状态条、按键区与扫码任务；本外壳面向消费者。
- 不复用 `mall`：商城是桌面货架，有购物车与买家身份；独立站 APP 只做品牌展示。
- 不复用 `site`：Web 是编辑式宽版面，APP 是单列卡片流；两套页面源各自渲染，不共享布局类。
