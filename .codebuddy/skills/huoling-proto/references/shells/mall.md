# 商城外壳视觉法（mall）

适用于 `shell = "mall"` 的货灵商城（`mall-app`，六页，全部 `shop` 型）。商城**管理**页（`mall-admin` 七页）归货灵运营中台管理端，走 `references/shells/admin.md`，不在本卷。

## 1. 设计意图

货架型界面。使用者是来选货的采购方，判据是「三十秒内能不能找到货、敢不敢下单」。与后台的根本差异：后台的主体是表，商城的主体是**商品与价格**。

由此定四条取向：

- **商品是主角**：版面重心永远在商品图与价格上，不在导航、不在装饰。
- **价格是锚点**：金额字号大于商品名，访客态用「登录可见价格」占住同一个位置，不塌版。
- **单一强调色**：`--wx-mall-*` 独占价格、促销、主按钮、当前类目；不与主色 `--wx-primary-*` 混用。
- **前台外壳**：没有侧栏、没有页头页签、没有货主下拉，导航就是页面 + 类目两条。

## 2. 基准

| 项 | 取值 |
| --- | --- |
| 内容区 | `max-width: 1200px` 居中，两侧留白由 `--wx-sp-6` 控制 |
| 设计基准 | 1440 宽桌面为主，窄到 768 仍可读（类目与导航换行，不横向滚动） |
| 顶栏 / 导航 | 商城前台顶栏与类目导航各一条，不高仿后台顶栏 |
| 最小触控目标 | 44px；卡片整体可点，不靠小字链接 |
| 字体 | 系统字体栈，与后台同一套 |

## 3. 骨架

```
.wx-shop-app
├ .wx-shop-top（品牌 / 商品搜索 / 进货单 + 角标 / 我的订单 / 登录或采购账号）
├ .wx-shop-nav（本端页面项 + 分隔 + 类目项）
├ .wx-shop-main（max-width 1200）
│   └ .page[data-page-id]（一屏一个）
└ .wx-shop-foot（一行货源与履约说明）
```

- 搜索框是 2px 强调色描边的一体化控件，输入与按钮同框，不做两个分离的圆角块。
- 进货单入口带数量角标；角标是唯一的「强提醒」形态，不额外加红点、加气泡文案。
- 页面容器仍遵循 `.page` + `data-page-id`，切页用 `data-target`，与后台同一套脚本语义。
- 登录层是 `entry` 模式：默认停在首页，由顶栏「登录」入口唤起，可关闭回到首页。访客态与登录态由 `<html data-auth>` 驱动。

## 4. 页面类型

六页全部 `shop` 型，用 `ShopPage` 组合共享组件，**不套** `ListPage` / `DetailPage` / `ReportHero` / `ScanPage`，不写页面级脚本。

| 页 | 主体 | 组合 |
| --- | --- | --- |
| 商城首页 | 楼层 + 店铺推荐 | `ShopHero` + `ShopHomeGrid`（`ShopCategory` + `ShopFloor`）+ `ShopPanel` |
| 商品搜索 | 筛选 + 结果 | `ShopFilter` + `ShopResult` + `ProductCard` / `ShopEmpty` |
| 商品详情 | 商品 + 阶梯价 + 加购 | `ShopDetailHero` + `ShopTable` + `ShopActions` |
| 进货单 | 行项目 + 合计 | `CartTable` + `ShopSummary` |
| 确认订单 | 收货信息 + 清单 + 提交 | `ShopFields` + `CartTable`（只读）+ `ShopSummary` + `ShopActions` |
| 我的订单 | 订单卡列表 | `OrderCard` |

## 5. 层级与节奏

- **卡片四段**：缩略区 / 名称与规格 / 价格 / 动作，顺序固定。缩略区是 140px 高的色块加首字（由 `tone` 决定底色），不引外部图片、不塞图标库、不用 emoji。
- **网格**：楼层内卡片等宽等高，一行 4 列；≤1080 降 3 列，≤800 降 2 列。行数由数据决定，不为了「填满」而复制商品。
- **类目条**：左侧 200px 固定宽度（≤1080 收窄到 160px），是筛选器不是第二套导航。
- **价格**：一律由 `ShopPrice` 输出，金额由 `money()` 从单价与数量派生；页面模块不直接拼「￥」。
- **结果条**：搜索页保留「共 N 件商品」计数，空结果时页面不能只剩一块空白；当前类目只有一处高亮。

## 6. 强调色纪律

- `--wx-mall-50` 做浅底，`--wx-mall-500` 做主按钮与价格，`--wx-mall-600` 做文字强调与 hover。
- 主色 `--wx-primary-*` 不出现在商城前台；后台件（表格、页签、状态胶囊的 `info` tone）不得串进 `shop` 页。
- 访客态不是「禁用态」：金额位置显示「登录可见价格」，颜色用中性灰，不用警示色。

## 7. 禁区

| 错误做法 | 正确做法 |
| --- | --- |
| 给货灵商城套后台外壳、加侧栏与页头页签 | `shell = "mall"` 走 `wx-shop-app`，导航只有页面 + 类目 |
| 把后台表格直接搬进商品列表 | `ProductCard` / `ShopFloor` 组织商品，表格只用于进货单与阶梯价 |
| 同屏出现橙色促销块 + 蓝色按钮 + 红色角标 | 强调色只有一个来源 `--wx-mall-*` |
| 轮播、自动滚动、倒计时闪动 | 静态楼层 + hover 轻反馈；动效不承担信息 |
| 商品卡堆角标（包邮、现货、新品、爆款） | 最多一个状态标记，其余信息进商品标题或详情 |
| 空结果只显示一行字，结果条计数一起消失 | `ShopEmpty` 说状态 + 说原因，结果条保留计数，页面不留整屏空白 |
| 楼层标题下挂「精选好货，品质保障」式宣传语，商品名后跟一句卖点补充 | 商品图、名称与价格自己说话；卖点并入规格或详情页，不常显 |
| 为了清爽，把提交订单的扣款与发货规则、取消与退货条件一并删掉 | 提交订单是不可逆动作，后果提示留在提交区，不随宣传语一起删 |
