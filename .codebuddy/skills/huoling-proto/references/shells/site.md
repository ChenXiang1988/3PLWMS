# 独立站 Web 外壳视觉法（site）

适用于 `shell = "site"` 的货主独立站 Web 端（`site-app`，5 页，全部 `shop` 型）。页面源在 `site-front` 模块，产物归本端。本外壳只服务品牌站展示；采销站的交易页在货灵ERP，不进本端。

## 1. 设计意图

编辑式品牌站。使用者是来了解品牌与产品的访客，判据是「三十秒内知不知道这是谁、卖什么、去哪里看实物」。与货灵商城的差异：商城的主体是货架与价格，独立站的主体是**品牌与产品叙事**，交易不是必需。

四条取向：

- **品牌是主角**：首屏给品牌名、品牌事实与主推产品，不给促销条与倒计时。
- **编辑式版面**：宽留白、细分隔线、大字号标题；版面靠栅格与留白分层，不靠彩色卡片堆叠。
- **单一强调**：全站只用主色 `--wx-primary-*` 与中性灰；不出现商城橙 `--wx-mall-*`。
- **前台外壳**：没有侧栏、没有页头页签、没有货主下拉、没有进货单角标。

## 2. 基准

| 项 | 取值 |
| --- | --- |
| 内容区 | `max-width: 1200px` 居中，两侧留白由 `--wx-sp-6` 控制 |
| 设计基准 | 1440 宽桌面为主，窄到 768 仍可读 |
| 顶栏 | 站点字标 + 站点名 + 五个页面入口，粘顶 |
| 最小触控目标 | 44px |
| 字号 | 只用 12 / 13 / 14 / 16 / 20 / 24，不引入新档 |
| 适配 | flex / grid / 百分比 / media query，不用 `rpx` |

## 3. 骨架

```
.wx-site-app
├ .wx-site-top（站点字标 + 站点名 + 页面导航 + 登录入口）
├ .wx-site-main（max-width 1200）
│   └ .page[data-page-id]（一屏一个）
└ .wx-site-foot（站点名、备案号、联系方式）
```

- 页面容器仍遵循 `.page` + `data-page-id`，切页用 `data-target`，与其它端同一套语义。
- 登录层是 `entry` 模式：默认停在首页，访客可浏览；登录入口在顶栏，不遮挡首屏。
- 站点字标取 `sites.json` 的 `siteMark`，不写死「仓」。

## 4. 页面类型

五页全部 `shop` 型，用 `ShopPage` 组合共享组件，不套 `ListPage` / `ReportHero` / `ScanPage`。

| 页 | 主体 | 组合 |
| --- | --- | --- |
| 站点首页 | 品牌首屏 + 品牌事实 + 商品楼层 + 门店入口 | `ShopHero`（深色底）+ `ShopFloor` + `ProductCard` + `ShopRow` |
| 站点商品 | 类目 + 商品网格 | `ShopCategory` + `ShopFloor` + `ProductCard` |
| 站点商品详情 | 大图 + 规格 + 公开价 + 到店咨询 | `ShopDetailHero` + `ShopTable` + `ShopActions` |
| 品牌故事 | 年份沿革 + 产地 + 资质 | `ShopPanel` + `Block` 等价的分段结构 |
| 门店网点 | 城市分组 + 地址 + 营业时间 + 电话 | `ShopTable` / 自定义门店行 |

品牌站价格走公开零售价：`ShopPrice` 传 `publicPrice: true`，访客态不显示「登录可见价格」。商品卡不出现加购按钮，动作文案为「查看商品」或「到店咨询」。

## 5. 层级与节奏

- **首屏三段**：站点名与一句品牌事实（数据）→ 主推产品 → 门店入口。顺序固定，换页不换。
- **商品网格**：一行 4 列，≤1080 降 3 列，≤800 降 2 列；卡片等宽等高，不为了填满复制商品。
- **留白**：只用 8 / 16 / 24 / 32；区块之间用 32，卡片内部用 16。
- **数字**：品牌事实（门店数、在售商品、始创年份）用 20 / 24 档，同一行不并排两个大数字。

## 6. 强调色纪律

- 主色只给主操作、当前导航与关键数字；首屏深色底用 `--wx-gray-900`，正文用 `--wx-gray-700`。
- 不出现 `--wx-mall-*`；不出现橙色促销块、红色角标。
- 状态色只在需要时出现，一屏不超过一处。

## 7. 禁区

| 错误做法 | 正确做法 |
| --- | --- |
| 套后台外壳、加侧栏与页头页签 | `shell = "site"` 走 `wx-site-app`，导航只有页面入口 |
| 把货灵商城顶栏与进货单角标搬过来 | 独立站没有购物车与买家身份，顶栏只留站点与页面导航 |
| 首屏堆促销条、倒计时、轮播 | 静态品牌首屏 + 商品楼层；动效不承担信息 |
| 品牌名旁挂「品质保障」「源自自然」式口号 | 品牌事实用数据表达（门店数、产地、年份），口号不进界面 |
| 商品卡堆包邮、现货、新品角标 | 最多一个状态标记，其余进商品详情 |
| 价格位在访客态塌掉 | 品牌站用公开零售价，金额位置固定 |

## 8. 与其它外壳的边界

- 不复用 `mall`：商城有购物车、买家登录与商城橙，独立站没有。
- 不复用 `admin`：独立站没有双栏、导航面板与货主作用域。
- 采销站的交易能力不落到本外壳；交易在货灵ERP的站点商品、站点订单与订单中心。
