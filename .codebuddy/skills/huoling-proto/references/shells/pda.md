# PDA 外壳视觉法（pda）

适用于 `shell = "pda"` 的 PDA 作业端（`pda-app`，14 页）。页面源分散在多个模块：`pda/*` 六页终端壳层、`task/pda-*` 四页作业入口与任务列表、`inbound|outbound|warehouse` 三页扫码作业。**源按模块放，产物归本端**，跨模块不是违规。

## 1. 设计意图

手套型界面。使用者站着作业、单手、可能戴手套、注意力在货上而不在屏上，判据是「一次扫对没有、下一步该干嘛有没有歧义」。

四条取向：

- **一屏一任务**：屏幕上只回答三件事——我在哪张单、现在该扫什么、这张单还剩多少。
- **大目标**：可点元素 ≥ 44px；主操作常驻底部，不藏进菜单。
- **单输入**：任何时刻只露**一个**待输入控件，扫完自动转下一项，不铺表单。
- **高对比、零悬停**：触屏没有 hover，所有反馈靠按下态、状态条与大数字，不靠悬停提示。

## 2. 基准

| 项 | 取值 |
| --- | --- |
| 设备基准 | 375 × 812（竖屏单手） |
| 当前外壳渲染 | 机身 405px 宽，屏 375 × 720，圆角 30 / 8px，深色机身 |
| 屏内可用高度 | 720 − 状态条 28 − 导航 44，其余给内容，底部操作区常驻 |
| 最小触控目标 | 44px |
| 字号 | 只用 12 / 13 / 14 / 16 / 20 / 24，不引入新档 |
| 适配 | flex / grid / 百分比 / media query，**不用 `rpx`** |

## 3. 骨架

```
.wx-pda（居中容器，浅灰底）
└ .wx-pda-device（深色机身 + 摄像头 / 指示灯 / 侧键装饰）
    ├ .wx-pda-screen（375 × 720）
    │   ├ .wx-pda-status（左：操作员 中：设备号 右：端名）
    │   ├ .wx-pda-nav（返回 / 当前页名 / 我的）
    │   ├ .wx-pda-body（唯一滚动容器，一屏一个 .page）
    │   └ .wx-pda-toast
    └ .wx-pda-keypad（返回 / 主页 / 菜单 / 清空 / 扫描 / 确定 六键）
```

- 机身为演示载体，只做一次，页面模块不画机身、不画状态条。
- 「我的」按钮只在 `pda-mine` 存在时出现，否则留同宽占位，避免标题左右跳动。
- 扫码页的 `.page` 在屏内是绝对定位的滚动容器；页面自己的样式不要覆盖 `.wx-pda-body .page` 的定位规则。

### 3.1 登录是设备登录

首屏是 `pda-login` 页的设备登录屏，**不是账号密码表单**。使用者在货架边站着，手上可能有货，判据是「几秒能开工」，不是「密码是否合规」。

- **主路径**：扫工号牌。工牌就是身份，扫完进 PIN 或直接进作业。
- **备选**：输入工号 + 4 位 PIN（扫不到工牌时用），数字键盘由系统调起，页面只给一个 56px 高的居中输入位。
- **设备能力**：人脸识别走 `pda-face` 页，登录屏只给入口。
- **设备状态**：状态条左栏未登录时显示「未登录」；本机没绑定就在登录屏给「未绑定 · 去接入」，跳 `pda-invite`。
- **禁止**：记住工号、忘记密码、第三方登录、验证码、账号 + 密码双输入框——这些是网页登录的语汇。忘记工号找班组长，设备没绑走接入流程。
- **不叠两层**：共享登录层在本端是 `entry` 模式（不覆盖首屏），登录由页面承担；否则用户要先过一遍后台表单，再看见真正的设备登录。

## 4. 页面类型

本外壳用 `scan`（主）、`list`、`report`（我的）：

| 类型 | 在本端怎么用 | 硬约束 |
| --- | --- | --- |
| `scan` | `ScanPage` 六段：导航 → 任务上下文 → 当前输入 → 对象摘要 → 数量与进度 → 操作 | 一屏只露当前一个输入；动作快照不铺成步骤表 |
| `list` | `ListPage` 走 `bare: true` + `card`，**不出**页签、筛选条、工具条、分页 | 卡片是入口不是表格；一屏 3–5 张，多了靠滚动 |
| `report` | `ReportHero` + `StatRow` + `Block` 压缩使用 | 指标 ≤ 4 个，卡片内不并排放第二组数字 |

写 `scan` 页前先答三句：人现在只该扫哪一个？扫到的东西显示在哪？这条做完该干嘛？答不上就是又想铺步骤表。系统的校验序列（拦什么、留什么证）不是人的操作步骤，不落到界面上。

## 5. 层级与节奏

- **三级层次**：任务上下文（单号、货主）→ 当前输入（唯一焦点）→ 摘要与进度（辅助）。三者在屏内从上到下，位置固定，换页不换顺序。
- **数字优先**：数量与进度用 20 / 24 档，单位跟在数字后，同一行不并列两个大数字。
- **按钮**：底部两键等宽常驻（`flex:1`），次操作在左（ghost），主操作在右（主色）。危险动作（清空、取消）走文字按钮或按键区，不占主操作位。
- **留白**：只用 4 / 8 / 12 / 16 / 24；屏宽有限，不用 32。

## 6. 强调色纪律

- 主色只给主操作、当前进度、扫描成功态。
- 状态胶囊在屏内不超过两个，且不并排；作业状态用文字 + 色型，不靠图标。
- 不使用彩色底块分区（后台的灰底卡片在这里会占掉一屏高度）。

## 7. 禁区

| 错误做法 | 正确做法 |
| --- | --- |
| 把扫码页做成步骤表 / 向导条，一次露多个输入框 | 只露当前一个输入，扫完自动转下一项 |
| 在 375 宽里塞多列密集表格 | 改 `card` 列表，一屏 3–5 张 |
| 依赖 hover / tooltip 传递关键信息 | 信息直接摆在屏上，反馈用按下态与 toast |
| 横向滚动、双指缩放、长表单 | 单列纵向；表单拆成多次提交 |
| 屏内出现后台的侧栏、页头页签、货主下拉 | 本端只有状态条 + 导航 + 内容 + 按键区 |
| 机身里再画一套状态栏 | 状态条与按键区由 `renderPdaShell` 统一生成 |
| 在屏上写操作说明、字段旁提示、区块引导句 | 一屏一任务靠结构表达；本端无 hover，删减或并入主标签，不用 tooltip 兜底。表单标签、可访问名称与清空等不可逆动作的后果提示不在此列 |
