# 文案权威源

本文件是 [SKILL.md](../SKILL.md) 第 2 步「查权威源」的第 2 项，**3PL 云仓原型所有可见文字的唯一出处**。页面上的字，要么在本文件里，要么先登记再写。

## 1. 使用规则

- 端名、模块名、页面名、页签、列名、按钮文案、状态中文名、空态文案、分页单位，逐字取用，含空格与全半角。
- 字段名（JSON 的 key）与显示文案（列 `label`）分开：字段名用小写驼峰，显示文案取本文件。
- 列定义 `tipKey` 写口径说明，但说明本身也是文案，取本文件第 5 节的口径句，不自撰。
- 演示数据里的值也受约束：状态值、优先级、单位取本文件的枚举，不写 `test` / `demo` / `示例数据`。
- 本文件只收「会出现在界面上的字」。实现说明、设计理由、迭代计划一律不进本文件，也不进页面。

## 3. 状态枚举与色型

### 单据状态（list / detail 页）

| 值 | 中文 | tone |
| --- | --- | --- |
| `pending` | 待处理 | `pending` |
| `doing` | 进行中 | `enabled` |
| `exception` | 异常待处理 | `rejected` |
| `completed` | 已完成 | `disabled` |
| `cancelled` | 已取消 | `disabled` |

### 其它枚举

| 项 | 取值 |
| --- | --- |
| 优先级 | `高` / `中` / `低`，对应 `Tag` 的 `danger` / `info` / `default` |

| 数量单位 | 件 / 箱 / 托 / 千克，按列定义取，页面上不自造单位 |
| 分页单位 | 条 / 单 / 行 / 个 / 件，按页面取 |
| 变更类型 | 新增 / 变更 / 停用 |
| 是否 | 是 / 否 |
| 出库分配规则 | FEFO / FIFO |
| 失效日期来源 | 生产日期推算 / 供应商给定 |
| 批次编码规则 | 生产日期加流水 / 到货日期加流水 / 供应商批次号 |
| 温区 | 常温 / 恒温 / 冷藏 / 冷冻 |
| 仓库类型 | 中心仓 / 前置仓 / 分拨仓 / 保税仓 / 转运仓 |
| 温区配置 | 常温 / 恒温 / 冷藏 / 冷冻；多温区用逗号拼接，如「常温，冷藏」 |
| 策略项 | 是否效期管理 / 保质期天数 / 生产日期必填 / 失效日期来源 / 临期预警天数 / 禁售天数 / 是否批次管理 / 批次编码规则 / 混批存放 / 出库分配规则 / 温区 / 质检要求 |
| 报表分节标题 | 明细 / 构成 |
| 金额单位 | 元；价格、小计、合计统一写「￥」加两位小数 |
| 商品类目 | 全部商品 / 食品饮料 / 日化清洁 / 家居百货 / 数码配件 |

## 6. 新增文案登记流程

1. 在本文件对应表格追加一行，给出值、中文名、色型或列宽口径。
2. 若涉及新端、新模块或新页面，同步 [modules.md](modules.md) 第 2 节与 `prototypes/01 shared/modules.json`。

## 7. 禁语表

下列文字不得出现在页面或产物中（验收脚本 S5 / 构建期 `[文案]` 与 `[非SaaS]` 会拦）：

| 类别 | 词 |
| --- | --- |
| 过程文字 | `TODO`、`lorem`、占位符、`示意代码`、实现说明、设计注解、操作指引 |
| 迭代话术 | 本期不做、后续迭代、暂不支持、待开发 |
| SaaS 红线 | 租户、账号空间、按租户分库、订阅、套餐、充值、续费、试用到期、升级专业版、平台运营后台、主体切换器 |

商城端允许多货主店铺、店铺评分与入驻入口：供货方是本部署内的货主，店铺是业务展示维度，不是独立租户，商城卖的也是货主的货。入驻指货主在本部署内开通店铺，不写订阅、套餐、充值、续费、试用到期、升级专业版，不画平台运营后台与主体切换器。上表一个词都不放宽：多店铺是业务维度，不是架构分层。
